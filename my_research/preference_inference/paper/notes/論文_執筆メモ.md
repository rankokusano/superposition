## 1. 前提

- 投稿先：未定（候補：Advanced Robotics、認知科学、日本神経回路学会誌）。まず日本語で書く。刷り上がり 8〜15 ページ（目安 13 ページ前後）。
- 原稿：Overleaf。本文は章ごとの .tex（`sections/intro.tex` など）で、`\section` から始める。
- **処理系（2026-10-25 確定）**：upLaTeX と jsarticle（`\documentclass[uplatex,dvipdfmx,a4paper,11pt]{jsarticle}`、`pxjahyper`）。Overleaf の Compiler は「LaTeX」で、最上位の `latexmkrc`（uplatex → upbibtex → dvipdfmx）で動かす。LuaLaTeX と ltjsarticle は時間切れになるため使わない。
- **文字**：upLaTeX は Unicode の文字をおおむね扱えるが、投稿先のテンプレートが pLaTeX の場合に備え、ローマ数字（Ⅰ・Ⅱ）や丸数字（①②）は使わない。段階は「段階I・段階II」（半角）、データの①②は本文では名前（緑好みデータ・好み混合データ）で書く。
- 仮の `main.tex`（2026-10-25）：文献は unsrt。まだない節・図は見出しと枠だけを出して止まらない。表は `tables/` に枠だけの仮のファイルを置き、Claude Code が上書きする。投稿先が決まったら文書クラスと文献の体裁を差し替える。節のファイル名：intro / related / methods / results / discussion（限界の小節 `sec:limitations` を含む）/ conclusion / appendix。
- 参考文献：BibTeX で別に出し、本文は `\cite`。書誌は確かなものだけ書き、不確かなものは【要確認】とする。
- 図：`\includegraphics{figs/…}` で場所だけ作り、コメントで中身（横軸・縦軸、何と何を比べるか）を書く。図そのものは Claude Code で作る。
- 表：数字の入った表は Claude Code がログから .tex で作る。本文では `\input{tables/…}` で場所だけ作り、コメントで中身を書く。
- 数字：プロジェクトの md にあるものだけ使う。見つからないものは【要確認】、まだ出ていないものは【結果待ち】。推測で埋めない。最後に Claude Code でログと照合する。

## 3. 論文の方針（書き方の約束）

1. **「他者の好みを推定する AI」ではなく、「シミュレーションで他者を理解する仕組みの、できることとできないこと」**として書く。成功も否定的な結果も、一つの問いへの答えの部分として置く。
2. **「好み」より「価値に従う行動の見込み」**と書く（快・不快は方角ごとに人が計算して渡しているため）。
3. **「好みを与えれば他者の動きを予想できる」とは書かない**（投影の誤りで予測がかえって外れるため）。「他者を価値の方へ動く者として予測する」と書く。
4. **発達研究**（Sommerville らのくっつく手袋、Repacholi & Gopnik、Woodward）は類推として書く。人間について証明したとは書かない。
5. **限界は正直に書く**：人間のデータがない、環境が小さい、Encoder は凍結（自他の揃いは与えたもの）、快・不快は人が計算した方角ごとの値、逆推論の候補はこちらが用意した二択。
6. **本文で版の番号を使わない**。実験は番号、条件・モジュールは中身の分かる名前（対応表）。
7. **事前登録の区別を文で分ける**：事前登録した判定、事後に定義した指標、事前登録外の記述。
8. 倍率（約2.3倍など）は使わず、差と 95% CI で書く（文書内で 2.3 倍と 2.4 倍が混在するため）。
9. **研究室の中の言い方を本文で使わない**（2026-10-25 決定）。下の用語集にそろえる。

## 5. 主張と根拠（数字は md にあるもの）

**主張1：自分の経験から、価値に従う行動の見込みが生まれ、経験なし < 50% < 80% と段階的に強くなる（実験1）**
- G3 の組をまたいだ差（6組、事前登録外の記述）：50%−なし +0.071 [+0.064, +0.079]、80%−50% +0.141 [+0.131, +0.152]、80%−なし +0.213 [+0.205, +0.221]（v13 まとめ §11）。
- 組ごとの判定（事前登録）：G2・G3 は 50%・80% とも 6/6、G3 の 80%−50% も 6/6（v13 まとめ §10）。
- 共有によらない（3組）：G3 80% +0.225〜+0.240、非共有 +0.238〜+0.248（v13 まとめ §5）。
- 注意：G1 は 80% で 6組とも 0.80 に届かない（共通テスト 0.72〜0.75。角にとどまる学習データによる一般化の弱さ）。経験の量は3水準だけで、比例か飽和かは分からない。

**主張2：見込みは共有を通って他者側に届き、他者側に入れた快・不快に働く（実験2）**
- 事前登録した G5b：80%−なし +0.361 [+0.057, +0.665]（6組、5/6 組で正、s3 で外れる）。段階ごと（50%−なし +0.143 [−0.109, +0.394]、80%−50% +0.218 [−0.066, +0.503]）は 0 を含む。
- 符号に従う分（s0〜s3 は事後に定義、s4・s5 だけ事前登録）：二段階とも 0 を含まない。① 50%−なし +0.138 [+0.028, +0.248]、80%−50% +0.207 [+0.050, +0.363]。② +0.137 [+0.027, +0.246]、+0.163 [+0.059, +0.267]。
- 非共有で消える（3組）：G5b −0.01〜+0.01、符号に従う分 0 前後。自分側は同じ。作りから予想される確認として書く（入口の重みが一度も学習されない）。
- **書き方**：「当てはめは経験の量に応じて強くなる」と書くときは、根拠が「事前登録した G5b（80% と経験なしの差）」と「段階的に強くなる符号に従う分（一部は事後の指標）」の二つであることを区別する。G5b だけで段階的な強まりが示されたようには書かない。段階的と言い切れるのは自分側（G3）。
- 使わない：「G5b は同じシードの中で 80% > 50% が4組とも」「経験なしとの差は4組中3組」（古い言い方）。
- 外れた組は本文で触れ、詳細は付録：s3（経験なしの G5b が +0.29）、s5（G5b は 50% の方が大きいが、符号に従う分は 80% の方が大きい）。
- G5b の限界：A-2 静止の共通テストで、1つの範囲に ±a（a = 0.28）を入れる人工的な入力。A-2 の本当の好みは使っていない。

**主張3：見込みが強いほど、行動の仕方が自分と違う他者では、本当の快・不快を入れると予測がかえって外れる（投影の誤り、実験2）**
- T3 の D6（他者側の特徴予測の誤差）：80% 0.39〜0.42、50% 0.25〜0.28、経験なし 0.26〜0.29。組 s1 では零より悪い（3組。v13 まとめ §4）。
- 悪化の大部分は一歩の種類によらない全体の位置のずれ（従った一歩でも +0.11〜+0.15）。
- **書き方**：「自分の好きな方へ寄せる」ではなく、「**他者を、自分と同じ強さで快の方へ動く者として見積もる（自分の行動の仕方を当てはめる）**」。寄せすぎの向きは入れた快・不快の正の向き（A-2 の好きな色）。A-1 自身の好きな色への投影は、調べたモデル（v12・v14-C）では出ていない。
- シミュレーション説の「投影の誤り」に当たる、と考察で書く。D6 は段階Iにとって学習で見ていない入力であることも並べる。

**主張4：他者用のモジュールは、好みを書き出さず、位置や方角の近道を選ぶ（実験3）**
- 自由出力モジュール：v12 正式 T2 1/4・T5 1/4、v13（探索）T2 2/4・T5 1/4。Q2 の分散の大半が範囲 2〜5。
- 作りを変えても同じ：形制限モジュール（v12 b、T2 0/4）、他者遮蔽学習（v12 c、T2 0/3）、1ビットモジュール（v14-B、T5 ≈ 0、食い違う場面で好みに従う割合 0.30〜0.41）。
- 本文 4.4 では一段落で「作りを4通りに変えても毎回近道を選んだ」ことを示す。各設計の詳しい数字は付録へ。
- 理由（三層の分析、近道と本道）は推測として考察へ。

**主張5：仮説を入れ比べる逆推論では、80% で正解率が偶然を上回り（H4a）、方角と食い違う場面でも一部の組で好みに従った（H4b、部分的）（実験4）**
- 主の判定（本番の3組 s0〜s2）：80% は3組とも合格、50% は1組（s0）で不合格。全6組（頑健さ、除かない）：80% は4組（s0・s1・s2・s5）、50% は1組（s0）。s3・s4 は単独では不合格（v14_summary §2 (1)、v14_results_log §9、v14 ログ §43・§44）。
- 共有なしでは成り立たない（v13 − 非共有が3組とも 5/5。非共有は s0〜s2 だけ）。
- **方角だけの基準**（表・図に並べる）：A-2 の t = 1〜50 の進んだ方角で選ぶと、好みとの一致は全体で 0.707、規則の一歩が少ない3分の1で 0.607（データだけで決まる値。v14 ログ §19）。BA で表した値は md にない【要確認：Claude Code で出す】。
  - **注意**：この基準の一致率 0.71 は、80% のモデルの BA（L1 で 0.53〜0.70）と同じかそれより高い。「方角より正解率が高い」とは書けない。言えるのは「モデルの選択は方角だけには還元できない（食い違う場面で一部の組が好みに従う）」まで。方角の基準は A-2 の本当の位置を使うが、モデルは A-1 の視界だけを使うことも並べる。
- 食い違う 88 エピソード（FP、MSE 期間の最終5点、事前登録の条件）：本番の3組で2組（s1・s2）、全6組で4組（s1・s2・s3・s5）が「好み」。s0・s4 は「方角」。
- 指標で組が入れ替わる：FP では s1・s2・s3・s5、自己の視界の誤差（L1）では s0・s1・s5。両方で満たすのは s1・s5（v14_summary §5 の 3）。
- 注意：s4 の不成立は、経験なし（v12）の s4 も 0.5 を上回ったため（0.557〜0.574、組の差 +0.015 [−0.040, +0.075]）。経験なしでも区別できる組がある点は限界に入れる。s0・s5 の組の差は、経験なしの逆向き（s0 0.389〜0.420、s5 0.392〜0.432）による部分がある。
- 注意：v12 の経験なし s2 も条件を満たす。規則の一歩が少ない3分の1ではどの組も満たさない。方角の条件は v12 の結果を見た後に決めた。手続き（二択の候補）は外から与えたもの。「ネットワークが自分で推し量った」とは書かない。

**付録実験A（好み切替経験）**
- 付録に入れ、考察で一〜二文：「好みが一貫した経験の量は当てはめを強めるが、好みが変わる経験では強くならない」（どんな経験が効くかの手がかり）。
- 「好みが変わる経験では投影も出ない」は、投影が固定した自分の好みから生まれるという解釈と合う。ただし当てはめ自体が弱まっていることが理由である可能性も併記する。

### 11.2 考察の枠組みの検討（投影の誤りと実験3を結びつける）

- 提案された枠組み：本モデルの投影の誤りは「調整を欠いたシミュレーション」（Tamir & Mitchell の、自分を出発点にして調整する過程のうち調整がない状態）に当たる。Suzuki らの区別でいえば、自分の価値づけを流用する経路だけがあり、他者の行動の予測誤差で他者の価値を補正する経路がない。
- 検討の結果：枠組みとして使える。ただし実験3の結果に合わせて一点を足す必要がある。
  - 他者用モジュールは、他者の行動の予測誤差（他者側の特徴予測の誤差）で学習するので、Suzuki らの行動予測誤差に当たる学習信号は与えられていた。
  - 実際にモジュールは予測の外れを大きく減らした（経験80% で、他者側の特徴予測の誤差が、生成した出力で 0.12〜0.15、本当の快・不快で 0.40〜0.42。v13 まとめ §4）。つまり補正は起きたが、価値の補正ではなく、位置・方角の手がかりを伝える形で起きた。
  - したがって書き方は「他者用モジュールも補正を学ばなかった」ではなく、「補正は他者の価値を直す形ではなく、予測に役立つ位置・方角の手がかりを伝える形で学ばれた」が正確。
- 発達の対応：Repacholi & Gopnik の 14か月児の自己中心的な反応と対応づける（18か月児の結果は引用の中心にしない）。
- 類推にとどめる。Tamir & Mitchell の調整は人の判断の過程についての主張で、本モデルの構成要素と一対一に対応するとは書かない。

## 12. 新しさの書き方（2026-10-26 4:20 確定）

1. 文献 [1] の新しさ：自分の経験が他者の予測に役立つこと自体ではなく、自他の対応（他者の動きを自分のどの経験に当てはめるか）を与えずに、重ね合わせから自他の区別・他者の位置・他者の視点・他者の運動が同時に生まれたこと。序論で文献 [1] を紹介するときはこれを新しさとして書く。
2. 本研究はその土台を引き継ぐが、自分の新しさとは書かない（視覚エンコーダを固定しているので、自他の対応は与えたもの）。
3. 本研究の新しさ：その対応に乗って価値に従う見込みが他者に運ばれることの、利点・代償・限界を一つのモデルで切り分けたこと。
   - 運ばれる。共有だけを外すと他者側だけが消えるので、運んでいるのは重ね合わせの共有そのもの。
   - 自分側の見込みは経験の量で段階的に強まり、それが共有を通して他者に当てはめられる（他者側に「段階的」とは書かない）。
   - 運ばれるからこそ、自分と違う他者には投影しすぎる。
   - 運ばれた見込みは使える（照合）が、他者用モジュールの補正は他者の価値を直す形ではなく、位置や方角の手がかりを伝える形で学ばれる。
4. Copete ら (2016) との違い：上の3に加えて、(a) Copete らは観察者と行為者が同じ視点を共有すると仮定して自他の対応を与えている（論文 II-B 節、自他の対応は VI 節で今後の課題）。重ね合わせでは対応は予測学習から生まれる（本研究では固定して用いる）。(b) 重ね合わせでは他者のための内部状態が別にあり、そこに自分の見込みが入り込むので投影がその場で起き、測れる。(c) 重みの共有だけを外す対照が作れる。
