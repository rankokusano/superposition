### 6.2 τ と区間の選び方への感度
- **τ**：
  - τ = 0〜2.0 で、$b_{\mathrm{dir}}$ の符号は変わらない。大きさは τ = 0 から 2.0 で 2〜4 割増える（oracle・経験80%：0.053 → 0.066、$c^{\pm}$・経験80%：0.056 → 0.080）。

- **区間**：

  - 前半の向きは A-2 の初期位置と相関する（−0.5 前後）。後半はほぼ無相関。

  - oracle 系列・FP の $b_{\mathrm{dir}}$ は、初期位置を足すと大半が消える（§4.3）。$c^{\pm}$ 系列と L1 は残る。

### 6.3 必要なエピソード数・組の数の目安（計算の根拠つき）
- **根拠**：
  - 組の中の SE は、エピソード数 N に対して $1/\sqrt N$ で縮むと仮定した。
  - 観察された $|b|$（組の平均）を、両側 α = 0.05・検出力 0.8 で 0 と区別するエピソード数の目安は $N_{80} = N_{\mathrm{used}}\,((1.96 + 0.84)\,\mathrm{SE}/|b|)^2$。
  - 組の数の目安は $P_{80} = ((1.96 + 0.84)\,\mathrm{SD}_{\mathrm{組}}/|\bar b|)^2$（正規近似、t の補正なし）。
  - 探索で選んで見た大きさなので、**楽観的**である（効果は小さく出直すことが多い）。
  - $P_{80}$ が 3 を下回るのは、正規近似のためで意味を持たない。t 分布では、少なくとも 3〜4 組が要る。

### 9.3 初期位置を入れた形での必要なエピソード数の目安（探索的（事前登録外）。判定基準は決めない）

#### 計算の根拠
- 式は §6.3 と同じ（§36.4 で決めたもの）。
  - $N_{80} = N_{\mathrm{used}}\,\big((1.96 + 0.84)\,\mathrm{SE}/|\bar b|\big)^2$。
  - $P_{80} = \big((1.96 + 0.84)\,\mathrm{SD}_{\mathrm{組}}/|\bar b|\big)^2$。
- 各量の取り方：
  - $\bar b$：6 組（または 5・3 組）の平均。
  - SE：組の中のエピソードのブートストラップ（1000 回）の SD を、組で平均したもの。$N_{\mathrm{used}}$ 個のエピソードでの、1 つのモデルの係数の標本誤差にあたる。
  - SD$_{組}$：組の値の標準偏差。
- 仮定：
  - SE はエピソード数 N に対して $1/\sqrt N$ で縮む。
  - 段階Bのデータでも、説明変数の分布と相関（向きと初期位置の相関 −0.56、VIF 2.25）が同じ。相関が強くなれば SE は大きくなり、弱くなれば小さくなる。
  - $N_{80}$ は 1 つのモデル（1 組）で 0 と区別するエピソード数で、組を平均する効果は入れていない（§6.3 と同じ）。
- 注意：
  - 探索で見た大きさなので**楽観的**。
  - $|\bar b|$ が 0 に近い行（t CI が 0 を含む）の $N_{80}$ は、「観察した大きさが本当なら」の値にすぎない。効果があることを意味しない。
  - 主の形と符号が逆になった行の $N_{80}$ は、逆の符号の効果を 0 と区別する数（表に印を付けた）。
  - $P_{80}$ が 3 を下回る値は意味を持たない（t 分布では少なくとも 3〜4 組が要る）。
