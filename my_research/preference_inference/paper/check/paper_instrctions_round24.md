# Claude Code 指示書 第24弾：「自分を出発点にして、他者を見て直す」学ばせ方は作れるか（下調べ，学習なし）

- 作成：2026-11-07
- 宛先：追加実験の方（Claude Code の実験チャット）


## 背景と目的

第21〜23弾で、次のことが分かりました。
- 自己の経路は、入れ替えの後に赤の新しい場所への動きを予測した（経験に依存）。
- 他者の経路が快・不快を他者の動きの予測に使っているとは言えなかった。学習の間、他者の経路に快・不快は一度も入らない。

次の段階の候補として、次の学ばせ方を先生に相談しています（返事待ち）。

- **学ばせ方：** エピソードの途中の入れ替えを、検査だけでなく学習にも入れる。その場面で他者を見ながら、予測の外れだけで他者の側（生成器と、他者の経路の入口）を学ばせ直す。他者の好みは教えない。
- **比べること：** 出発点の予測器（経験なし・経験50%・符号無作為（経験50%））によって、他者の好きな物に結びつけた予測が、少ない観察でどれだけ早く身につくか。
- **学ばせる範囲（案）：**
  - 段1：共有の LSTM は固定し、他者の側の入口の小さな層と生成器だけを学ばせる。
  - 段2：共有の LSTM も学ばせる。

今回は、先生の返事を待つ間に、この学ばせ方が**作れるか**と、**学ぶための手がかりが足りるか**を、学習なしで確かめます。学習そのものは、先生の了承の後に別の指示書で行います。

## 決まり

- **学習はしません。** ただし、時間の見積もりのための短い試し（数十ステップ）は行ってよいです。試しの重みと値は結果として使わず、保存もしません。
- 位置づけは**探索・事前登録外**です。
- GPU は GPU1〜3 を使います（GPU0 は使いません）。
- コミットは pull してから、ファイルを名前で指定して行います（`git add -A` は使いません）。
- 既存の結果・予測器・生成器・論文の本文は変えません。新しいコードは新しいファイルにします。
- **進め方：** §1 から順に進めてください。§1.1 か §1.3 ができないと分かったら、そこで報告して止まってください。

## §1 作れるか

### 1.1 学習用の入れ替えのデータ
1. 段階II（生成器の学習）のデータの作り方に、エピソードの途中で赤と緑を入れ替える場面を入れられるか。第20弾の入れ替えの仕組みを使えるか。
2. 入れ替えの時点（固定か、範囲の中で乱数か）と、入れ替えのある回の割合を設定できるか。
3. 入れ替えの後、A-2 の動きの規則は、**今の**色の配置に従うか（好きな色の新しい場所へ向かうか）。古い場所へ向かうことはないか。コードで確かめ、数エピソードの画像でも確かめてください。
4. A-2 の好み（赤好き・緑好き）は、今の段階IIと同じく両方作れるか。

### 1.2 学ぶための手がかりは足りるか（データだけの計算）
入れ替えのある回で、他者の好みを知らないと予測が当たらない時点がどれくらいあるかを数えます。

- **数える時点：** 入れ替えの後、A-2 が動いた時点のうち、その動きが「好きな色の新しい場所に近づく」かつ「古い場所からは遠ざかる（または近づかない）」もの。場所の習慣では外れ、好きな物の規則では当たる時点です。
- **出すもの：**
  - 1エピソードあたりの数と、全時点に占める割合
  - 段階IIの1エポックあたりの数（入れ替えのある回の割合ごと）
  - 入れ替えの後、A-2 が新しい場所に着くまでの歩数の分布（着かない回の割合も）
- **設定：** A-2 の規則の強さは今の 0.5 と、第20弾の 0.8 の両方。入れ替えの時点は2〜3通り（例：$t=20$・$50$・範囲の中で乱数）。
- 0.5 で手がかりが極端に少ない場合は、そう書いてください。0.8 に変えることの影響（元の段階Iの学習データとの違い）も一言添えてください。

### 1.3 学ばせる部分を分けられるか
1. 予測器の重みを、次の三つに分けて一覧にしてください（名前・形・数）。
   - 自己の経路だけが使うもの
   - 他者の経路だけが使うもの
   - 共有のもの（LSTM など）
2. 他者の経路の快・不快の入力（生成器の出力が入る欄）が LSTM に入るまでの道筋を書いてください。
3. **段1の形：** 共有の部分を固定し、他者の経路の快・不快の入力の後に小さな層（例：8→8 の線形層、または 8→16→8。初めは恒等写像と同じになるようにする）を足して、そこと生成器だけに勾配が流れるようにできるか。
   - 勾配が、足した層と生成器にだけ流れ、ほかの重みには流れないことを確かめてください。
   - 足した層を恒等写像で始めたとき、今の予測器・生成器の出力とビット単位（または数値誤差の範囲）で同じになるかも確かめてください。
4. **段2の形：** 共有の LSTM も学ばせる場合に、自己の予測（A-1 の次の視界）が壊れないようにする方法として、何が使えそうか（自己の予測の損失を同時に入れる、学習率を下げる、など）。案だけで構いません。

### 1.4 損失
1. 学ばせ直すときの損失は、今の段階IIの損失（A-1 の視界の L1・他者の視点の特徴など）をそのまま使えるか。
2. 損失のどこにも、A-2 の本当の快・不快や好みのラベルが入っていないことを確かめてください。

### 1.5 評価
「少ない観察でどれだけ早く身につくか」を測るために、学習の途中の重みで、次の検査を回せるかを確かめます。
1. 第20弾のデータ（A-2 が入れ替えの前に好きな色の方へ動く。$p_{\mathrm{rule}}=0.8$、$T_s=50$）で、第21弾と同じく入れ替えの後に入力を止め、予測画像の中の A-2 が $L_{\mathrm{new}}$ と $L_{\mathrm{old}}$ のどちらへ向かうか（$C_{\mathrm{other}}$）を測れるか。
   - 第21弾との違い：他者の経路への入力は、A-2 の視界から計算した値ではなく、**生成器の出力**にする。生成器は入れ替えの前の A-2 の動きを見ているので、好みを読み取れていれば、それが入力に表れるはず。
   - 赤好き・緑好きの A-2 の両方で測れるか。
2. 予測画像の読み出しが A-2 の実際の動きを読めることは、第23弾で確かめ済み（0.80〜0.84）。同じ読み出しを使ってください。
3. 1回の評価にかかる時間。

### 1.6 時間の見積もり
- 段1・段2 それぞれで、1エポックにかかる時間（短い試しから見積もる）と、1枚の GPU に同時に載るモデルの数。
- 条件（経験なし・経験50%・符号無作為）× 組1〜6 × 2段 で、学習と途中の評価を合わせた全体の時間の見積もり。GPU1〜3 を使う前提で。

### 1.7 そのほか
- 入れ替えの場面でも、赤と緑の箱は左の壁の2隅にあり、快・不快が入るのは範囲 0・1・6・7 だけ、で合っているか。

## §2 出発点の値（学習なし）

今の予測器と、今の生成器（段階IIの最終の重み）のままで、§1.5 の検査を行ってください。これは学習曲線の「0回目」の値になります。

- **条件：** 経験なし・経験50%・符号無作為（経験50%）・経験80%（記述）、組1〜6。A-2 は赤好き・緑好きの両方。
- **出すもの：** $C_{\mathrm{other}}$（生成器の出力を入れたとき）と、2種類の CI（6組の $t$ の 95% CI、2段のブートストラップ（組とエピソード、1000回））。読めた割合。
- **並べるもの：** 第21弾の $C_{\mathrm{other}}$（A-2 の視界から計算した入力）と、零入力。
- **予想：** 第21〜23弾から、どの条件でも ≈0 と予想しています。≈0 でない場合は、そのまま書いてください。
