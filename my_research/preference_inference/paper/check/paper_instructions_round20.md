# Claude Code 指示書 第20弾：途中で赤と緑を入れ替える検査（Woodward 型，学習なし）

- 作成：2026-11-06
- 宛先：追加実験の方（Claude Code の実験チャット）
- 保存：第19弾までの指示書と同じ場所に、同じ名前の付け方で保存してからコミットしてください。

## 目的

先生の了承のもとで、今後の研究の候補A（好みを知らないと予測が当たらない課題で、自分の経験が「好きな物に結びつけた他者の予測」を生むか）の最初の一歩として、**今のモデルが場所と好きな物のどちらに結びつけるか**を、学習なしで確かめます。

形は、乳児の Woodward (1998) や BIB（Gandhi et al. 2021）の検査と同じです。

1. 他者（A-2）が好きな色の方へ向かうのを見せる。
2. 途中で赤と緑の位置を入れ替える。
3. その後に A-2 が向かう先を2通り作る。
   - **新しい場所へ行く（N）：** 好きな色の新しい位置へ向かう。好きな物に結びつけた予測なら、こちらの驚きが小さい。
   - **古い場所へ行く（O）：** 前に向かっていた場所（今は嫌いな色）へ向かう。場所に結びつけた予測なら、こちらの驚きが小さい。
4. 予測器の驚き（予測誤差）を2通りで比べる。

## 決まり

- **学習はしません。** 既存の予測器（段階I）と生成器（段階II）を固定して評価だけ行います。新しく作るのは評価データだけです。
- 他者の好みを学習の教師にしません（ORIGIN-01）。好みは、データの作成と採点にだけ使います。
- 位置づけは**探索・事前登録外**です。§2 の手順と読み方の表は、計算の前にコミットし、その後で変えません。
- GPU は GPU1〜3 を使います（GPU0 は使いません）。草野さんの指示で変える場合があります。
- コミットは pull してから、ファイルを名前で指定して行います（`git add -A` は使いません）。
- 既存の結果・事前登録・論文の本文は変えません。
- **進め方：** §1 の確認で止まる条件に当たらなければ、§2 の手順をコミットしてから計算に進んでください。止まる条件に当たったときだけ、報告して止まってください。

## §1 評価データを作り、確かめる

### 1.1 データの作り方

第19弾 §1 の4の変更を使います。

- **場とモデル：** 今と同じアリーナ、基準エンコーダ、予測器と生成器。
- **エピソード：** 600。
  - A-2 の好き（赤・緑）× 配置（入れ替え前の赤と緑の位置）の4セルに 150 ずつ。
  - 乱数の鍵は新しくし、今までのデータと重ならないようにする。
- **前半（慣らし）：** $t=0$〜$T_s-1$。
  - A-2 は今の規則で、好きな色の方へ向かう。$T_s=50$ を主とする。
  - 慣らしの手がかりを強くするため、規則を試す確率は `p_rule` = 0.8 を主とする（0.5 は記述）。
  - A-1 は今の評価と同じくランダムに動く。A-1 の軌跡は、N と O で同じにする。
- **入れ替え：** $t=T_s$ で赤と緑の位置を入れ替える。
- **後半：** $t=T_s$〜$T_s+K-1$（$K=30$）。A-2 の動きを次の2通りで作る。前半は、両方とも同じ乱数で、ビット単位で同じにする。
  - **N（新しい場所へ）：** 今の規則のまま（入れ替えた後の視界の好きな色へ向かう）。
  - **O（古い場所へ）：** A-2 の方策に渡す視界だけを、入れ替える前の配置で描き直す（前の場所へ向かう）。
  - **規則を試す確率：** 後半は両方とも 1.0 にする（向かう先をはっきりさせるため）。
  - **後半の動きの量：** N と O で、A-2 の後半の移動距離をそろえる。そろわない場合は、その差を報告する。
- **対照（入れ替えなし）：** 同じ前半のまま入れ替えをせず、後半を次の2通りで作る。
  - 好きな色へ向かう（S）
  - 反対の色へ向かう（R）

  入れ替えのない場面で、予測器が「好きな色へ向かう」動きを予測しやすいかを測る基準になる。

### 1.2 確かめること（止まる条件）

1. **前半が同じか：** N と O（と S・R）の前半が、視界・位置・快・不快までビット単位で同じか。
2. **入れ替えが起きているか：** $t=T_s$ で赤と緑の位置が入れ替わっているか。少数のエピソードの画像を保存し、目で確かめる。
3. **向かう先が違うか：** 後半で、N の A-2 が好きな色の新しい位置へ、O の A-2 が古い位置へ近づいているか。後半の最後の、目標までの距離の分布で確かめる。
4. **既存の評価との一致：** 入れ替えのない前半の部分で、既存の評価のコードと同じ損失が出るか（段階Bと同じ流し方で、少数のエピソード）。

1〜4 のどれかが成り立たなければ、報告して止まってください。

## §2 評価の手順（計算の前にコミットする）

### 2.1 予測器への入力（視覚の見せ方）

今の評価は最初の1枚の後に視覚を入れないので、そのままでは予測器が入れ替えを見ません。そこで、視覚の見せ方を3通りにします。

- **V1（主）：** $t=0$ と、入れ替えの直後の $t=T_s$〜$T_s+2$ の3枚だけ見せる。ほかの時点は隠す。
- **V2：** 視覚を毎時点見せる。
- **V0（対照）：** $t=0$ だけ見せる（予測器は入れ替えを見ない）。

### 2.2 他者用の経路に入れる快・不快

| 記号 | 中身 | 何が分かるか |
|---|---|---|
| G | 主の生成器の出力。生成器は毎時点、本当の視界を受け取る | 今のシステム全体が、場所と好きな物のどちらに結びつけるか |
| T | A-2 の本当の視界から計算した本当の快・不快 | 正しい好みの信号を与えたとき、予測器がそれを使って新しい場所への動きを予測できるか（分からないこと3） |
| Z | 零 | 快・不快なしの基準 |

### 2.3 モデル

- **予測器：** 経験50%・経験なし・符号無作為（経験50%）、組1〜6。G は組1〜4（主の生成器と学習前）。
- **チェックポイント：**
  - T・Z の流し方は、段階Bと同じ（MSE 期間の最終5点）。
  - G の流し方は、段階Cと同じ。
  - 他者の視点の特徴の誤差は MSE 期間、予測画像を使う量は L1 期間とする。

### 2.4 量

**驚き：** 他者の視点の特徴の予測誤差（他者特徴の誤差、FP2）を、後半の評価区間で平均したもの。評価区間は $t=T_s+3$〜$T_s+K-1$（視覚を見せた直後の数枚を除く）とする。

| 記号 | 定義 | 読み方 |
|---|---|---|
| $D_{\mathrm{swap}}$ | 驚き(O) − 驚き(N) | **主に見る量。** 正なら、古い場所へ行く方に驚く（好きな物に結びつけた予測）。負なら、新しい場所へ行く方に驚く（場所に結びつけた予測） |
| $D_{\mathrm{noswap}}$ | 驚き(R) − 驚き(S) | 入れ替えのない場面で、好きな色へ向かう動きの方を予測しやすいか |
| 自己の誤差 | A-1 の次の視界の誤差 | 入れ替えによる乱れの記述 |
| 追跡の乱れ | 自己位置の追跡を、入れ替えの前後で入れ替えなしと比べる | 入れ替えによる乱れの記述 |

- 自己の誤差と追跡の乱れは、V1・V2 で求める。
- 組の値は、最終5点の平均。
- CI は、6組（G は4組）の $t$ の 95% CI と、2段のブートストラップ（組とエピソード、1000回）の CI。
- 比べるもの：
  - 経験50% と、「経験50% − 経験なし」「経験50% − 符号無作為」。
  - 入力 G・T・Z ごと、視覚の見せ方 V1・V2・V0 ごと。
  - A-2 の赤好き・緑好き別も出す。
- **主の組み合わせ：** 経験50%・入力 G・V1・`p_rule` 0.8・$T_s=50$。ほかは記述として出す。

### 2.5 読み方の表（計算の前に固定する）

| 結果の形 | 読み方 |
|---|---|
| $D_{\mathrm{swap}}<0$（CI が0を含まない） | 場所に結びつけた予測。BIB の深層モデルと同じ失敗。候補A の出発点の結果 |
| $D_{\mathrm{swap}}\approx0$ で $D_{\mathrm{noswap}}>0$ | 入れ替えのない場面では好きな色への動きを予測するが、入れ替えの後はどちらとも決めていない |
| $D_{\mathrm{swap}}>0$（CI が0を含まない）で、経験50%の方が経験なし・符号無作為より大きい | 好きな物に結びつけた予測で、自分の価値の経験に依存する。予想していない結果なので、確かめ直してから読む |
| 入力 T で $D_{\mathrm{swap}}>0$、入力 G で $\le0$ | 正しい好みの信号を与えれば予測器は新しい場所への動きを予測できるが、生成器はその信号を作っていない |
| V0 と V1 で $D_{\mathrm{swap}}$ が同じ | 予測器は入れ替えを見ても予測を変えていない（入れ替えに鈍い） |

- 追跡の乱れが大きい場合（入れ替えなしとの差が、入れ替えの前の追跡の誤差の2倍以上）は、$D_{\mathrm{swap}}$ の読みに「追跡が乱れている」と添える。
- どの形でも、原因を確定したとは書かない。
