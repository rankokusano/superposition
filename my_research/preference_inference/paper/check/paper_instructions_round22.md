# Claude Code 指示書 第22弾：他者の経路は快・不快の向きを使うか（測り方の感度と経験80%，学習なし）

- 作成：2026-11-06

## 背景と目的

第21弾（§45）で、次のことが分かりました。

- 自己の経路：入れ替えの後、赤の新しい場所への動きを予測した（$C_{\mathrm{self}}$ +0.249）。
- 他者の経路：同じ予測は見えなかった（$C_{\mathrm{other}}$ +0.025、≈0）。

ただし、実験の方の推測にあるとおり、他者の経路の量が鈍かった可能性があります。
- 入れ替えなしでも $\Delta_{\mathrm{other}}$ は ≈0 だった（+0.028）。
- 同じデータの G5b は +0.175 で正だった。

今回は、他者の経路が快・不快の向きを使っているかを、測り方を変えて確かめます。実験1で他者側の応答が確立した経験80%の予測器も含めます。

- 他者の経路が快・不快の向きを使っていると分かった場合：次の段階（生成器の学習）の考え方が変わる。
- 使っていないと確かめられた場合：つまずきは他者の経路にあると言える。

## §1 確認

1. 第21弾の保存した結果から、次をそのまま読み出せるか。
   - 他者の経路の $\Delta$（入れ替えあり・なし × 保つ・反転・零）
   - 自己の経路の $\Delta$（同じ組み合わせ）
2. 第21弾の流し方で、経験80%・符号無作為（経験80%）の予測器（組1〜6）を流せるか。
3. 他者の経路に入れる快・不快の大きさが、自己の経路に入れた快・不快の大きさと比べてどのくらいか。範囲ごとの値の平均と最大で比べる。
4. 止まる条件：1 または 2 ができない。

## §2 手順（計算の前にコミットする）

### 2.1 保存した結果からの読み出し（計算なし）

入れ替えなしで、他者の経路の「保つ − 反転」の $\Delta$ を求めます。快・不快の正負で、予測の中の A-2 が向かう向きが変わるかを見るためです。自己の経路の同じ量と並べます。条件は経験50%・経験なし・符号無作為（経験50%）です。

### 2.2 経験80%の予測器

第21弾と同じ流し方・同じ量で、次を求めます。
- $C_{\mathrm{self}}$、$C_{\mathrm{other}}$
- 「保つ − 反転」の $\Delta$
- 対象：経験80%・符号無作為（経験80%）（組1〜6）
- 比べるもの：経験80% − 符号無作為（経験80%）、経験80% − 経験なし

### 2.3 他者の経路への入力を強める・形を変える

経験50%と経験80%で、次の入力の $C_{\mathrm{other}}$ を求めます。

| 記号 | 入力 |
|---|---|
| X1 | 第21弾と同じ入力（A-2 の視界から計算した「赤が好き」とした快・不快）の2倍・4倍。範囲 $(-1,1)$ に切り詰め、切り詰めの割合を報告する |
| X2 | 自己の経路に入れた快・不快と、大きさをそろえた入力（範囲ごとの値の平均が自己と同じになるように拡大） |
| X3 | G5b と同じ形の入力（一つの範囲に $+0.28$）を、$L_{\mathrm{new}}$ の方角の範囲と $L_{\mathrm{old}}$ の方角の範囲にそれぞれ入れ、予測の中の A-2 のずれを比べる |

### 2.4 読み出しの方法を変える（できれば）

予測画像から A-2 の位置を読む代わりに、他者の視点の特徴の空間で比べます。
- 予測した他者の視点の特徴を、「A-2 が $L_{\mathrm{new}}$ の方へ $d$ 歩動いた視界」の特徴と「$L_{\mathrm{old}}$ の方へ $d$ 歩動いた視界」の特徴と比べる。
- 自己の $s_X$ と同じ考え方。
- 照合する視界を作れる場合だけ行い、作れなければ「未実施」と書く。

### 2.5 読み方の表（計算の前に固定する）

| 結果の形 | 読み方 |
|---|---|
| 入れ替えなしで、他者の「保つ − 反転」が自己と同じ向きで、0を含まない。かつ、どれかの入力で $C_{\mathrm{other}}>0$ | 他者の経路も快・不快の向きを使っている。第21弾の $C_{\mathrm{other}}\approx0$ は、測り方や入力の大きさによる |
| 経験80%でだけ $C_{\mathrm{other}}>0$ | 他者の経路への流用は、自己の規則が強いとき（経験80%）にだけ起きる。実験1の H1b の結果と合う |
| どの条件・入力でも、他者の「保つ − 反転」と $C_{\mathrm{other}}$ が ≈0 | 他者の経路は快・不快の向きを使っていない。つまずきは他者の経路にある |
| 入力を強めたときだけ $C_{\mathrm{other}}>0$ | 他者の経路は快・不快に弱くしか応答しない。入口の大きさが問題 |

- 経験80%は、自己位置の追跡の前提を満たさない。結果にはそのことを添える。
- どの形でも、原因を確定したとは書かない。
