# Claude Code 指示書 第31弾：元論文と同じ形で、他者の視界の復号を確かめ直す（学習なし）

- 作成：2026-11-09
- 宛先：追加実験の方（Claude Code の実験チャット）


## 背景と目的

第30弾（§54.3）の §2 では、既存の復号器でエンコーダ2の特徴を画像に戻すと、次のようになりました。
- 箱の位置は A-2 の視界に近い。
- 赤と緑の箱が同じ黄土色になる。

ただ、論文の会話の側の指示書に不備がありました。§2 (a) を「A-2 の実際の視界をエンコーダ2に通した特徴」と書いていましたが、元論文（Noguchi et al. 2022）の使い方は次のとおりです。
- エンコーダ2に入れるのは **A-1 の視界**。
- エンコーダ1の特徴で学んだ復号器を、エンコーダ2の特徴に当てる。
- 戻した画像を A-2 の実際の視界と比べる（画素の差の絶対値の平均。Fig. 5d・5e）。
- 評価の配置は、A-1・A-2 を [−9, 9] の整数の座標のすべての組み合わせに置いたもの。

今回は元論文と同じ形で確かめ直し、次の二つを分けます。
- 視点の取り方（どこに何があるか）は、元論文の主張どおり再現しているか。
- 色の区別（赤と緑のどちらがどこにあるか）は残っているか。

問題が「私たちの再現」にあるのか、「元の作りそのもの」にあるのかを分けるためです。結果によって、好みの仕組みで過程2を使うか、「自分がその場所にいたら何が快いか」を自分の経験で学ぶ案に寄せるかを決めます。

## §2 手順（計算の前にコミットする）

### 2.1 データ
- **元論文と同じ配置：** A-1・A-2 を [−9, 9] の整数の座標のすべての組み合わせに置く（重なる配置は除く）。赤と緑の配置は2通りとも作る。A-1 の視界と A-2 の視界を描く。
- 配置の数が多すぎる場合は、無作為に間引いてよい（間引いた数を書く）。

### 2.2 元論文と同じ復号
- **予測器：** 段階I、経験50%・経験なし・符号無作為（経験50%）・経験80%、組1〜6。
- **手順：** A-1 の視界 → エンコーダ2 → 既存の復号器 → 画像（$\hat v^2$）。比べるために、A-1 の視界 → エンコーダ1 → 復号器 → 画像（$\hat v^1$）も作る。

### 2.3 量
1. **元論文の量（画素の差）：**
   - $d(\hat v^2, v^2)$：戻した画像と A-2 の実際の視界の差。
   - $d(\hat v^2, v^1)$：戻した画像と A-1 の実際の視界の差。
   - $d(\hat v^1, v^1)$：自分の視界の作り直しの差（復号器の質）。
   - 元論文の主張どおりなら、$d(\hat v^2, v^2) < d(\hat v^2, v^1)$。
2. **位置の量（色を区別しない）：** 範囲ごとの「色の付いた箱の画素の量」（赤と緑を区別しない）を、$\hat v^2$ と $v^2$ で比べた相関。
3. **色の量：** 範囲ごとの「赤 − 緑」を、$\hat v^2$ と $v^2$ で比べた相関。戻した画像は色がずれることがあるので、次の2通りで出す。
   - 自己の快・不快と同じ閾値の計算
   - 閾値を使わない連続の量（範囲ごとの（R チャンネル − G チャンネル）の平均など）
- 範囲0・1・6・7 を主にし、全範囲も出す。

### 2.4 色の情報がエンコーダ2の特徴にあるか（診断の読み出し）
- エンコーダ2の特徴（A-1 の視界から）→ A-2 の視界の範囲ごとの「赤 − 緑」の線形の読み出しを、配置の半分で学び、残りの半分で評価する（相関と $R^2$）。
- 比べるもの：エンコーダ2の特徴 → 「色の付いた箱の画素の量」（位置の量）の同じ読み出し。
- これは「情報があるか」を見る診断で、答えのラベルを使う。仕組みには使わない。

### 2.5 CI
6組の $t$ の 95% CI と、ブートストラップ（組と配置、1000回）。

### 2.6 読み方の表（計算の前に固定）

| 結果（経験50%） | 読み方 |
|---|---|
| $d(\hat v^2, v^2) < d(\hat v^2, v^1)$ で、位置の量も色の量も高い（目安 0.7 以上） | 元論文と同じ形なら、他者から見た色の区別まで戻せる。第30弾の結果は使い方の違いによる。過程2を使って②を作る道が残る |
| $d(\hat v^2, v^2) < d(\hat v^2, v^1)$ で位置の量は高いが、色の量は低い。§2.4 の色の読み出しは高い | 視点の取り方は再現している。色の情報はエンコーダ2の特徴にあるが、エンコーダ1の形ではないので、元の復号器では戻せない |
| 同上で、§2.4 の色の読み出しも低い | 視点の取り方は再現しているが、他者から見た色の区別はエンコーダ2の特徴にほとんどない。この作りでは、他者から見て好きな色がどこにあるかを持てない |
| $d(\hat v^2, v^2) \ge d(\hat v^2, v^1)$、または位置の量も低い | 私たちの予測器は、元論文の視点の取り方を再現していない。段階Iの学習を確かめ直す必要がある |

- 経験なし・符号無作為・経験80% も同じ形かを記述する。
- §1-5 で元論文の値が読み取れた場合は、$d$ の値を並べて書く。
- どの形でも、原因を確定したとは書かない。
