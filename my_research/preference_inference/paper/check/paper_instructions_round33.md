# Claude Code 指示書 第33弾（案A）：他者の快・不快の作り方を比べる（内部状態の共有・位置で学ぶ・幾何）

- 作成：2026-11-12
- 宛先：追加実験の方（Claude Code の実験チャット。案Aの続き）


## 背景と目的

案Aの②（他者の快・不快）は、「ŵ × 他者から見た赤 − 緑（範囲ごと）」で作ります。第29〜32弾で、次の二つの道では「他者から見た赤 − 緑」を作れないと分かりました。
- 特徴の空間（エンコーダ1の読み出しをエンコーダ2に当てる）
- 画像の空間（エンコーダ2 → 復号器）。重みの減衰が強いと色が消え、弱いと他者の視点の画像が崩れる。

残る三つの作り方を、同じ評価データで比べます。どれも、学ぶときは**自分の経験だけ**を使い、他者の答えは評価にだけ使います。

| 案 | 自分の経験で学ぶもの | 他者に当てるとき |
|---|---|---|
| 1 内部状態の共有 | 自分の状態 $h^1$ → 自分の快・不快 の読み出し R | 同じ R を他者の状態 $h^2$ に当てる |
| 2 位置で学ぶ | 自分の位置と色の配置 → 自分の快・不快 の地図 M | 同じ M を A-2 の位置と色の配置に当てる |
| 3 幾何（予備） | なし | A-2 と箱の位置から式で計算（第30弾 §3） |

案1は、元論文の「自他で同じ仕組みを使う」をそのまま価値に広げる形で、うまくいけば手作りの部分がありません。結果で②の作り方を決めます。

## 決まり

- 位置づけは**探索・事前登録外**です。§2 の手順と読み方の表は、計算の前にコミットし、その後で変えません。
- 学習は、読み出し R と地図 M（小さな線形のものと小さな網）だけです。予測器の重みは変えません。
- **R と M の学習に使うのは A-1 自身の情報だけ**です（自分の状態・自分の位置・自分の視界から決めた色の配置・自分の快・不快）。A-2 の情報は評価にだけ使います。ただし §2.4 の診断の読み出しだけは、情報があるかを見るために A-2 の答えを使います（仕組みには使いません）。
- GPU は GPU1〜3 を使います（GPU0 は使いません）。
- コミットは pull してから、ファイルを名前で指定して行います（`git add -A` は使いません）。
- **既存のものは変えず、消さず、上書きしません。** 出力はすべて新しい場所（例：`data/result/paper_extra/Round33/`）に置きます。計算の前後で既存のもののチェックサムを取り、変わっていないことを確かめてください。
- **起動の確かめ：** 複数本を起動したら、数分後にすべての記録が進んでいることを確かめてください。
- **進め方：** §1 → §2（手順と表をコミット）→ 計算 → §3 で報告して止まってください。

## §1 事実の確かめ（コードと記録から、計算なし）

1. 段階Iで、過程1と過程2のそれぞれに入っていたもの（視覚・運動・快不快）と、そのときの入れ方。特に、過程2に毎時点エンコーダ2の特徴が入っていたか。
2. 過程1に自分の快・不快が入力として入る時点で、$h^1$ がその入力の写しを持ってしまう可能性。R の学習で「入力の写しを読むだけ」にならないための扱い（§2.2 の (i)・(ii)）が、コードの上でできるか。
3. 自分の位置・A-2 の位置・色の配置（赤がどちらの隅か）が、データに記録されているか。
4. 自分の視界から色の配置を読む方法（第30弾 §3 で配置を 98% 読めた方法）を使えるか。

## §2 手順（計算の前にコミットする）

### 2.1 評価データ（三つの案で共通）
- **(b) 観察中：** 段階Iと同じ流し方（過程2には毎時点エンコーダ2の特徴が入る、運動と快・不快は0）。入れ替えのない回。
- **(c) 入れ替えの後に入力を止める：** 第21弾と同じ形（入れ替え、直後の3枚を見せてから 15 歩止める）。止めている間の各時点で評価する。
- 正解（評価だけに使う）：各時点の A-2 の視界から計算した範囲ごとの「赤 − 緑」。
- 予測器：経験50% を主にし、経験なし・符号無作為（経験50%）・経験80% も行う。組1〜6。

### 2.2 案1：内部状態の共有
- **R の学習（自分の経験だけ）：** 段階Iのデータで、各時点の $h^1_t$ → その時点の自分の快・不快（8範囲）。線形のものと、小さな網（例：128 → 64 → 8）。
- **入力の写しを避ける扱い（2通り）：**
  - (i) 自分の快・不快の入力を0にして過程1を流し直した $h^1$ で学ぶ（過程2も快・不快の入力は0なので、自他でそろう）。
  - (ii) $h^1_t$ から**次の時点**の自分の快・不快 $p^1_{t+1}$ を読む（入力の写しでは当てられない向きにする）。
  - 経験なしの予測器では快・不快の入力がもともと0なので、(i) と同じになる。
- **他者に当てる：** 同じ R を $h^2_t$ に当て（(ii) なら $h^2_t$ から A-2 の次の時点の値と比べる）、正解と比べる。
- **自分の側の確かめ：** 自分の検証データでの R の当たり（自分の状態から自分の快・不快）。

### 2.3 案2：位置で学ぶ
- **M の学習（自分の経験だけ）：** 段階Iのデータで、（自分の位置 x, y、色の配置）→ 自分の快・不快（8範囲）。小さな網（例：3 → 64 → 64 → 8）。色の配置は自分の視界から読んだもの（§1-4）。
- **他者に当てる：** 同じ M に（A-2 の位置、色の配置）を入れる。A-2 の位置は次の2通り。
  - 本当の位置（上限）
  - A-1 の視界（観察中は実際の画像、止めている間は予測画像）から第30弾 §3 と同じ方法で見つけた位置
- 色の配置は、(c) では止めている間の予測画像から読んだもの（第30弾 §3 で 98%）。

### 2.4 診断：他者の状態に色の情報があるか（答えを使う）
- $h^2_t$ → A-2 から見た赤 − 緑 の線形の読み出しを、評価データの半分で学び、残りの半分で評価する。
- 案1で R が当たらなかったときに、「情報が $h^2$ にない」のか「あるが自分の読み出しと形が違う」のかを分けるため。

### 2.5 案3：幾何（比べる相手）
- 第30弾 §3 の方法を、同じ評価データ（(b)・(c)）で計算し直す。

### 2.6 量と CI
- 範囲0・1・6・7 の相関（主）と、全範囲。範囲ごとの値も。
- 6組の $t$ の 95% CI と、ブートストラップ（組とエピソード、1000回）。

### 2.7 読み方の表（計算の前に固定）

| 結果（経験50%、(b) 観察中、範囲0・1・6・7） | 読み方 |
|---|---|
| 案1（(i) か (ii) のどちらか）で 0.7 以上 | 自分の状態から快・不快を読む読み出しを、そのまま他者の状態に当てて他者の快・不快を作れる。②は案1で作る |
| 案1 は 0.7 未満で、§2.4 の診断が 0.7 以上 | 情報は他者の状態にあるが、自分の読み出しと形が違う。案2 か案3 を使う |
| 案1 も §2.4 も 0.7 未満 | 他者の状態に、他者から見た色の情報が十分にない。案2 か案3 を使う |
| 案2（見つけた位置）で 0.7 以上 | 「自分がその場所にいたら」を自分の経験で学ぶ形で作れる。案1 がだめなら②は案2 で作る |
| 案1・案2 とも 0.7 未満 | ②は案3（幾何）で作る |

- (c) 入力を止めた後の値は、三つの案について記述する。止める前の値を持ち越すかどうかは、論文の会話で決める。
- 経験なし・符号無作為・経験80% は記述する。案1 では、経験なしの予測器でも R が自分の状態に当たるかを書く（経験がない予測器では、そもそも快・不快を学んでいない）。
- どの形でも、原因を確定したとは書かない。
