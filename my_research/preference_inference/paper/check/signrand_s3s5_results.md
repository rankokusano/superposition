## 判定のまとめ

1. **全体の判定（主1，§3.2）：成り立った。** 共通の評価データの d_P と G5b の両方で、6 組の差の t の 95% CI（自由度 5）の上限が 0 を下回った。
   - d_P：−0.239 [−0.250, −0.228]、G5b：−0.362 [−0.521, −0.203]。6 組すべてで負（符号検定 p = 0.031）。
   - 副の 5 つ（共通の ①②、B4 の G5b・①②）も、CI はすべて 0 を含まず、6 組すべてで負。
2. **2 つの形（各モデルの平均の差／エピソードを対にした差）は食い違わなかった。** CI が 0 を含むかどうかも、組ごとの差の向きも、どの量でも同じだった。このため、事前登録の追記（「弱い方の結果に合わせて書く」）で選ぶ方は、どちらでも同じになる。
3. **組ごとの判定（5 点中 3 点で合格）は、すべての組で合格したわけではない。** 本文で組ごとの数を書くときは次の数を使う。
   - d_P：6/6
   - G5b：共通 5/6、B4 6/6
   - 符号に従う分 ①②：共通・B4 とも 5/6
   - 組4〜6 だけで見ると、どの量も §4.4 の規則（3 組中 2 組以上）を満たしている。
4. **不合格になった組**（除外はしていない）。外れたのはどちらも経験80% のモデルの側で、v13 の時点から記録されている。符号無作為のモデルの値は、6 組で同じ範囲にある。
   - 組4（s3）の符号に従う分 ①②：共通・B4 とも 0/5。この組の経験80% のモデルは符号にほとんど従わない（共通 +0.013 / +0.071、B4 +0.026 / +0.008）。
   - 組5（s4）の G5b（共通）：2/5。この組の経験80% の G5b は 6 組で最も小さい（+0.204）。
5. **真値条件 Δ（V2）**：組1〜3 と同じく、一部でしか成り立たない（緑好み 2/6、好み混合 3/6）。
6. **除外の扱い（事前登録外）**：補足資料 S5 と同じ作り（そのまま／(a)／(a3)／(b1)／(b2)）で、組ごとの合否も 6 組の CI も変わらなかった。
7. **組1〜3 だけの値との比較**：組1〜3 だけ（自由度 2）では、② と B4 の G5b の CI が 0 を含んでいた。6 組では含まない。
