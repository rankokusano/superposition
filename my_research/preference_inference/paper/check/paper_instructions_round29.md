# Claude Code 指示書 第29弾：新しい仕組み（行動の頻度から好みを推定し、自分の仕組みで他者の動きを作る）を作る前の確かめ

- 作成：2026-11-09
- 宛先：追加実験の方（Claude Code の実験チャット）


## 背景と目的

先生から、「できないことの分析」ではなく「うまくいく仕組み・設定」を作るよう指示がありました。あわせて、「観測者は他者の価値を行動の頻度でしか知ることができないので、行動の頻度を扱える仕組みにする」という手がかりをもらいました。

論文の会話では、次の仕組みを考えています（構造図：`claude/新しい仕組みの案と新規性の評価_2026-11-09.md`）。今の予測器（段階I、固定）に三つを足します。

1. **頻度の積み上げ：** A-2 がどの色の方へ何回動いたかを積み上げ、色ごとの好き度 ŵ を出す。
2. **他者の快・不快：** 自分の快・不快と同じ計算を、ŵ と「他者から見た色の方向」で行う。
3. **動きの模型：** 段階Iの自分の経験から「快・不快 → 次の自分の動き」を学び、他者に使う。その出力（他者の動き）を、**過程2の運動の欄**に入れる（元論文の Motion Generator と同じ入口）。過程2の快・不快の欄は使わない。

学び方は予測の外れだけで、好みのラベルも他者の行動のラベルも使いません。

今回は、これを作る前に、成り立つための四つの前提を確かめます。

## §0 事実の確かめ（コードと記録から、計算なし）

次のことを、コードで確かめて書いてください。
1. A-1 と A-2 の動き（行動）の表し方（離散の行動か、移動量か、回転を含むか）と、予測器の運動の欄への入れ方。A-2 の動きを、A-1 と同じ形で運動の欄に入れられるか。
2. A-2 の動きの規則（`p_rule` のときに何をするか、それ以外のときに何をするか）。
3. 段階Iの学習で、過程2の運動の欄に何が入っていたか（いつも 0 か）。過程1と過程2で、運動の欄の重みは同じか。
4. 元論文（Noguchi et al. 2022）のコードまたは本文で、Motion Generator の出力が過程2のどこに入り、何を動かしていたか（A-1 の視界の中の他者か、他者の視点の予測か）。手元にない場合は「確かめられない」と書いてください。
5. 段階Iの学習データ（経験なし・経験50%・経験80%・符号無作為）それぞれで、A-1 の動きの決め方と、自己の経路の快・不快の入力の有無。
6. 1エピソードの長さ。

## §1 過程2の運動の欄に動きを入れると、予測の中の A-2 は動くか（学習なし）

- **予測器：** 段階I、経験50%・経験なし・符号無作為（経験50%）・経験80%（記述）、組1〜6。
- **データ：** 第21弾と同じ形（A-2 は静止）。入れ替えはしない。
- **流し方：** 第21弾と同じく、ある時点から 15 ステップ、運動と視覚を止める。止めている間、過程2の運動の欄に、A-2 を方向 $d$ へ動かす動き（§0-1 の形）を入れる。
  - 方向 $d$：A-2 が動ける方向すべて（例：4方向）。
  - 対照：零の入力、反対の方向。
- **量：**
  - **(a) A-1 の視界の予測の中の A-2：** 第23弾で確かめた予測画像の読み出しで、A-2 が方向 $d$ へずれたか（$M_{\mathrm{img}}(d)$ = 方向 $d$ の入力でのずれ − 零の入力でのずれ、$d$ の向きに射影したもの）。
  - **(b) 他者の視点の予測：** 第22・23弾の特徴の照合で、予測した他者の視点の特徴が「A-2 が方向 $d$ へ $k$ 歩動いた視界」と「反対の方向へ $k$ 歩動いた視界」のどちらに近いか（$M_{\mathrm{feat}}(d)$）。
  - 方向ごとと、方向の平均を出す。
- **CI：** 6組の $t$ の 95% CI と、2段のブートストラップ（組とエピソード、1000回）。

**読み方の表（計算の前に固定）**

| 結果（経験50%、方向の平均） | 読み方 |
|---|---|
| $M_{\mathrm{img}}>0$（CI が0を含まない） | 運動の欄から入れた動きで、A-1 の視界の中の A-2 が動く。新しい仕組みの出力は運動の欄に入れ、検査は今までどおり予測画像で行える |
| $M_{\mathrm{img}}\approx0$、$M_{\mathrm{feat}}>0$ | 運動の欄の動きは、他者の視点の予測にだけ表れる。新しい仕組みの検査は他者の視点の予測で行う必要がある。A-1 の視界の中の A-2 を動かすには別の道が要る |
| どちらも ≈0 | 運動の欄からも、他者の動きを予測に入れられない。新しい仕組みの出口を考え直す必要がある |

- 経験なし・符号無作為でも同じ形かを記述する（運動の欄の重みは快・不快の経験と関係しないので、同じ形が予想される）。

## §2 「快・不快 → 次の自分の動き」を段階Iのデータから学べるか（小さな学習）

- **データ：** 段階Iの学習データ。経験50%・経験80%・経験なし・符号無作為（経験50%）。それぞれの検証の部分で評価する。
- **模型：** 入力は時点 $t$ の自己の快・不快（8範囲）。出力は時点 $t+1$ の A-1 の動き（§0-1 の形）。小さなネットワーク（例：8 → 32 → 動きの数）と、比べるための線形のもの。
- **量：**
  - 動きの正答率（離散の場合）または誤差。
  - 比べるもの：偶然の水準、動きの頻度だけで当てる水準、環境の規則から計算できる最良の水準（§0-2 の規則を知っているとしたときの正答率）。
  - 学んだ模型に、方向ごとに一つの範囲だけ快を入れたとき、その方向へ動く確率（反応の図）。
- 組（段階Iの組1〜6 のデータ）ごとに学び、6組の平均と CI を出す。

**読み方の表（計算の前に固定）**

| 結果 | 読み方 |
|---|---|
| 経験50%で、最良の水準に近く（差が最良と偶然の差の 2割以内）、偶然を明らかに上回る | ③は段階Iのデータから学べる |
| 偶然は上回るが、最良の水準から遠い | ③は学べるが弱い。入力（視界の特徴を足すなど）を考え直す |
| 偶然と変わらない | 段階Iのデータからは③を学べない |

- 経験なし・符号無作為は、偶然の水準か向きが逆になると予想される。そのまま書く。

## §3 他者から見た色の方向を、好みの答えを使わずに読み出せるか（小さな学習）

**考え方：** A-1 は赤が好きなので、自己の快・不快は「赤の画素 − 緑の画素」（範囲ごと）です。自分の視界の特徴からこれを読み出す線形の読み出しを、**自分の経験だけ**（自分の視界と自分の快・不快）で学びます。同じ読み出しを他者の視点の特徴に当てはめれば、「他者から見た赤 − 緑」が得られるはずです。他者の快・不快は、これに ŵ（赤好きなら +、緑好きなら −）を掛けて作れます。

- **読み出しの学習：** 経験50% の段階Iのデータで、A-1 の視界の特徴（過程1で使う形）→ 自己の快・不快（8範囲）の線形の読み出しを学ぶ。組1〜6。
- **評価（ラベルは評価だけに使う）：** その読み出しを次の二つに当てはめ、A-2 の視界から計算した本当の「赤 − 緑」（範囲ごと）と比べる。
  1. 実際の他者の視点の特徴（描画した A-2 の視界を同じエンコーダに通したもの）
  2. 過程2が予測した他者の視点の特徴
- **量：** 範囲ごとと全体の相関と $R^2$。範囲0・1・6・7 と範囲2〜5 を分けて出す。自分の視界での値（学習データの検証の部分）も並べる。
- 経験なし・符号無作為の予測器の特徴でも同じことをする（読み出しは予測器の特徴に依存するため）。

**読み方の表（計算の前に固定）**

| 結果（経験50%、範囲0・1・6・7） | 読み方 |
|---|---|
| 実際の他者の視点で相関が高く（目安 0.7 以上）、予測した他者の視点でも明らかに正 | 自分の経験だけで学んだ読み出しで、他者から見た色の方向が読める。②を作れる |
| 実際の他者の視点では高いが、予測した他者の視点では低い | 読み出しは他者にも使えるが、過程2の予測が足りない。②の入力は、観察した他者の視点の特徴にする必要がある |
| どちらも低い | 自分の経験だけの読み出しは他者の視点に移らない。別の作り方が要る |

## §4 何歩の観察で好みを見分けられるか（計算のみ、GPU なし）

- **理想の観察者：** A-2 の位置と箱の位置を正確に知り、§0-2 の規則も知っているとする。各歩で「赤好き」と「緑好き」の二つの仮説の尤度比を計算し、積み上げる。
- **データ：** 既存のデータの A-2 の実際の軌跡（段階IIのデータ `v11_s2_pref`、入れ替えなし）。`p_rule` 0.5 と、第20弾の 0.8。
- **量：**
  - 観察の歩数 $n$ ごとに、正しい好みを当てる割合（$n$ = 1, 2, 5, 10, 20, 50, 100, …, エピソードの長さ）。
  - 正答率 90%・95% に届く歩数の中央値と分布。
  - 1歩あたりの情報量（尤度比の対数の平均）。
  - A-2 が好きな色に着いた後（止まる・その場にいる）の歩が情報を持つかも分けて出す。
- **比べるもの：** エピソードの長さ（§0-6）。

**読み方の表（計算の前に固定）**

| 結果（`p_rule` 0.5） | 読み方 |
|---|---|
| 95% に届く歩数が、エピソードの長さの半分以下 | 1エピソードの中で好みを見分けられる。①は1エピソードの中の積み上げでよい |
| 届くのがエピソードの終わり近く、または届かない | 1エピソードでは足りない。同じ A-2 を何回か見せる（BIB 型）、または `p_rule` を上げる必要がある |
