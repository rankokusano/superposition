# Claude Code 指示書 第27弾：正しい好みの得はどこから来るか、最も緩い上限で検査の量は動くか

- 作成：2026-11-08
- 宛先：追加実験の方（Claude Code の実験チャット）


## 背景と目的

第26弾（§50.3）で、次のことが分かりました。
- 正しい好み（T）を入れると、逆の好み（W）より損失が下がる（経験50% の $S_{\mathrm{WT}}$：V +0.229、B +1.403）。得のほとんどは他者の視点の特徴の予測から来る。
- それでも、T を入れて足した層だけを学ばせても、検査の量 $D_T$ は 0 から動かない（組1〜3）。
- 段階Iのデータを半分混ぜると、共有の LSTM を学ばせても自己の規則（$C_{\mathrm{self}}$）は保たれる。

論文の会話では、「他者の経路は快・不快を『他者から何が見えるか』の予測には使うが、『A-1 の視界の中で A-2 がどこへ動くか』の予測には使っていない」可能性を考えています。今回は次の二つを行います。

1. **§1（学習なし）：** 正しい好みの得を、A-2 の好み別と損失の成分別に分けます。
2. **§2（短い学習）：** 最も緩い上限（答え T、視覚を止める B、足した層と共有の LSTM の両方を学ばせる、段階Iのデータを混ぜる）で、$D_T$ が動くかを見ます。

**区切りの規則（論文の会話で前もって決めたもの）：** §2 でも $D_T$ が動かなければ、この仕組みでは「自分を出発点にして、他者を見て直す」方向の学習は止め、ここまでの結果をまとめて先生に報告します。

## §1 正しい好みの得の内訳（学習なし）

- **もとの値：** 第26弾 §1 の計算。保存した値で分けられない場合は、同じ手順で計算し直してください（学習なし）。
- **条件：** 経験なし・経験50%・符号無作為（経験50%）・経験80%（記述）、組1〜6。V と B。入れ替えのある回と、ない回（対照）。
- **分け方：**
  1. **A-2 の好み別：** 赤好き・緑好き。
  2. **損失の成分別：** A-1 の視界の L1、他者の視点の特徴の項、そのほかの項。
  3. **A-1 の視界の中の場所別（できれば）：** A-2 が写っている周りの領域の L1 と、それ以外の L1。A-2 の位置は描画の情報から決めてください。決められない場合は「未実施」と書いてください。
- **量：** それぞれの $S_{\mathrm{WT}} = L(W) - L(T)$ と $S_{\mathrm{ZT}} = L(Z) - L(T)$。損失の大きさで割った値も出す。
- **CI：** 6組の $t$ の 95% CI と、2段のブートストラップ（組とエピソード、1000回）。

**読み方の表（計算の前に固定）**

| 結果（経験50%、B を主に見る） | 読み方 |
|---|---|
| 赤好きで $S_{\mathrm{WT}}>0$、緑好きで ≈0 か負 | 他者の経路は、快・不快を「快い方に赤が見える」という見え方の手がかりとして使っている（自己の好みの写し） |
| 赤好き・緑好きの両方で $S_{\mathrm{WT}}>0$ | 他者の経路は、快・不快を好みによらない形（快い方へ向かう、快い物が見える）で使っている |
| A-1 の視界の成分（または A-2 の周りの領域）の $S_{\mathrm{WT}}\approx0$ | 今の損失では、A-1 の視界の中の A-2 の予測は好みによらない。検査の量 $D$ を学ぶ信号が損失にない |
| A-1 の視界の成分（または A-2 の周りの領域）の $S_{\mathrm{WT}}>0$ | A-2 の位置の予測にも好みの信号はある。それが検査の量に表れない理由は別にある |

- 好み別と成分別の結果は、別々に表に当てはめる。
- 入れ替えのない回でも同じくらいの得が出る場合は、入れ替えと関係のない得として書く。
- 経験による違い（経験50% − 符号無作為、経験50% − 経験なし）は記述する。

## §2 最も緩い上限（短い学習）

- **出発点：** 第26弾 §2 の B の終わりの重み（足した層を学ばせたもの）。条件は経験なし・経験50%・符号無作為（経験50%）、組1〜3。
- **入力：** 生成器の代わりに T。範囲2〜5 は足した層の後で 0（M）。
- **データ：** 第25弾の学習用データを B の形にしたもの（第26弾 §2 と同じ）。
- **学ばせるもの：** 足した層と共有の LSTM。
- **段階Iのデータを混ぜる：** 第26弾 §3.2 と同じく、各バッチの半分を段階Iの学習データ（経験50%）にし、その半分の損失は段階Iの損失にする。
  - 経験なし・符号無作為の予測器でも、混ぜるのはそれぞれの段階Iの学習データにする。残っていない場合は、そう書いて、その条件は混ぜずに行う。
- **共有の LSTM の学習率：** ほかの学習率の 1/10（第26弾 §3.2 で自己の規則が保たれたもの）。
- **エポック：** 50。5エポックごと（0 エポック目を含む）に評価。
- **評価（第26弾 §2 と同じ）：**
  - $D_T(e) = C_{\mathrm{other}}(\text{T を足した層に通した入力}) - C_{\mathrm{other}}(Z)$。赤好き・緑好きを分けて出し、平均も出す。
  - 見張り：$C_{\mathrm{self}}$（保つ）、A-1 の視界の誤差。
  - §1 と同じ $S_{\mathrm{WT}}$（B、成分別）を、0 エポック目と 50 エポック目で出す。

**読み方の表（計算の前に固定）**

| 結果 | 読み方 |
|---|---|
| 経験50%で $D_T>0$（3組の平均で、2種類の CI のどちらも0を含まない） | 答えを入れ、共有の部分も学ばせれば、他者の経路は好みを他者の動きの予測に使えるようになる。次に、生成器がそれを担えるかを論文の会話で考える |
| どの条件でも $D_T\approx0$ | **区切りの規則に当たる。** 答えを与えても、この仕組みの他者の経路は、好みを A-1 の視界の中の他者の動きの予測に変えない。この方向の学習は止める |
| 経験なし・符号無作為でだけ $D_T>0$ | 自己の規則によらない経路で起きている。そのまま書く |
| 50 エポック目に $C_{\mathrm{self}}$ が始めの半分を下回る | 自己の規則が崩れたことを添える |

- 3組なので、経験による違いは記述にとどめる。
- 50 エポック目の成分別の $S_{\mathrm{WT}}$ で、A-1 の視界の成分が増えたかどうかも記述する。
