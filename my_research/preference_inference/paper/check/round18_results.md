## 4. 読み方の表のどの形に当たるか

**主（c±、向きを調整する形）は行1 に当たる。**
- 緑好きの $b^{\text{緑}}$ は +0.0420 で、両方の CI が 0 を含まない。6/6 の組が正。
- 赤好きの $b^{\text{赤}}$ は +0.0327 で、同じ程度（緑好きの方がやや大きい）。
- 全体の $b_{\mathrm{red}}$ は −0.0028 で、CI は 0 を含む。
- 読み：観察者が作れる候補での関連は、赤好きのエピソードの赤への偏りによるものではなく、緑好きでも好みの側に沿う（「整合する」の読みで、原因を確定したとは書かない）。
- 比較でも同じ形：
  - 経験50% − 経験なし：赤好き +0.0365・緑好き +0.0401
  - 経験50% − 符号無作為：赤好き +0.0417・緑好き +0.0376
  - どれも両方の CI が 0 を含まない。
- 行2・行3 は当たらない。$b^{\text{緑}}$ は 0 に近くも負でもなく、$b^{\text{赤}}$ より小さくもない。$b_{\mathrm{red}}$ も正ではない。
- 行4 は当たらない。
  - 向きを調整すると $b_{\mathrm{pref}}$ は小さくなる：赤好き 0.060 → 0.033、緑好き 0.061 → 0.042。
  - それでも、どちらも 0 に近くはない。
  - 向きとの重なりは好み別でも大きい。食い違う場面では、好みの色によらず向きの側を選ぶ（赤好き 0.335、緑好き 0.382）。
