## 8. 読み方の表（§40.3）のどの形に当たるか（経験50%、合計の損失）

- **行1（$R_1$ が小さい、かつ $S_{\mathrm{pos}}$ が大きく $S_{\mathrm{ax}}$ が小さい → 説明P・O と整合）：一部だけ当たる。**
  - $R_1/D_G$ は +3.8%・+6.5%・−1.3%・−8.7%（$s$ = 1, 2, 4, 7）。t の CI はどの $s$ でも 0 を含む。
  - $s=2$ の +6.5% は「数% 以下」の境目で、CI の上限は +20.8%。$s=7$ は負で、ブートストラップの CI は 0 を含まない。
  - $S_{\mathrm{ax}}$ は 0.14 で小さい。
  - $S_{\mathrm{pos}}$ は 0.48 で、$D_G$ の約半分。$S_{\mathrm{res}}$（0.48）と同じ大きさで、位置の成分だけが担うとは言えない。
- **行2（$R_1$ が正で無視できない → 説明D と整合）：当たらない。** $R_1$ が正で CI が 0 を含まない $s$ はない。ただし $s=2$ の上限（$D_G$ の 21%）までの正は、CI からは除けない。
- **行3（$R_2$ は正だが $R_1$ は0に近い → 説明P と整合）：$s=1$ で当たる。**
  - $R_2(1)$ は +0.033（2 種類の CI とも 0 を含まない）。$R_1(1)$ は +0.009（どちらの CI も 0 を含む）。
  - 学習前の $G$ の点（零に近い）では $R_1(1)$ は +0.029 で、$R_2(1)$ に近い。
  - $s \ge 2$ では、$R_2$ そのものが小さいか負（$s=2$ は +0.010、t の CI は 0 を含む）なので、この形の前提が成り立たない。
- **行4（$S_{\mathrm{res}}$ が大きい → 位置で説明できない成分も損失を下げる。位置以外に何を運ぶかは決められない）：当たる。**
  - $S_{\mathrm{res}}$ は 0.48 [0.26, 0.70]。位置の成分を除くと、損失は $D_G$ の 52% だけ増える（$[L(res)-L(a)]/D_G$）。
- 経験なしとの差：$R_1$・$S$ の差はどれも t の CI が 0 を含む。$R_2(1)$ と $L(z)-L(p+)$（$s=1$）は経験50% の方が大きい（経験なしの $R_2$ は 0 に近い）。
- どの形でも、原因を確定したとは書かない。介入で確かめるまでは「整合する」とだけ書く。
