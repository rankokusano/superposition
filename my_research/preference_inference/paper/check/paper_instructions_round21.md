# Claude Code 指示書 第21弾：自己の経路で、入れ替えの後に「赤の新しい場所へ進む」と予測するか（学習なし）

- 作成：2026-11-06
- 宛先：追加実験の方（Claude Code の実験チャット）

## 背景と目的

第20弾とその追加（§44.4〜44.6）で、次のことが分かりました。
- 他者用の経路に本当の快・不快（入力 T）を入れても、色の配置の効果 $I$ は 0 に近い。
- 他者の驚きは、A-2 の道筋（とどまるか動くか）で決まっていた。

**今回の問い：** 予測器は自己の経路でなら、入れ替えの後に「A-1 は赤の新しい場所へ進む」と予測するか。

- **自己では予測し、他者では予測しない：** 予測器は「快い色へ進む」規則を学んでいるが、それが他者の経路で使われていない（自己から他者への流用の問題）。
- **自己でも予測しない：** 予測器が学んだのは「快い色へ進む」規則ではなく、「赤があった場所へ進む」習慣。

あわせて、他者の経路でも、実際の道筋を使わない同じ形の検査（予測画像を自由に走らせる形）を行います。第20弾の「とどまるか動くか」の交絡を除いた形で、他者の経路を確かめるためです。

## 決まり

- **学習はしません。** 既存の予測器（段階I）を固定し、評価だけ行います。新しく作るのは評価データだけです。
- 位置づけは**探索・事前登録外**です。§2 の手順と読み方の表は計算の前にコミットし、その後で変えません。
- GPU は GPU1〜3 を使います（GPU0 は使いません）。
- コミットは pull してから、ファイルを名前で指定して行います（`git add -A` は使いません）。
- 既存の結果・事前登録・論文の本文は変えません。
- **進め方：** §1 の確認で止まる条件に当たらなければ、§2 の手順をコミットしてから計算に進んでください。止まる条件に当たったときだけ、報告して止まってください。

## §1 評価データを作り、確かめる

### 1.1 データ

- 第20弾の入れ替えの仕組みを使います。
- **エピソード：** 600（配置2 × 4セルで均等）。新しい乱数の鍵を使います。
- **A-1：** 実験1の評価と同じくランダムに動く。
- **A-2：** 静止。他者の経路の検査は、実験1の G5b と同じく、A-2 が静止したデータで行います。
- **入れ替え：** $t=T_s=20$ で赤と緑の位置を入れ替えます。
- **対照（入れ替えなし）：** 同じ A-1 の軌跡で、入れ替えをしないもの。$t=T_s$ までは、ビット単位で同じにします。

### 1.2 確かめること（止まる条件）

1. 入れ替えありとなしで、$t<T_s$ がビット単位で同じか。
2. $t=T_s$ で赤と緑が入れ替わっているか。画像で目で確かめます。
3. 入れ替えなしのデータで、実験1の $g$（自己）と G5b（他者）の流し方の値が、既存の評価と同じ程度に出るか。少数のエピソードで確かめます。

どれかが成り立たなければ、報告して止まってください。

## §2 手順（計算の前にコミットする）

### 2.1 流し方（実験1の「入力を止める」流し方を、入れ替えの後で行う）

- **視覚：** $t=0$〜$T_s+2$ は毎時点見せます。入れ替えの直後の3枚も見せます。
- **入力を止める：** $t=T_s+3$ から 15 ステップ、運動と視覚を止めます（実験1と同じ）。
- **自己の経路の快・不快（止めている間）：** 次の3通りにします。
  - 保つ：最後に見えた視界から計算した値。入れ替えの後なので、赤の新しい方角を指す。
  - 反転：保つの符号を反転したもの。
  - 零
- **他者の経路の快・不快（G5b と同じく10ステップ）：** 同じ時点から、他者の経路に A-2 の視界から計算した「A-2 は赤が好き」とした快・不快を入れます。入れ替えの後なので、赤の新しい方角を指します。反転と零も同じく用意します。
- **対照：**
  - **V0：** 入れ替えの直後の3枚を見せずに、$t=T_s$ で止める。予測器は入れ替えを見ません。
  - **入れ替えなし：** 同じ流し方で、入れ替えをしないもの。
- **チェックポイント：** 予測画像を使うので L1 期間の最終5点。

### 2.2 量

予測画像の中の A-1（自己）と A-2（他者）が、どちらの場所へ向かうかを測ります。読み方は既存の量と同じです。
- 自己：実験1の $s_X$ と $g$ の作り方
- 他者：G5b の位置の読み取り

場所の記号：
- $L_{\mathrm{old}}$：入れ替えの前に赤があった場所（入れ替えの後は緑）
- $L_{\mathrm{new}}$：入れ替えの後に赤がある場所

量：
- $\Delta$：止めている間に、予測の中の主体が $L_{\mathrm{old}}$ の方へ動いた傾きから、$L_{\mathrm{new}}$ の方へ動いた傾きを引いたもの。正なら古い場所の方へ進む予測、負なら新しい場所の方へ進む予測です。
- **主に見る量：** $C = \Delta_{\text{入れ替えなし}} - \Delta_{\text{入れ替えあり}}$（快・不快は「保つ」）。
  - 入れ替えなしでは、赤は $L_{\mathrm{old}}$ にある。そのため、色の規則でも場所の習慣でも $\Delta>0$ になる。
  - 入れ替えありでは、色の規則なら $\Delta<0$、場所の習慣なら $\Delta>0$ のままになる。
  - よって $C>0$ なら色の規則、$C\approx0$ なら場所の習慣。
  - 道筋は入れ替えありとなしで同じなので、軌跡の違いは差で消える。
- **確認の量：**
  - 入れ替えありで、「保つ」と「反転」の $\Delta$ の差。色の規則なら、反転で向きが逆になる。
  - V0 の $C$。入れ替えを見ていないので、0 に近いはず。
- 自己（$C_{\mathrm{self}}$）と他者（$C_{\mathrm{other}}$）を別々に求めます。
- **条件：** 経験50%・経験なし・符号無作為（経験50%）・経験80%（記述）、組1〜6。
- **比べるもの：** 「経験50% − 経験なし」「経験50% − 符号無作為」。
- **CI：** 6組の $t$ の 95% CI と、2段のブートストラップ（組とエピソード、1000回）の CI。
- 予測画像から位置を読めなかったエピソードは、今までと同じ規則で除き、読めた割合を報告します。

### 2.3 読み方の表（計算の前に固定する）

| $C_{\mathrm{self}}$ | $C_{\mathrm{other}}$ | 読み方 |
|---|---|---|
| $>0$（CI が0を含まない） | $>0$ | 予測器は自己でも他者でも、入れ替えの後に赤の新しい場所への動きを予測する。第20弾の $I\approx0$ は、他者の実際の道筋で驚きを測ったこと（とどまるか動くか）によると考えられる |
| $>0$ | $\approx0$ | 自己では「快い色へ進む」規則を学んでいるが、他者の経路では使われていない（自己から他者への流用の問題） |
| $\approx0$ | $\approx0$ | 予測器が学んだのは「快い色へ進む」規則ではなく、「赤があった場所へ進む」習慣である。段階Iの学習を変える必要がある |
| $\approx0$ | $>0$ | 予想していない形。確かめ直してから読む |

- 「経験50% − 経験なし」「経験50% − 符号無作為」で $C$ が正なら、その規則は自分の価値の経験に依存する。
- どの形でも、原因を確定したとは書きません。
