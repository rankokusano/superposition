## 1. b1 好みの形の差で下がる誤差と、$G$ が下げた誤差

### 1.1 E2 と T3 のデータ・チェックポイントの一致
- **一致していること**（コードで確認した事実）：
  - 評価データ：どちらも `v11_s2_pref` の test 300（主）と `v11_s2t_green` の test 300（副）。同じ並び。
  - 流し方：視界は t = 0 だけ見せる。process-1 の運動は隠さない。評価のモード。
  - FP の定義：$h^2$ から予測した特徴と、x_{t+1} の他者側エンコーダの出力との MSE。
- **数値での確認**：E2 の MSE 期間 ep200 の FP（零）と T3 の FP（零）、E2 の FP（正しい好み）と T3 の FP（D6＝$P^{A2}$）を比べた。エピソードごとの最大の差は 1.0e−7 以下で、8 モデルともそろった。
  - （推測）残る差は、T3 が float32 で保存したエピソードの平均と、E2 のステップごとの配列から計算した平均の丸めの違いと考えられる。
- **違うこと**：
  - チェックポイント：E2 は段階Iの MSE 期間の ep160〜200 で、$G$ はない。T3 は段階IIの $G$ の ep160〜200 で、土台は L1 期間の ep200。
    - L1 期間では FP に関わる重みが変わらないので、$G$ の土台の FP は MSE 期間の ep200 と同じ（上の数値の一致とも合う）。
    - 主の比べ方は、E2 の ep200 と $G$ の最終5点にした。
  - 区間：E2 の主の区間はフレーム 1〜50（t = 0..49）。T3 はエピソードごとの t = 0..99 の平均だけを保存している。主の比べ方は t = 0..99。
  - 組：E2 は組1〜6 があるが、$G$ は組1〜4 だけなので、組1〜4 を使った。

### 2.3 読み方（§39.3 のとおり。記述）
- **経験50% − 経験なし**：主のデータで、$U_{\mathrm{use}}$（FP）・$U^{\mathrm{pos}}_{\mathrm{use}}$ とも CI の下限 > 0（6 組とも正）。ほかの 3 つのデータでも、FP 1〜100 の緑好みを除いて下限 > 0。
  - 規則どおり、「自己の価値経験のある予測器は、他者の正しい快・不快の入力を、他者を含む視界の予測（他者特徴、予測画像の A-2 の位置）により役立てる」と記述する。
- **経験50% − 符号無作為（経験50%）**：
  - 主のデータでは、$U_{\mathrm{use}}$（FP）は −0.006 で CI は 0 を含む。符号無作為の方がわずかに大きい組が多い（正は 1/6）。
  - $U^{\mathrm{pos}}_{\mathrm{use}}$ は +1.14 で、6 組とも正だが CI は 0 を含む → 主のデータでは「符号への依存は示されない」。
  - 緑好み・A-2 0.8 緑好みのデータでは、$U^{\mathrm{pos}}_{\mathrm{use}}$ の下限 > 0（記述）。
- 解釈の注意（§39.3）：$U_{\mathrm{use}}$ は零と比べた正しい好みの入力の効果で、$P^{A2}$ の持つ位置の情報の効果を含みうる。
  - 恒等式 $U_{\mathrm{use}} = [\mathrm{L}(\text{零}) - \mathrm{L}(\text{反対の好み})] + U_{\mathrm{pref}}$ が成り立つ。
  - b1 と E2 の記録では $U_{\mathrm{pref}}$ が $U_{\mathrm{use}}$ よりずっと小さいので、FP の $U_{\mathrm{use}}$ の大部分は、反対の好みを入れても得られる部分である（定義からの事実）。
