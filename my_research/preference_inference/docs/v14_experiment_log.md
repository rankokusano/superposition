## 2. 準備（指示書 §4.1）

### 2.1 v12 の 2段目の流し方・範囲と色の対応・2段目 b の出力の形（準備 1）
コード（`model/model_v12.py`、`analyze/v11/eval_s2_v11.py`・`t1t3_s2_v11.py`、`analyze/v12/eval_d6_v12.py`・`s2run.py`、`v11core/pleasure.py`）を読んで確認した。
- **process-1**（2段目）：運動は隠さない（`motion_masking = False`：印 0、運動は本当の値、快・不快は毎ステップの今の視界から。隠れた区間の「止め」も働かない）。
- **視覚**：t = 0 だけ見せ、t > 0 は process-1・2 とも p = 1 で零（`util.mask` は `rand < p` なので p = 1 で必ず零。乱数によらない）。`model.eval()`（dropout なし）、`util.seed_all(0)`、cudnn deterministic。→ 同じ入力なら出力は決定的で、候補を替えた2回の流しはステップごとに完全に対になる。
- **process-2**：`[運動 0, 0, 快・不快の枠 8, 印 1]`（11 次元）。v11 のモデルは 8 次元の快・不快の枠だけ（印・運動なし）。
- **予測誤差**：自己の視界は `|予測 − x_{t+1}|` の画素平均（[−1, 1] の尺度、`eval_s2_v11.run_q2` と同じ）。他者側の特徴予測は `predict_feature(h²)` と `Encoder-2(x_{t+1})` の MSE（`t1t3_s2_v11.run` と同じ）。
- **範囲と色の対応**：パノラマは世界に固定（回転しない）。範囲 k = 列 8k〜8k+7、中心の向き −157.5° + 45°k。ランドマークは各 16 列（2 範囲）を占め、元の配置（layout 0）で **緑 = 範囲 0・1、赤 = 範囲 6・7**、入れ替えた配置（layout 1）で **赤 = 範囲 0・1、緑 = 範囲 6・7**（`eval_s2_v11.GB = {0: [0, 1], 1: [6, 7]}`、`RB = {0: [6, 7], 1: [0, 1]}`）。1段目のデータの P（赤 − 緑）の平均の符号でも確かめた（layout 0：範囲 0・1 が負、6・7 が正。layout 1 は逆）。
- **2段目 b の出力の形**（`signed_pairs`）：`Q2 = P_max·[−u·m0, −u·m1, 0, 0, 0, 0, u·m6, u·m7]`、`u = z[2]`、`m_k = (z_k + 1)/2`、P_max = 1。**u = +1 は「範囲 6・7 が快い」**。
- **違い（報告）**：2段目 b の範囲ごとの強さ m_k は**部品がフレームごとに自由に決める値**で、固定の形ではなかった（その自由度が「残る抜け道」だった）。したがって「2段目 b で使った形」は使えず、指示書のとおり **1段目のデータでの |P| の範囲ごとの平均**を使う（2.2）。

### 2.2 候補の形（v14-A の c+／c−、v14-B の固定の形）
`analyze/v14/cand_shape_v14.py` → `data/result/v14/cand_shape.json`。1段目の学習データ（train 3000 エピソード × t = 0〜99）での |P| の範囲ごとの平均：

| 範囲 | 0 | 1 | 2〜5 | 6 | 7 |
|---|---|---|---|---|---|
| 経験あり（`v11_s1_mixed`） | 0.1231 | 0.1682 | 0 | 0.1693 | 0.1230 |
| 経験なし（`v11_s1_random`） | 0.0856 | 0.0854 | 0 | 0.0856 | 0.0850 |
| 二つの平均を左右で揃えたもの（**案**） | **0.1042** | **0.1271** | 0 | **0.1271** | **0.1042** |

- **案**：経験あり・なしで同じ候補を使う（候補の違いが比べる二つのモデルの違いに入らないように）ため、二つの条件の平均をとり、範囲 k と 7−k を平均して左右対称にする（c+ と c− が「どちら側が快いか」だけで違うように）。c+ = [−0.104, −0.127, 0, 0, 0, 0, +0.127, +0.104]、c− = −c+。
- 参考：0 でないフレームだけの平均は、経験あり 0.20〜0.23、経験なし 0.12。経験ありの方が大きいのは、好きな色の近くにいる時間が長いため。【要確認】経験ありのモデルには経験ありのデータの形を使う案（条件ごとの形）もありうるが、比べる二つで候補が違うことになるので、主は上の共通の形とする（§3 で確定）。

- 0.5 を下回るのは「逆向き」として別に記録する。経験なしの BA の CI の上限が 0.5 より下なら「経験なしは逆向き」として判定と並べて書く。

**H. 予想される形**（報告で、結果がどれに当たるかを書く）

## 4. 事前登録の案：v14-B 1ビット（**草野さんの確認の後に確定し、学習の前にコミットする**）

- **学習**：v12 の 2段目と同じ（exp3 の手順、L1、AdamW lr 1e-3、wd 0.01、batch 10、200 エポック、10 エポックごとに保存、G 以外は凍結、pretrain は `v12_s1_{c}_l1_s{s}` の ep200、`--cudnn_deterministic --data_load_memory`）。exp config `v14_s2u_pref_{random,mixed}_s{s}`。データ ② `v11_s2_pref`（主）。① `v11_s2_green` は GPU に余裕があれば。

- **主の指標**（late-5、組の差は同じエピソードで対にしたブートストラップ）：
  1. **u と正しい候補の一致率**：② の test で、t = 1〜99 のうち sign(u_t) が正しい候補の符号（3.C）と同じステップの割合をエピソードごとにとり、4 つの組み合わせで BA。

## 25. 事前登録（記述）：A-1 自身の好みの「投影」の検査（2026-10-23 13:30、草野さんの判断。**値を見る前**。v14-C のモデルはまだ学習中で、緑好きの評価はどのモデルでもまだしていない）
