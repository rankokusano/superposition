## 2. 方法の節の事実確認（`paper/check/methods_check.md` に結果を書く）

`paper/notes/methods.tex` の記述を、コード・設定・ログと照らす。各項目について「合っている／違う（正しい値）／確かめられない」と、根拠のファイルと行を書く。**違うものは本文を直すので、一覧の先頭にまとめる。**

### 2.1 本文の【要確認】
1. **段階I本番の最適化の設定**：本文は AdamW（学習率 1e-3、重み減衰 0.01、バッチ 10）。経験なし・50%・80%・非共有の本番の設定ファイル（`config/exp/v12_s1_*`・`v13_s1_*`・`v13ns_*`）で確かめる。重み減衰が部品ごとに違うなら、それも書く。
2. **L1 期間に学習する範囲**：本文は「L1 期間は視覚予測器だけを学習する」。コードでは `vision_decoder_module` だけが変わる（v14 ログ §20）。これが h¹・h² をまとめる全結合層まで含むか（文献 [1] の Visual Predictor 全体に当たるか）を確かめる。含まないなら、まとめる層がどこにあり、どの期間に学習されるかを書く。
3. **方角だけの基準の BA**（新しい計算。データだけで決まるので CPU で行う）：
   - 好み混合データの評価用 300 エピソード（`v11_s2_pref` の test）で、A-2 の t = 1〜50 の変位が範囲 6・7 の方向に寄っていれば c+、そうでなければ c−（v14 ログ §18 の「方角の正解」と同じ定義）を選択とし、好みの正解（v14 ログ §3 C）に対する BA（配置 × 好みの4セルの正解率の平均）と、エピソードのブートストラップ 1000 回の 95% CI を出す。
   - 素の一致率が v14 ログ §19 の 0.707 と一致することを確かめる。規則の一歩が少ない3分の1（117 エピソード）でも同じ値を出す（素の一致率 0.607 と一致するか）。
   - T = 50 以外（5, 10, 20, 30, 100）でも同じ基準の BA を出す（図6 に横線または曲線として描くため）。
   - 計算の前に、測り方を `paper/check/` のログに書いてからコミットし、それから計算する。

### 2.2 モデル名と組の確認
4. 組5・6（s4・s5）の経験なし・50%・80% のモデル名とチェックポイントの場所。
5. 段階IIの自由出力モジュール（v12 正式、v13 2段目）、形制限モジュール、他者遮蔽学習、1ビットモジュールのモデル名（対応表 §3 の【要確認】）。
6. 実験2の真値条件（T3 の D6）に、組4（s3）の値があるか。あれば経験なし・50%・80% の値。

### 2.3 本文の数字と手順（合っているかを確かめる）
7. 環境とデータ：20×20 のアリーナ、101 フレーム、休止の確率 0.005 と長さ 10〜30、学習用 3000・評価用 300 エピソード、赤から距離5以内のフレームの割合（経験なし約0.03、50%約0.33、80%約0.85）、80% で中央値14ステップで赤の角に着く、実際に規則で動いた一歩（80% 57%、50% 48%）。
8. 快・不快：範囲 k ＝ 列 8k〜8k+7、(好きな色の画素 − 嫌いな色の画素)/128、マスク前の視界から計算、範囲 2〜5 は常に 0。
9. 運動の隠し方：5〜15 ステップの区間を交互、t ≥ 1 の約48%、隠れた区間は P を区間の最初の値に保つ、印 b_t。
10. 基準エンコーダの値：h¹→自己の位置 R² 0.977、h²→他者の位置 0.973、文献 [1] の図5に当たる取り出しのマージン +0.091、自他一致度 0.80。一から学習したときの自他一致度 0.18〜0.27。
11. 非共有条件：LSTM を分け、層正規化と特徴予測器は分けない。process-2 用は process-1 用の写しから始める。
12. 段階II：他者用モジュールの構成（マスク前の視覚エンコーダ2の出力 64 次元 → LSTMCell 128 → 全結合 → tanh 8 次元）、x² = [0, Q2, 1]、L1 と特徴予測の損失、AdamW（1e-3、0.01、バッチ 10）、200 エポック、t > 0 で視覚を隠す。1ビットモジュールの c+ = (−0.104, −0.127, 0, 0, 0, 0, +0.127, +0.104)。
13. 評価の手順：G3（t = 20 から15ステップ、d = 0〜10、g の式）、G5b（t = 20〜29、a = 0.28、10ステップ後のずれ、8範囲の平均）、符号に従う分（(止める − 反転)/2）、T2（t = 50）、T5（A-2 1.0 以内・A-1 3.0 以内、t ≥ 20）、実験4（T = 50、BA、他者特徴基準は MSE 期間の最終5点）。
14. 組をまたいだ統計：各組の最終5点の平均、組どうしを対にした t の 95% CI（6組で自由度5）。
