# v14 のまとめ：見込みを逆向きに使う（v14-A）／部品の出力を1ビットにする（v14-B）／自分の好みを変える（v14-C）

- 期間：2026-10-23 〜 2026-10-25（worktree `.worktrees/v11`、ブランチ `feature/v11-self-experience`。v14 のファイルは新しく足し、v11〜v13 のコード・結果は変えていない）

## 1. 問いと設計（要約）
- **v14-A 逆推論（評価のみ）**：1段目のモデルの process-2 の快・不快の枠に、好みの候補を二つ（c+：範囲 6・7 が快い、c−：範囲 0・1 が快い。大きさは1段目の |P| の範囲ごとの平均、ログ §2.2）入れ、**A-1 の次の視界の予測がよく当たる方**（累積誤差 T = 50）を選ぶ。候補は A-2 の位置を使わない定数なので、位置を流す道がない。主の指標は ② の test（好みがエピソードで変わる）の balanced accuracy（BA）。
- **v14-B 1 ビット**：他者用の部品 G の出力をスカラー u（tanh）だけにし、Q2 = u × c+ とする（2段目、exp3 の手順）。部品が「好みを書き出す」かを見る。
- **v14-C 好み変数化**：1段目で A-1 の好きな色をエピソードごとに赤／緑から選び、快・不快を「好きな色 − 嫌いな色」にする（符号がエピソードで変わる）。
- 対象のモデル：v12 の1段目（経験あり 50%・なし、s0〜s3）、v13 の経験あり 80%（s0〜s3。経験なしは v12 のもの）、v13-NS（自他で共有モジュールの LSTM を分けたもの、v13 のチャットで学習）、v14-C（経験あり s0〜s2、経験なし版 s0・s1）。

## 2. 主な結果（主張の順）

**(1) 80% の経験で逆推論が成り立つ（v12 では成り立たない）**（ログ §9・§27・§38、図 1）

**(2) 好みと方角が食い違う場面でも好みに従う（4 組中 3 組。s0 は方角）**（ログ §21・§27・§38、図 2）
- A-2 の好みと A-2 の t = 1〜50 の進んだ方角は 0.71 の割合で一致するので、正解率だけでは「好み」と「方角」を区別できない。食い違う 88 エピソードで、選択が好みの方に従う割合を見た。
- 事前登録した条件（他者側の特徴予測の誤差（FP）で選ぶとき、mse 段の late-5 で「好みに従う割合の CI の下限 > 0.5」が 3 点以上）：**v13 の s1（5/5）・s2（4/5）・s3（3/5）が満たす → 「好みを区別している」。s0（0/5）は「方角を区別している」**。FP の副の判定そのものは 4 組とも合格の形。
- 自己の視界の L1 で選ぶ場合（記述）：v13 の s0・s1 が好みに従う（ep200 で 0.659 [0.568, …]・0.625 [0.523, …]）。
- v12 の経験ありは、どの指標でも好みに従わない（ep200、4 組：FP 0.33〜0.48、L1 0.34〜0.47）。v12 の FP での正解率（0.63〜0.72）は方角に沿った選択で説明できる（ログ §19）。

**(3) 共有しないと成り立たない（v13-NS）**（ログ §35 B・§40、図 1・図 4）
- 主の比較「v13 の経験あり 対 v13-NS の経験あり」（同じシード・同じエピソード）：**3 組とも 5/5 で v13 が上**（ep200 の差 +0.255・+0.157・+0.107、CI は 0 を含まない）。
- NS の経験ありは偶然並みか、それを下回る（BA 0.42〜0.53）。好み × 配置のセルごとに見ると、**NS は一方の候補に偏り、セルに沿って入れ替わらない**（図 4）。NS では候補を替えても他者側の特徴予測の誤差がほとんど変わらない（s0 の ep200 で、c+ と c− の累積誤差の差の最大が NS 0.46、v13 30.6）。
- **これは作りの上で予想どおりの確認である**：NS では process-2 の快・不快の入口の重みが1段目で一度も学習されない（初期値のまま、重みの減衰だけ）。事前登録に「逆推論は偶然並みになると予想する」と書いてあり、論文では「逆推論でも、他者側へ届く道は共有以外にないことの確認」と位置づける。

**(4) 部品に書き出させると、どの条件でも方角（または位置）を書く**（ログ §28・§29・§39・§41、図 3・図 5）

| 1段目のモデル | 合否（§4 の規則） | u の一致率 BA（経験あり） | (a) T5 > 0 | (b) 食い違いで好みに従う | 書き方 |
|---|---|---|---|---|---|
| v12 経験あり | 合格（3/3） | 0.67〜0.73 | T5 −0.013〜0（D6 +0.42） | 0.33〜0.58（CI の下限 > 0.5 は 0〜1/5） | 事後の確認で好みの根拠なし |
| v13 経験あり | 合格（3/3） | 0.51〜0.65 | 0/3 組 | 0/3 組（0.30〜0.41） | **方角（または位置）** |
| v14-C 経験あり（探索） | 合格（3/3）、主の「v12 より上」は 0/3 | 0.63〜0.71 | 0/3 組 | 0/3 組 | **方角（または位置）** |

- v12 の v14-B は (a)・(b) を事前登録していなかった（判定の後に方法を決めた確認、ログ §29）。v13・v14-C では事前登録した。
- **同じモデルで「当てて選ぶ」（v14-A）と「書き出す」（v14-B）を比べると**（図 3）：v13 では、当てて選ぶと食い違うエピソードで好みに従う（L1 0.55〜0.66、FP 0.57〜0.67）のに、書き出すと方角に従う（0.30〜0.35）。正しい候補との一致率は書き出す方が高いこともある（v12）が、それは方角・位置に沿った一致である。→ **ネットワークの中には好みを区別する情報があり、自分の見込みに当てて使うと取り出せる。しかし部品に書き出させると、部品は予測に効く方角・位置を書く**（v12 の三層の分析の層2：好みを書く利点が小さい、を部品の側から裏づける形。推測を含む）。

## 3. v14-C（好み変数化）：否定的な結果（ログ §33・§37・§38・§41、図 6）
- 1段目の関門：**G1〜G3 は合格**（3/3 組、各 5/5）。赤好き・緑好きのエピソードのどちらでも同じ形で、**自分側の見込みは好きな色ごとに対称に出る**（G3 の g：赤好き +0.09〜+0.12、緑好き +0.08〜+0.12）。**G5a・G5b は不合格**（1/3 組、s2 だけ）。→ v12 §24 の規則により、2段目は探索として行った。
- G5a が s0・s1 で消えた理由の確認（事前登録外）：A-2 の本当の快・不快を入れても、予測の中の A-2 は**A-2 の好きな色にも A-1 自身の好きな色にも寄らない**（両者が同じエピソードでさえ 0 前後）。自分の好みを投影したのではなく、「入れた快・不快の方へ動く」当てはめそのものが弱くなった。
- v14-A：主の比較（v14-C の経験あり 対 v12 の経験あり）は **0/3 組**（BA 0.50〜0.57）。FP は「方角」（条件 0/5）。
- v14-B：v12 の経験ありより u の一致率が上がらない（0/3 組。s0・s1 では下がる）。
- **投影の検査**（A-1 を赤好き → 緑好き、選択が A-1 の好きな色の側へずれるか）：どのモデルにも「投影」はない（自己の視界の L1 では「混ざらない」か弱い「対比」）。**FP による投影の検査は作りの上で必ず 0 になる**：共有モジュールは重みを共有するが process-1 と process-2 の状態は別で、FP が読む h² には process-1 の入力が入らないため（ログ §37）。
- まとめ：好みの符号がエピソードで変わる経験では、自分側の見込みは保たれたが、逆推論も他者側への当てはめも強くならず、投影も出なかった（指示書 §1.3 の仮説は支持されない）。

## 4. 主張できること・できないこと
**主張できること**
1. A-1 が 80% の割合で好みに従った経験を持つと、自分の見込み（process-2 に好みの候補を入れたときの予測）に当てて選ぶだけで、A-1 の視界だけから A-2 の好みを偶然より高く区別できる（v13、4 組中 3 組）。50% の経験（v12）ではできない（4 組中 1 組）。
2. その区別は、4 組中 3 組で、A-2 の直近の進む方角では説明できない（好みと方角が食い違う場面でも好みに従う）。
3. 自他で共有モジュールの重みを共有しないモデル（NS）ではこの区別は出ない（作りの上で予想どおりの確認）。
4. 他者用の部品に好みを書き出させると、1 ビットに絞っても、どの1段目のモデルでも部品は方角（または位置）を書く。
**主張できないこと**
1. 「ネットワークが自分で他者の好みを推し量った」とは言えない。言えるのは「自分の経験から生まれた見込みに、A-1 の視界だけから他者の好みを区別する情報がある」まで（指示書 §1.1）。手続き（二つの候補を当てて選ぶ）は外から与えたもの。
2. 部品が好みを表すようになった、とは言えない（v14-B はすべて方角・位置）。
3. 好みを変数として扱う経験が他者の好みの理解を助ける、とは言えない（v14-C は否定的）。

## 5. 限界
1. **A-2 が規則で動く一歩が少ないエピソードでは区別できない**：規則の割合が下から 3 分の 1 のエピソードでは、v13 のどの組も「好みに従う」条件を満たさない。ただし ② の test ではこの割合の幅が狭く（0.36〜0.56）、下から 3 分の 1 でも「ほとんどランダム」ではない。
2. **v12 の経験なし s2 も食い違いの条件を満たした**（FP、mse 段 4/5）。経験なしでもこの形が出る組があるので、条件を満たすことだけでは経験の効果とは言えない（主の判定は経験なしとの組の差で行っている）。
3. **指標（FP と自己の視界の L1）で好みに従う組が入れ替わる**：FP では s1・s2・s3、L1 では s0・s1。どちらの指標でも満たすのは s1 だけ。
4. **s3 は単独では不合格**（2/5）。4 組の判定は 3 組で合格だが、4 組すべてではない。
5. 1段目の l1 段では Decoder だけが学習されるので、FP は l1 段のどの点でも同じ値になる（ログ §20 の訂正。FP の主の数え方は mse 段の late-5 にした）。
6. 候補の大きさは1段目の |P| の平均（0.10〜0.13）で、本当の P_A2（0 でないとき 0.2〜1）より小さい。本当の P_A2 を候補にした参照の BA は v12 の s2・s3 で 0.5 以下で、参照も強くない。
7. 自他を同じ書き方で表す性質は凍結した v4 の Encoder で与えたもの（v12 の限界 1 と同じ）。
8. v13-NS は v13 のチャットで学習したモデルで、v14 では読むだけ。NS の入口の重みは初期値のままで、偶然を外れる値（s0 の L1、s2 の FP で 0.5 より下）は初期値による候補への偏りと読んだ（推測）。

## 8. 今後の課題
1. 逆推論が成り立つ条件の切り分け：v13 で成り立ち v12 で成り立たないのは「見込みの強さ」によると考えられるが、80% と 50% の間（例 65%）や、1段目の見込みの強さを別の方法で変えたときに、正解率が単調に変わるかは確かめていない。
2. 「当てて選ぶ」手続きを部品が自分で学ぶ条件：v14-B では部品は方角・位置を書いた。好みを書く利点が予測にとって大きい課題（A-2 の行動が好みでほぼ決まる、A-2 が長く見えない、など。v12 まとめ §13 の 2）で、v14-A の手続きと同じ情報を部品が書き出すかを見る。
3. v14-C で他者側の当てはめが消えた理由（G5a の確認では「どちらにも寄らない」）の切り分け。
