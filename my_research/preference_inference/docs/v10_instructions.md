## 1. 背景

### 1.1 元論文（ベースモデル）
Noguchi, Iizuka, Yamamoto & Taguchi (2022), *Scientific Reports* 12:2859, "Superposition mechanism as a neural basis for understanding others"。公式実装は https://github.com/wtrnoguchi/superposition （このリポジトリの root がその clone）。

- A-1 は、自分の一人称視覚（16×64 RGB、全方位）と自分の運動を入力に、次の視覚を予測するよう学習します。
- 1つの LSTM（Superposition Module、128ユニット）を process-1（自己）と process-2（他者）で共有します。重みは同じで、記憶は別です。
- その結果、自己と他者の位置（h¹→自己 R² 0.967、h²→他者 0.993）、他者の視点（Fig.5）、他者の運動が、予測学習だけで獲得されました。

### 1.2 本研究のこれまで（v4〜v7）
入力を「運動」から「行動価値（Q値）」に置き換え、「自分の価値だけを学習して、他者の価値が分かるか」を調べてきました。

| 版 | 内容 | 結果 |
|---|---|---|
| v4 | process-1 の入力を 8方向の probe-Q に置き換え。Encoder は元論文のものを凍結 | 自己位置は保たれる（R3-A_400、h¹→自己 0.906）。他者の価値は生成できない |
| v5 | Encoder も価値入力で学習し直し | 他者側の表現が弱まる。価値の生成は失敗のまま |
| v6 | 報酬パラメータを推定。条件付き critic Q(s,a,r) | 推定はほぼ定数 |
| v7 | A-1 の critic を部品にした逆強化学習 | 目標は当たるが、状態を壊しても当たる。動く向きだけで決まっていた |

### 1.3 進捗発表での指導教員の指摘（v10 の出発点）
- 今のモデルでは、**価値が位置に結びついてしまっている**。本当は価値と行動が結びついてほしいが、まずは**価値と色が結びつく**かを確かめたい。
- 「価値を止めて、ランドマークの色の位置を変えても、自己と他者（の区別）はできる」「元論文のものは位置」：今のモデルが自他を区別できるのは位置を読んでいるからで、価値がなくても成り立つ。自他の区別の成功は、価値を使っている証拠にならない。
- 「他者の予測はやめて」：他者の価値の推定はいったん止める。
- 具体策：**選好を与えているのは赤と緑だけなので、赤と緑の位置だけ入れ替えてみる。**

### 1.4 これまでの結果との対応
- A-1 はランダムに歩くので、A-1 自身の経験の中で Q値は「次にどう動くか」の手がかりにならず、「今どこにいるか」の手がかりにしかならない。
- v7 では、critic が最良とする向きが場所によらずほぼ一定でした（赤なら 129°）。四隅の配置ではランドマークがどこから見ても同じ方角にあるため、「赤の方へ」と「左上の方へ」が区別されていません。
- v4 の critic_swap（A-1 の critic を A-2 のものに差し替えると h¹→自己が −34.8%）は「h¹ は価値の構造を使っている」根拠でしたが、その価値の構造自体が位置で決まっている可能性があります。

### 1.5 v10 でやること・やらないこと
- **やる**：赤と緑の位置を入れ替えた環境を作り、(段階A) 既存のモデルをその環境で評価し、(段階B) 入れ替えのある環境で学習し直して、価値が色に結びつくかを調べる。
- **やらない**：
  - 他者の価値の推定（VE、逆強化学習）。
  - A-1 の動き方の変更。**A-1 はランダム歩行のまま**です。
  - critic を外す、入力を運動に戻す、などのモデル構成の変更（将来の v11 で検討。§10）。
- v8（内側配置）・v9 の構想は保留です。v10 では使いません。

## 2. v10 の問いと主張

- **問い**：価値は「色」に結びついているか、「場所」に結びついているか。入れ替えのある環境で学習すれば、色に結びつくか。
- **主張できる形**：
  - 段階A：「既存のモデルでは、価値は場所に結びついていた（または色に結びついていた）」。どちらの結果でもそのまま記録する。
  - 段階B（成功した場合）：「赤と緑の位置が入れ替わる環境で学習すると、critic の価値と、共有モジュールの自己の内部状態が、場所ではなく色に沿って整理される」。
- **限界として必ず明記すること**：
  - critic は共有モジュールの外の別ネットワークで、強化学習で学習している。段階Bで価値が色に結びつくかは**主に critic の学習**で決まる。報酬は色で定義されているので、入れ替えのあるデータで critic を学習すれば、色に結びつくのはある程度予想どおり。
  - 共有モジュールについて言えるのは、「色に結びついた価値を渡されたとき、内部状態も色に沿って整理されるか」まで。共有モジュールが価値を自分で作ったとは言わない。
- **主張しないこと**：「価値と行動が結びついた」「他者の価値が分かった」。

**実装**

### 段階A：既存のモデルを入れ替え環境で評価する（再学習なし）

**データ**
- 入れ替え環境で、既存の評価データと同じ形式・同じ設定のデータを新しく作る。
  - `v10_swap_r2`：A-1 ランダム、A-2 は既存の A-2 の actor で動かす（`r2_a1random_a2rl` と同じ設定）。**A-2 の actor は元の配置で緑へ向かうよう学習したもの**なので、入れ替え環境でどこへ向かうか（新しい緑の位置か、元の緑の場所か）を、終端位置の分布として記録すること。それ自体が「A-2 の actor は色と場所のどちらで動いているか」の結果になります。
  - 可視化用の 20 エピソード版：`v10_swap_r2_viz20`。
  - エピソード数と split は、評価に必要な分だけでよい（`r2_a1random_a2rl` の test split と同じ規模を目安に、回帰器の学習用に train split も必要なら作る。v4 の `regression_baseline_v4.py` が回帰器をどの split で学習しているかを確認し、それと揃えること）。
- 収集の決まり：視覚は uint8、シードはデータセット名の MD5 から生成して HDF5 属性に記録、Q値は保存しない、`other_vision` を保存する、少量で bit-identical な再現を確かめてから本収集。

**評価する条件**

| 条件 | 環境 | probe-Q | 意味 |
|---|---|---|---|
| A0 | 元の配置 | critic が元の視界から計算 | 基準（既存の結果の再現） |
| A1 | 入れ替え | critic が入れ替え後の視界から計算 | 価値は色で計算される |
| A2 | 入れ替え | **止める**（各時刻の平均に置換。v4 の constant と同じ） | 指導教員の「価値を止めて、色の位置を変えても自他はできる」の確認 |
| A3 | 元の配置 | 止める（同上） | A2 との切り分け |

- probe-Q の正規化統計（μ, σ）は**元の値のまま**使う（事前登録）。
- 主条件は R3-A_400（seed0・seed1）。副条件は `v5_base_l1`。

**測ること**
1. **critic の最良方向マップ**（主結果）：A-1 の critic（`v3_rl_critic.pth`）について、両方の配置で、格子上の各位置の最良方向（8方向、または K=64 方向の argmax）を図にする。各位置で、最良方向と「その配置での赤の方向」との角度差、「元の赤の場所 (−9,9) の方向」との角度差を出す（ランドマークから 2 以内は除く）。
2. **critic の Q値マップ**：両方の配置で、格子上の各位置の Q値（8方向の最大値）。
3. **A-2 の critic・actor** も同じ図を作る（緑について）。
4. **4軸 R²**（h¹→自己、h¹→他者、h²→自己、h²→他者）：条件 A0〜A3 で。回帰器は (i) 各条件のデータで学習し直す場合と、(ii) A0 で学習した回帰器をそのまま当てる場合の両方を出す。(i) は「情報があるか」、(ii) は「同じ符号化か」を見るためです。
5. **視覚予測の誤差**：条件 A0〜A3 で、process-1 の自己の視覚予測の誤差。
6. **Fig.5（他者の視点の取り出し）**：A0 と A1 で、other_other・other_self・self_other を出す。Decoder は元の配置で学習したものなので、入れ替え環境で崩れるかどうかも記録する。

**読み方（事前登録）**
- critic について：入れ替え環境で、最良方向と「赤の方向」の角度差の平均が、「元の赤の場所の方向」との角度差の平均より **15° 以上小さい**なら「色に結びついている」、逆なら「場所に結びついている」、どちらでもなければ「中間」と記録する。
- 共有モジュールについて：A2（価値を止めて入れ替え）で h¹→自己・h²→他者が A0 の 0.8 倍以上保たれれば、「自他の区別は価値に依存していない」（指導教員の指摘どおり）と記録する。
- 段階Aは合否ではなく、現状の診断です。どの結果でも段階Bに進むかは私が判断します。

### B1：入れ替えのある環境で critic・actor を学習する

- `v3_rl_critic.pth` などを学習したスクリプトと設定をコピーし、**エピソードごとに 1/2 の確率で配置を入れ替える**ことだけを変えて学習する。報酬、好み、ネットワーク、学習率、エピソード数は v3 と揃える。
- A-1（赤好き）と A-2（緑好き）の両方を学習する（B2 のデータで A-2 を動かすため）。
- 3シード。所要時間を事前に見積もって報告すること。

**関門 B1（事前登録。A-1・A-2 それぞれ、3シードのうち2本以上が満たすこと）**
1. **崩壊していない**：critic 健全性チェック（ノイズ画像・4隅・中心・行動変化に対する Q の応答。`action_std > 0.05` かつ `state_std > 0.05`）。
2. **actor が好きな色へ行ける**：両方の配置で、50エピソード×100ステップのロールアウトの終端距離（好きな色の柱の中心から）が ≤ 5。
3. **critic の最良方向が色を向く**：両方の配置で、最良方向と「好きな色の方向」の角度差の平均が、「もう一方の配置で好きな色があった場所の方向」との角度差の平均より **30° 以上小さい**。
- 最良方向マップと Q値マップ（両方の配置）を必ず図にし、目視確認する。
- 満たさなければ B2 に進まず報告すること。学習設定を変えて再挑戦するかは私が決めます。

**関門 B2（事前登録。報告のみで、私の確認を待つ）**

### B3：共有モジュールを学習する

- 収束：v4 の基準（`docs/v6_instructions.md` §4.2）で、3シードのうち2本以上。`min(B)` の値も併記。

### B4：主分析（価値が色に結びついたか）

**比較するモデル**
- 入れ替えで学習したモデル（B3）。
- 元の配置で学習したモデル（R3-A_400。段階Aで使ったもの）。
- どちらも、`v10_swapmix_r2` の **test split** と、元の配置だけ・入れ替えだけに分けた部分集合で評価する。

**測ること**
1. **配置の読み取り**：h¹ から、そのエピソードが入れ替えありかなしかを当てるロジスティック回帰（エピソード単位で分けた交差検証）。時刻 t = 1, 5, 10, 20, 50, 100 ごと。
2. **赤までの距離 vs 左上までの距離**：h¹ から「A-1 から赤までの距離」と「A-1 から左上 (−9,9) までの距離」をそれぞれ回帰した R²。
3. **比較用の読み取り**：同じ読み取りを、(a) その時刻の probe-Q（8次元）だけから、(b) その時刻の Encoder の出力だけから、も行う。h¹ が入力をそのまま流しているだけか、時間をかけて統合しているかを区別するためです。
4. **4軸 R²**（共通評価と in-dist の両方）。
5. **視覚予測の誤差**（配置ごと）。
6. **PCA 状態マップ**：h¹ を、自己の位置で色付けした図と、赤までの距離で色付けした図を、配置ごとに並べる。
7. **Fig.5**：配置ごとに other_other・other_self・self_other。
8. **段階Aの A2 に相当する操作**（probe-Q を止める）を B3 のモデルにも行い、h¹→自己・配置の読み取りがどれだけ落ちるか。

**主関門（事前登録）**
1. **色への結びつき**：B3 のモデルで、h¹ からの配置の読み取りが t=20 で正答率 ≥ 0.80、かつ R3-A_400 より 0.15 以上高い（95% 信頼区間が 0 を含まない。エピソード単位のブートストラップ）。
2. **時間による統合**：B3 のモデルで、h¹ からの配置の読み取りが、その時刻の probe-Q だけからの読み取りを上回る。
3. 1 と 2 を満たせば「共有モジュールの内部状態が、色に沿って整理された」と記録する。1 だけなら「色の情報は h¹ にあるが、入力の probe-Q をそのまま流しているのと区別できない」と記録する。1 を満たさなければ「入れ替えで学習しても、共有モジュールの内部状態は色に沿って整理されなかった」と記録する。**どの結果でも、そのまま報告すること。**
