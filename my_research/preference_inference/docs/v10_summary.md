## 1. 問いと設計

### 1.1 問い
v4〜v7 では、A-1 の行動価値（critic の 8 方向の probe-Q）を共有モジュール（Superposition Module、process-1 の入力）に渡してきた。指導教員の指摘は「**今のモデルでは価値が位置に結びついている**。まず価値と色が結びつくかを確かめる」。報酬は色（赤・緑の画素の割合）で定義されているが、元の環境ではランドマークが四隅に固定され、全方位カメラは回転しない（視界の列が世界の方角に固定）ため、「赤の方へ」と「左上の方へ」が区別できない。

**v10 の問い：価値は「色」に結びついているか、「場所」に結びついているか。入れ替えのある環境で学習すれば、色に結びつくか。**

### 1.2 設計
- **赤と緑の位置だけを入れ替える**（元：赤 (−9,9)・緑 (−9,−9) → 入れ替え：赤 (−9,−9)・緑 (−9,9)。青・シアン、報酬、視覚、行動空間は不変）。入れ替えはフィールドのメッシュのマテリアルの差し替えで実装し、元の配置では既存データと bit-identical、入れ替えでは色の割合の誤差 0 を確認した（関門 6.0）。入れ替えでは赤が「元は緑が見えていた列」に移るので、**critic が色を見ているか、列（方角）を見ているかを切り分けられる**。
- **段階A**：既存のモデル（v3 の critic・actor、R3-A_400、v5_base_l1）を入れ替え環境で評価（再学習なし）。
- **段階B**：エピソードごとに 1/2 の確率で入れ替える環境で、B1 critic・actor を学習 → B2 データを作成 → B3 共有モジュールを学習（R3-A と同じ設定） → B4 主分析。
- **B3 の 2 条件**：B3-frozen（事前登録どおり、元論文の Encoder・Decoder を凍結）、B3-ft（Encoder・Decoder も一緒に学習。違いは凍結リストから Encoder・share_lns・Decoder を外すことだけ）。各 3 シード。**v10 の主な結論は B3-ft で判定**（B3-frozen は比較の条件）。
- A-1 はランダム歩行のまま、好みは単一（A-1 赤、A-2 緑）。判定基準はすべて計算の前に事前登録してコミットした。

## 2. 主な結果

### 2.1 段階A：既存のモデルは「場所」に結びついていた（数値ログ §3）

**表 A1：critic・actor の最良方向（入れ替え環境、21×21 格子、K=64）**

|---|---|---|---|
| A-1 の critic（v3、赤） | 110.9° | **26.5°** | **場所** |
| A-2 の critic（v3、緑） | 104.9° | 31.6° | 場所 |
| A-1 / A-2 の actor | 105.8° / 108.3° | 25.2° / 25.3° | 場所 |

- A-1 の critic の Q(s, a) の両配置間の相関は **+0.996**（入れ替えにほとんど反応しない）。
- **A-2 の actor（v3）は、入れ替え後も 3000 エピソードすべてで元の緑の場所（今は赤）から 5 以内で終わる**（新しい緑の近くで終わるのは 0）。軌道の差は平均 0.42。
- 共有モジュール（R3-A_400）：h¹→自己 0.907 → 0.894（入れ替え後もほぼ保たれる）。入力の probe-Q から配置はほぼ読めず（0.52）、凍結 Encoder の出力も対のフレームで 12% しか変わらない（事前登録外の確認）。
- 予測画像：入れ替え後も**元の配色で描かれる**（凍結 Encoder→Decoder が列の位置から色を補う）。

**補足（ログ §5.35）**：v3 の A-2 の actor も、入れ替えで終端の位置がわずかにずれる（終端の x が 0.4〜0.5 ずれる）＝色もわずかに見ている。向かう先は両配置で同じ左下なので、「場所に結びついていた」という結論は変わらない。

## 3. 主張できること・できないこと

### 3.1 主張できること
1. **元の環境で学習した critic・actor の価値・行動は、色ではなく場所（見え方の配置）に結びついていた**（段階A：最良方向が元の場所を向く 26.5° vs 赤 110.9°、Q の両配置間の相関 +0.996、A-2 の actor は入れ替え後も元の緑の場所へ行く）。
2. **入れ替えのある環境で critic を学習すると、価値は色に沿うようになる**（Q の両配置間の相関 +0.996 → −0.81（A-1 seed0）、本当の報酬マップの相関 −1.000 の 6〜8 割）。ただし学習は不安定（3 項目合格 A-1 1/6、崩壊 2/6）。
3. **入れ替えのある環境で学習すると、共有モジュールの h¹ に色（配置）の情報が表れる。元の配置だけで学習したモデルには表れない**（A-2 の位置の交絡を除いた (a) で、B3 の h¹ 0.97 vs R3-A_400 0.545、差の 95% CI +0.39〜+0.46）。
4. **B3-ft では、その情報の大部分は Encoder が担う**（学習後の Encoder の出力だけで 0.946〜0.994。h¹ の上乗せは (a) で +0.020、(b)・swapmix では 0）。Encoder・Decoder を学習した B3-ft は、入れ替え後も正しい配色で自己の視覚を予測できる（誤差に配置の差なし）。
5. **B3-frozen では、共有モジュールが時間をかけて色の情報を統合している**（凍結 Encoder の出力 0.70〜0.76、probe-Q 0.86〜0.91 に対し、h¹ 0.97〜0.99）。**ただし収束は 1/3** で、予測画像は元の配色のまま（凍結 Decoder のため）。
6. 自他の区別（h¹→自己、h²→他者）は、元の配置で学習したモデルでも入れ替え後に大きくは崩れない（R3-A_400 の h¹→自己 0.907 → 0.894）。これは入力（probe-Q・Encoder の出力）が入れ替えでほとんど変わらないためで、自他の区別の成功は「価値が色を使っている」証拠にならない（指導教員の指摘と整合）。

### 3.2 主張できないこと
- 「価値と行動が結びついた」「他者の価値が分かった」（v10 の対象外）。
- **共有モジュールが価値を自分で作った**とは言わない。色に結びついた価値は主に critic（共有モジュールの外、強化学習）の学習による。共有モジュールについて言えるのは「色に結びついた価値を渡されたとき、内部状態も色に沿って整理されるか」まで。
- B3-ft の「色に沿った整理」（主関門2）を共有モジュールだけの働きとは言えない。Encoder の寄与が大部分で、データによっては区別できない。
- B3-frozen の結果を一般化しない（収束 1/3、結論の主な条件ではない）。
- 入れ替えのない元の環境で、critic が「色を使う」能力を本来持っているかどうか（元の環境では色と場所が一致していて、問えない）。

## 4. 交絡（A-2 の位置）を見つけた経緯と、除いた方法

1. **発見**（ログ §5.31）：B4 で、元の配置だけで学習した R3-A_400 の h¹ から、`v10_swapmix_r2` の配置が t=20 で 0.831 読めた。段階Aの後に測った基準値（A-2 が両配置で同じ場所へ行くデータ）では 0.519 だった。違いは A-2 の動き方：B2 のデータの A-2（B1 seed0 の actor）は**緑へ向かう**ので、A-2 がどこにいるか（左下か左上か）が配置を表してしまう。A-2 は A-1 の視界に映り、h¹ は他者の位置を持つ（h¹→他者 0.58〜0.82）。事前登録外の確認で、**A-2 の本当の位置だけから t ≥ 20 で配置が 100% 読める**ことを確かめた。
2. **除いた方法**（ログ §5.32〜§5.34）：学習はやり直さず、A-2 の位置が配置を明かさない評価データを作った。(b) A-2 を v3 の actor で動かす（両配置で同じ左下へ行く）、(a) A-2 を静止させる。**主関門の計算の前に**、各データで A-2 の本当の位置だけから配置を読む確認を行った。(b) は t=20 で 0.650（v3 の A-2 の終端がわずかにずれるため）で偶然の水準にならず、事前登録どおり主関門を計算せずに報告した。(a) は全時刻で 0.493。**結果を見る前に、データの性質だけにもとづいて主を (a) に切り替え**、(b) は A-2 の位置との比較を加えて副として並べた。
3. **教訓**：「潜在状態から潜在変数（ここでは配置）を読める」という結果は、それが観測可能な別の量（ここでは他者の位置）と混同されていない比較で初めて意味を持つ（v4 の Phase 3 の「選好 ≡ 位置」の交絡と同じ型）。

## 5. 副産物：A-2 の行動の規則性は、観察だけで覚えられる

- 交絡を除いた評価データ (a) では A-2 が静止しているが、B3 のモデルは**静止している A-2 を、学習時のように「緑の方へ動いた」位置に描いた**（B3-ft s0、入れ替え配置のエピソード 0：正解では黒い A-2 がその場にいるのに、予測では t=5 以降、右端の緑のそばに描かれる）。そのため (a) では自己の視覚の予測誤差が時間とともに増える（t=0 0.064 → t=50 0.141）。
- B3 の学習データでは、A-2（B1 seed0 の actor）は両配置で常に緑へ向かっていた。A-1 自身は緑へ向かう経験を持たない（ランダム歩行）が、**共有モジュールは他者の行動の規則性（「A-2 は緑へ行く」）を、自分の経験なしに、観察（視覚の予測）だけで覚えた**。入れ替え配置でも緑の側へ描くので、場所ではなく色に対する規則性として覚えている可能性がある（定量化はしていない）。
- 同じことは (b) にも現れる：v3 の A-2 は左下（入れ替え配置では赤）へ行くが、B3-ft は緑の方へ描くので、(b) の入れ替えのエピソードで誤差が大きい（0.143）。R3-A_400（v3 の A-2 のデータで学習）は (b) で誤差が小さい（0.073）。
- 図：`b4_reeval/diag_vision/fig_a2_learned_motion.{png,pdf}`（§7 の F11）。
- 位置づけ：事前登録外の観察。v11（共有モジュールが A-1 の行動の偏りを予測学習で覚えるか）に関わる手がかりになる。

## 6. 限界の一覧

1. **critic は共有モジュールの外**（強化学習）。色に結びついた価値は主に critic の学習による。報酬が色で定義されているので、入れ替えのあるデータで critic を学習すれば色に結びつくのはある程度予想どおり。
2. **入れ替えのある環境での critic の学習は不安定**（B1：3 項目合格 A-1 1/6、A-2 0/6、崩壊 A-1 2/6・A-2 1/6）。B2 以降は合格した 1 本（A-1 seed0）に依存する。関門 B1 は不合格のまま、結果を見た後の判断で進んだ。
3. **B3-frozen の収束は 1/3**（関門 B3 不合格）。seed1 の主関門は 1 本だけに基づく参考値。
4. **B3-ft の主関門2 の合格は僅差**（Encoder に対し +0.020、CI 下限 +0.002）で、副 (b) と B4 の swapmix では不合格。
5. **主 (a) は A-2 が静止**し、学習時の状況（A-2 が緑へ動く）と違う。(a) では全モデルの自己の視覚の予測誤差が大きい（0.13 前後）。
6. **(b) は交絡の確認に不合格**（A-2 の位置から t=20 で 0.650）。
7. **B4 の swapmix での配置の読み取りは A-2 の位置と交絡**しているので、色の証拠としては使えない。
8. 凍結 Encoder は元の配置のデータで学習されており、赤・緑をほとんど区別しない（段階A）。B3-frozen の Fig.5・予測画像はその影響を受ける。
9. **Encoder を学習すると自他の分離が弱まる**（Fig.5 のマージン：B3-frozen 0.079 → B3-ft 0.002〜0.022、s1 は入れ替えの grid で −0.001）。v5 と同じ向き。
10. 距離の R²（赤までの距離 vs 左上までの距離）は参考扱い。入れ替えのエピソードだけでは色と場所を切り分けない（指示書の誤り）。全体での「赤までの距離」は線形の読み取りに不利。
11. 自己の視覚に基づく収束判定は「落ち着いた」ことしか見ない（B3-frozen s2 は相転移していないのに収束と判定された）。
12. probe-Q の正規化（μ, σ）の手順は再実装で、v4 の値と 0.1〜0.15% ずれる（未解決、v10 の結果には影響しない）。
13. 単一の環境・手設計の報酬。シードは B3 が 3 本、R3-A_400 は収束した 2 本。

## 8. 運用上の教訓（v10 から次に引き継ぐもの）

- **ジョブを起動したら、終わったときに「すべての出力がそろっているか」を確認する**（ログ §9。R3-A_400 の評価が実行されていなかった件の教訓）。
- 報告・記録はすべて日本語で行う（ログ §5.25）。
