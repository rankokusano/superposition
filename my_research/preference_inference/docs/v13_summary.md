## 1. 問いと設計
- **問い**：v12 で残った層 2（自分の「快の高い方へ動く」見込みが弱い傾向にとどまり、好みを正しく伝えても他者の予測の改善が小さい）をふさいだら、他者用の部品は好みを表すか。
- **v12 から変えたのは一点だけ**：1 段目の経験ありで、A-1 が好みに従う一歩の割合を 50% から 80% にした。ほかは v12 と同じ（Encoder は v4 で凍結、運動の隠し方、2 段目のデータと A-2 の動き、関門と判定の基準）。
- **経験なしは v12 のモデルを再利用**（ログ §1）：データの乱数の作りから、80% 版でも配置・初期位置・A-2 の位置・眠りの時刻が経験なしと全エピソードで一致し、今のコードで v12 の経験なしを学習し直すと重みが bit-identical になることを確かめた。2 段目の経験なしも同じく再利用（ログ §13）。
- 一から学習版は回さない（v12 ログ §53 の決定、ログ §10）。

## 2. 80% 版のデータ（ログ §2）
- 赤から 5 以内にいるフレーム 0.85（50% 版 0.33）、後半（t ≥ 50）は 0.99。中央値 14 ステップで赤の角に着き、その後はほぼ角にとどまる。実際に規則で動いた一歩は 57%（50% 版 48%）。快の正の部分の和の平均 0.77（50% 版 0.44）。
- 経験の形は「速く赤へ近づき、着いたら角にとどまる」で、学習データの位置の分布は赤の角に大きく偏る。

**主な結果（2 つを並べて書く）**。同じシード・同じ初期値で、データだけが違う v12（50%）と v13（80%）を比べた（ログ §3.4 の数え方、§16）。
1. **自分側：経験の量に応じて見込みが強くなった**。
   - G2：運動が隠れた一歩の M1(d) +0.018〜+0.020、色の基準 +0.010〜+0.015（v12 の約 1.7 倍）。
   - G3：経験ありの g +0.20〜+0.26（v12 +0.09〜+0.10、約 2.3 倍）。v13 − v12 が 3 組とも 5/5 で正（「強くなった」）。
   - 好みに従って動く経験が多いほど、「快の高い方へ動く」見込みは強くなる。
2. **他者側でも、快・不快の向きに従う働きが経験の量に応じて強くなり、組にそろった**（§3.1）。
   - **G5b（主の根拠）**：process-2 に入れた快・不快の向きに従って、予測の中の他者がずれる。v12 は 2/3 組（経験ありの値 +0.02〜+0.24、強さは s0 に偏る）、v13 は 3/3 組（すべて 5/5、+0.35〜+0.75、v12 の 2〜6 倍）。v13 − v12 が 3 組で「強くなった」（4/5・5/5・5/5）。
   - **補足：G5a の符号に従う分**（事後の切り分け、事前登録外）：v12 は 3 組中 1〜2 組（① s0・s1、② s0）、v13 は 3 組とも（① +0.24〜+0.45、② +0.16〜+0.38、すべて 5/5、v12 の約 3 倍）。経験なしでは 0 か負。
   - 主張の言い方：「自分の経験から生まれた見込みは、process-2 に入れた快・不快にも働き、予測の中の他者を快の方向へずらす（G5b：v12 2/3 組、v13 3/3 組）。この働きは経験ありでだけ出て、好みに従う経験を増やすと強くなり、組にそろう。」
- **G5a の傾き（副に下げる）**：関門の判定は 1/3 組で不合格、v13 − v12 は 3 組とも CI が 0 を含む（−0.09〜+0.08）。ただし G5a の傾きには、快・不快の向きに従う動きと、止める前に置いた位置から本当の位置へ**戻る動き**（向きに依らない）が混ざる（§3.1）。v12 では戻る動きが傾きを押し上げ（半分ほど）、v13 では逆向きの戻る動きが向きに従う分を打ち消した、と読める（推測）。このため G5a の傾きは他者側の働きの強さを表す量としては使わず、副として記述する。v12 の G5a の合格（3/3 組）も「好みに従う動き」の根拠には使わない。
- **G1 の不足**（ログ §11・§12）：経験あり 80% の運動が見える一歩の R² は、共通の test（ランダムに歩く）で 0.72〜0.75（v12 の経験あり 0.86 前後）。しかし自分の学習データと同じ作りの test では 0.99 で、3 つのモデルの中で最もよい。**学習データの偏り（角にとどまる）による、経験していない場面への一般化の弱さ**と記録した。判定は「満たさず」のまま。
- 角の近くかどうかで分けた記述（ログ §11）：G3・G5a とも、角から離れた部分集合で全体と同じ向き・同じくらいの大きさ。角の近くだけで働く形は出ていない。
- **最初の寄り**（ログ §14、事前登録外）：G3・G5a とも、止めた直後（k=1）と K=15 後の「好きな色の方向 − ほかの方向」は、経験あり 80% でだけ大きく正で、v13 − v12 は 3 組ともすべての量で正。v12 の経験ありの G5a では最初の寄りは負（−2.8〜−4.3）だった。
  - **注意**：k=1 の値は、関門の手順では止めるかどうかに依らない（止める前に予測の中の A-2 をどこに置いているか）。80% 版のデータでは「快が高い ⇔ 角にいる」がほぼ一対一なので、これが「好きな色の方へ着くはずだ」という見込みなのか、「快・不快から位置への対応」なのかは区別できない。「他者側の見込みも強くなったが、表れ方が変わった」と読むことと矛盾はしないが、それだけを支えるとは言えない。

### 3.1 他者側で快・不快が使われていることの根拠：G5a の傾きの切り分けと G5b（ログ §15・§16、事前登録外、判定は変えない）
- **G5a の傾きは 2 つの動きが混ざった量だった**。快・不快を逆にして止めた場合（A-2 の好きな色と嫌いな色を入れ替えた形）と比べると、止めた傾き ＝「快・不快の符号に従う分」＋「符号に依らない分」に分けられる。

| | 経験なし | 50% 経験あり（v12） | 80% 経験あり（v13） |
|---|---|---|---|
| 符号に従う分（① / ②） | 0 か負 | ① +0.00〜+0.14（s0・s1 で 5/5、s2 で 0/5）／ ② −0.03〜+0.16（s0 だけ 5/5） | **① +0.24〜+0.45 ／ ② +0.16〜+0.38（3 組ともすべて 5/5）** |
| 符号に依らない分（① / ②） | 0 前後か負 | 正（+0.04〜+0.17） | 負（−0.38〜−0.05） |
| 止める前の A-2 の置き方（好きな色の方向、本当の位置との差） | 組でばらつく | 好きな色から離して置く（−0.7〜−1.9） | 好きな色の方へ寄せて置く（+0.5〜+3.7） |

  - v12 の G5a の正の傾きは、**半分ほどが「好きな色から離して置いた A-2 を本当の位置へ戻す動き」**（符号に依らない分）で、快・不快の向きに従う分は 3 組中 1〜2 組にとどまる。
  - v13 では、快・不快の向きに従う分が 3 組とも強く出た（v12 の約 3 倍）。G5a の傾きが v12 より大きくならなかったのは、これが逆向きの戻る動き（好きな色の方へ寄せすぎた所から戻る）で打ち消されたためと読める（推測）。
  - 読み取りの方法そのものの偏りはない（本当の視界に同じ読み取りを当てると 0 ± 0.02）。
- **G5b はもとの位置のずれに影響されない**。G5b は、同じ入力の履歴（t = 20 まで同じ）から、process-2 の範囲 k に +a を入れた予測と −a を入れた予測の差をとり、範囲 k の方向に射影する。止める前に予測の中の A-2 をどこに置いていたかや、快・不快の符号に依らない動きは、+a と −a の両方に同じように入るので差で消える。上の「符号に従う分」と同じ考え方の量で、関門の時点から事前登録されている。
  - G5b は v12 で 2/3 組（s0 5/5、s1 2/5、s2 3/5。経験ありの値 s0 +0.19〜+0.24、s1・s2 +0.02〜+0.12）、v13 で 3/3 組（すべて 5/5、経験ありの値 +0.35〜+0.75）に合格し、v13 − v12 も 3 組で正（4/5・5/5・5/5）。v12 の合格は s2 が 3/5 でぎりぎりで、強さは s0 に偏っていた。
- **書き方**（2026-10-23 草野さんが了承。§3 の主な結果に反映。v12 の文書は別のチャットで直す）：
  - 「他者側で快・不快の**向き**が使われている（process-2 に入れた快・不快の向きに従って、予測の中の他者を動かす）」ことの**主の根拠は G5b** とする。理由：同じ状態からの +a と −a の差なので、他者をどこに置いていたかに左右されない。事前登録した主の関門で、v12・v13 とも合格。
  - **G5a の傾きは副に下げ**、「止めた快・不快のもとで好きな色の方へ進む」ことは、戻る動きが混ざることを注記して記述する。v12 の G5a の合格（3/3 組）を「好みに従う動き」の根拠としては使わない。補足として、事後の切り分けの「符号に従う分」（v12 で 1〜2 組、v13 で 3 組）を並べる。
  - 主張の言い方の案：「自分の経験から生まれた『快の高い方へ動く』見込みは、process-2 に入れた快・不快にも働き、予測の中の他者を快の方向へずらす（G5b、v12 2/3 組・v13 3/3 組）。この働きは経験ありでだけ出て、好みに従う経験を増やすと強くなり組にそろう（v13 の G5b は v12 の 2〜6 倍、G5a の符号に従う分は約 3 倍）。」
  - G5b の限界も並べる：共通の test（A-2 は静止、A-1 はランダム）で、1 つの範囲に ±a を入れる人工的な入力であること。寄りは 1 段目で快・不快が出る範囲（0・1・6・7）に集まること。A-2 の本当の好みは使っていないこと（他者の好みを推し量ることではなく、与えた快・不快の使い方の検査）。

## 4. 2 段目（探索）（ログ §12・§22、数値ログ §8）
- 事前登録（ログ §3.3、v12 ログ §24）により、G2・G3 合格・G5a 不合格なので**探索として**行った。T2・T5 は事前登録の形で判定したが、他者の好みを予測できたと主張する根拠には使わない。経験なしの 2 段目は v12 のものを再利用（今のコードで学習し直すと bit-identical、ログ §13）。
- **結論：事前登録の「うまくいかない場合」に当たる**。自分側の見込みは強くなった（§3）が、2 段目は v12 と同じ「位置を流す形」のままだった（Q2 が範囲 2〜5 を通り道に使い、本当の快・不快とは負の相関）。「見込みの強さだけでは足りず、課題の作り（好みが他者の予測に必要な情報になること）も要る」と結論づける（指示書 §1）。

- **① T2 の合格と並べる注意**：
  1. 大きさ：経験ありの値は +0.02〜+0.05 で、D6（A-2 の本当の快・不快をそのまま入れた値、+0.60）の 1/12〜1/30。
  2. 組の差（s0 +0.16〜+0.21、s2 +0.06〜+0.11）の大部分は、経験なしの値が負であること（s0 −0.13〜−0.18、s2 −0.04〜−0.07）から来る。経験なしは v12 と同じモデル。
  3. 重視する副は支えない：Q2 と A-2 の本当の快・不快の相関は経験ありで 3 組とも負（① −0.04〜−0.17、② −0.05〜−0.12）。Q2 の分散の 52〜80% が範囲 2〜5。T3 で生成した Q2（他者側の特徴予測の誤差 0.12〜0.15）は D6（0.40〜0.42）よりずっと良い。
  4. 組で向きがそろわない（① は s1 で 0/5、② は s1 だけ）。
- **本当の快・不快（D6）を入れても、80% のモデルではかえって外れる**（事後の確認、ログ §24・§25、推測を含む）：T3 の D6（他者側の特徴予測の誤差）は、1 段目のモデルだけで決まる量で v12 と比べられ、経験あり 80% では 0.39〜0.42（50% 0.25〜0.28、経験なし 0.26〜0.29）に悪くなる。悪化は A-2 が好みに従った一歩でも +0.11〜+0.15 あり、従わなかった一歩・眠りでやや大きい（+0.01〜+0.04、「従った < 従わなかった < 眠り」の順で 3 組そろう）。80% のモデルは快・不快から「好きな色の角にいる」と強く見込み、50% しか好みに従わない A-2 を本当より好きな色の方へ寄せて予測する（§3.1 の「寄せすぎて置く」）ので、本当の好みを入れる利点が減り、部品が好みを書き込む理由もむしろ減ったと考えられる（推測）。**自分の見込みが強くなるほど、行動の規則が自分と違う他者では、自分の見込みをそのまま当てはめることが予測を悪くしうる**。
