## 2. A：自分と他者の規則の割合の組み合わせ（学習なし）

### 2.1 ねらい
真値条件の悪化が「自分と A-2 の行動の仕方の食い違い」から来るなら，A-2 も 80% で好みに従うデータでは，経験80%条件のモデルの悪化は小さくなる（または消える）はずである。「見ていない入力への不安定さ」から来るなら，A-2 の行動の仕方を変えても悪化はあまり変わらないはずである。

### 2.2 データ（CPU）
- 新しい評価用データを2つ作る：**A-2 が一歩ごとに確率 0.8 で好きな色へ向かう**以外は，既存の評価用データと同じもの。
  - 緑好み：`v11_s2t_green` の test（300 エピソード）と同じ作り・同じ乱数の鍵で，A-2 の規則の割合だけ 0.8。
  - 好み混合：`v11_s2_pref` の test（300 エピソード）と同じ作り・同じ乱数の鍵で，A-2 の規則の割合だけ 0.8。
- できれば，v13 の 80% 版のデータと同じ考え方（§1 の「方式の抽選は専用の乱数で，割合を変えても引く回数と値は変わらない」）で，**配置・初期位置・A-1 の歩き・眠りの時刻が元のデータと全エピソードで一致する**ようにする。収集のコードを読み，一致させられるかを先に確かめて報告する。一致しない部分があれば，それも書く。
- データの記述を出す：A-2 が好きな色から距離5以内にいるフレームの割合，実際に規則で動いた一歩の割合（0.5 版と 0.8 版），A-2 が角にとどまる程度。
- 学習用（train）は作らない。

### 2.3 評価
- モデル：段階Iの経験なし・経験50%・経験80%条件，**組1〜6 すべて**（真値条件は段階Iのモデルだけで決まるので，段階IIをしていない組5・6 も測れる）。チェックポイントは既存の真値条件（T3）と同じもの（どれを使っているかを確かめて書く）。
- 条件：A-2 の規則の割合 0.5（既存の評価用データ）と 0.8（新しいデータ）。緑好みと好み混合の両方。
- 量：既存の真値条件と同じ手順で，他者側の特徴予測の誤差を，process-2 に (a) 零，(b) A-2 の本当の快・不快（D6）を入れた場合で測る。**主の量は改善 Δ = (b) − (a)**（負なら本当の快・不快が役立つ）。A-2 の行動が変わると零の場合の誤差も変わるので，差で比べる。
- 副：(a)・(b) そのもの，A-2 の一歩の種類（好みに従った一歩・従わなかった一歩・休止）ごとの (b)，A-2 の位置の誤差（既存の T3 にあれば）。

### 2.4 事前登録の案（具体的な形は計算の前に決めて書く）
- **予想 A1**：経験80%条件のモデルで，Δ は A-2 0.8 の方が A-2 0.5 より小さい（よく役立つ）。
- **予想 A2**：A-2 0.5 では経験80%条件の Δ が経験50%条件より大きい（既存の結果の再現）が，A-2 0.8 ではその差が小さくなるか逆になる（自分と他者の割合が一致すると悪化が消える）。
- **予想 A3**：経験なし条件の Δ は A-2 の割合であまり変わらない。
- 判定の案：各組で A-2 0.8 − A-2 0.5 の Δ の差（同じエピソードで対にしたブートストラップ 1000 回の 95% CI）を出し，本番の3組中2組以上で CI が 0 を含まず予想の向きなら A1 を支持とする。全6組では組をまたいだ対の t の CI（自由度5）と，何組で成り立つかを並べる。A2 は（経験80% − 経験50%）の Δ の差を，A-2 0.5 と 0.8 で比べる交互作用として同じ形で出す。
- 解釈の表（ログに書いておく）：A1・A2 が成り立つ → 食い違いによる説明（投影または角に多くいた経験）を支持し，見ていない入力だけの説明には合わない。成り立たない → 見ていない入力への応じ方による説明が残る。どちらの場合も，価値の経験と位置の偏りは A では分けられない（C で分ける）。

## 3. B：非共有モデルに，学習後に自分側の重みを写す（学習なし）

### 3.1 ねらい
非共有条件で他者側の働きが消えるのは，「学習中に重みを共有していないから」か，「process-2 の快・不快の入口が学習されていないから（自分側で学んだ重みが使われていないから）」かを切り分ける。学習後に process-1 の LSTM の重みを process-2 に写して働きが戻れば，効いているのは「自分側で学んだ重みの再利用」であり，学習中の共有そのものではない。

### 3.2 モデル
- 非共有条件（組1〜3）の各チェックポイントで，**process-2 用の LSTM の重み（入力の重み・再帰の重み・バイアスのすべて）を process-1 用の LSTM の重みで置き換えた写し**を作る（以下，写しモデル）。元のチェックポイントのファイルは変えない（メモリ上で作るか，新しいディレクトリに保存する）。
- 置き換える範囲をコードで確かめて書く（層正規化と特徴予測器は非共有条件でも分けていない）。
- L1 期間には LSTM が変わらないので，写しの LSTM は MSE 期間の ep200 と同じになるはず。確かめて書く。

### 3.3 評価
- 比べるもの：同じ組の (i) 元の非共有モデル，(ii) 写しモデル，(iii) 経験80%条件（共有あり），(iv) 経験なし条件。すべて同じ装置・同じ手順で測る。
- 量：
  1. **G5b**（既存と同じ手順，L1 期間の最終5点）＝主。
  2. 符号に従う分（緑好み・好み混合）。
  3. 実験4の BA（自己視界基準，T = 50，L1 期間の最終5点）と，他者特徴基準の BA。
  4. **他者の位置を追えているか**：$h^2$ から A-2 の位置を読む決定係数（既存と同じ測り方）。写すと process-2 の動き方が変わるので，追跡が壊れていないかを必ず確かめる。
  5. 自分側の値（G3，次の視界の予測誤差）。process-1 は変えていないので元の非共有モデルと同じになるはず（確認）。ただし視覚予測器は h² も読むので，予測誤差は変わりうる。変わったら書く。

### 3.4 事前登録の案
- **予想 B1**：写しモデルの G5b は，元の非共有モデルより大きく，経験なし条件との差が CI で 0 を含まない（既存の G5b の判定の形）。本番の3組中2組以上で成り立てば支持。
- **予想 B2**：写しモデルの G5b・符号に従う分・照合の BA は，経験80%条件（共有あり）に近づく（差を並べて記述）。
- 解釈：B1 が成り立つ → 他者側の働きに要るのは「自分側で学んだ重みが他者側の計算に使われること」で，学習中の共有でなくてもよい（論文の主張を「自分側で学んだ重みの再利用」と書く根拠になる）。成り立たない → 学習中の共有が要るか，写すと他者の追跡が壊れたかのどちらか。量 4 で区別する。

## 4. C：位置の分布をそろえた対照（学習が要る。**データと設定の準備と事前登録までにして，学習は私の確認の後**）

### 4.1 ねらい
経験80%条件と全く同じ軌跡（位置の分布も同じ）で，「快の方へ動く」という価値と行動の結びつきだけをなくす。そのとき自分側・他者側の見込みや真値条件の悪化が消えれば，それらは価値に従って動いた経験によるもの，残れば角に多くいた経験（位置の偏り）によるもの，と言える。

### 4.2 データ（CPU。v14 の `make_randompref_v14.py` と同じ考え方）
- 経験80%条件の段階Iのデータ（train 3000・test 300）の全配列をそのまま写し，**エピソードごとに確率 1/2 で快・不快 P の符号を反転**したもの（以下，符号無作為データ）。反転の抽選は専用の乱数の鍵で決め，どのエピソードを反転したかを記録する。シミュレーションはしない。
- 反転したエピソードでは，A-1 は赤へ向かうが，P では緑が快い。したがって P の向きは A-1 の動きの向きと結びつかない。
- 確認：反転していないエピソードは元のデータと全配列で一致，反転したエピソードは P だけが符号違いで残りは一致。運動を隠す区間と快・不快を保つ処理が，学習の中で P の値に依らず同じに作られるか（データにあるか，学習の中で作るか）をコードで確かめて書く。
- 赤と緑の入れ替え（配置）はもともとエピソードごとに 1/2 なので，P の符号の反転は配置とは独立に決める。

### 4.3 学習と評価（確認の後）
- 学習：経験80%条件と同じ設定（基準エンコーダで凍結，MSE 期間 200 → L1 期間 200，`--cudnn_deterministic --data_load_memory`），データだけ符号無作為データにする。組1〜3（s0〜s2）。起動前に，ep0 の重みが同じ組の経験80%条件と一致することを確かめる。
- 所要時間の見込み：1 GPU に1本で約16時間（v13 の実績）。**案：今日の 13:30 以降に空く GPU4〜GPU7 のうち3枚に1本ずつ載せ，14 時ごろに起動**すれば，学習は 10/27 の朝（6〜8 時ごろ），評価を含めて 10/27 の昼ごろに終わる見込み。空く時刻がずれる場合や，v15 の段階2 の本番と重なる場合の案（1枚に3本で約1.7〜2倍，など）も出す。
- 評価：経験80%条件と同じ一式（自己位置の追跡，G2，G3，G5a，G5b，符号に従う分，真値条件，実験4）。加えて，自分側の見込みが P に従うかを見るため，G3 を **P を保つ／P を零にする／P の符号を反転して保つ** の3通りで測る（P を零にした G3 は既存の評価に記述としてある）。
- 組にする相手：同じ組の経験80%条件（軌跡が同じ）と経験なし条件。

### 4.4 事前登録の案（学習の前に書く）
- 価値の経験による説明の予想：符号無作為条件では，G5b・符号に従う分・真値条件の悪化が経験なし条件の水準まで下がり，経験80%条件との差が CI で 0 を含まない。G3 は，赤へ向かう癖として残りうるが，P の符号を反転したときの変化（P への依存）は経験80%条件より小さい。
- 位置の偏りによる説明の予想：符号無作為条件でも，真値条件の悪化と G3 が経験80%条件と同程度に残る。
- 判定の形は既存の関門と同じ（最終5点の 5 点中 3 点，3 組中 2 組），加えて組をまたいだ差を記述する。
