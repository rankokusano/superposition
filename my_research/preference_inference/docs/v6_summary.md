# v6 まとめ（報酬パラメータ推定による他者理解の試み）

**位置づけ**：本文書は`docs/v6_experiment_log.md`（全経緯の逐次記録、§1〜§40）とは別に、修士論文の1章分の材料として結果を整理したものである。数値はすべて`docs/v6_results_log.md`から引用し、該当する図の保存先パスを併記する。詳細な設計判断・棄却された仮説・やり直しの経緯は`docs/v6_experiment_log.md`を参照のこと。

**結論の要約**：v6はS1〜S4までv5を上回る結果を得たが、S5（報酬パラメータの推定）で構造的な上限に突き当たり、ここでラインを終了する。S6（観察時間と推定精度の関係）は実施しない。

---

## 1. 何を試したか

### 1.1 推定対象を変えた理由

v4/v5は「他者（A-2）の価値をA-1の視覚から推定する」ことを目指したが、2つの構造的な理由で失敗していた（`docs/v6_experiment_log.md` §0）：

1. **Q値が自他で通約不可能**：A-1用critic（std=0.63）とA-2用critic（std=0.009）は別個に学習されたものであり、値域が70倍異なっていた。値域を人為的に揃えても（P1.75）益はなかった。
2. **位置を流す方が視覚予測の損失に有利**：生成された他者価値`Q̂²`は、他者の価値そのものよりも**位置情報**を符号化する方が損失を下げられてしまい（`Q̂²→A-1位置 R²=0.387 ≫ →A-2位置 R²=0.097`、v5_r4_move）、VEは位置の代理変数を出力するよう学習されてしまっていた。

v6は、推定対象をQ値（8次元）から**報酬パラメータ`r=(w_red, w_green, w_blue, w_cyan)`（4次元）**に変更することで、この2つを設計レベルで同時に解消することを狙った：報酬は自他で同じ尺度を共有するため通約可能性が構造的に保証され、出力が4次元しかないため位置情報を符号化する帯域がない。

### 1.2 アーキテクチャ

```
v4/v5:  VE  → Q̂²（8次元）を直接出力                         → SM
v6:     VE' → r̂²（4次元） → 条件付きcritic Q(s,a,r̂²) → 8方向プローブ → Q̂²（8次元） → SM
```

中心となる新規実装は**報酬条件付きcritic `Q(s,a,r)`**：SACの学習中、エピソードごとに報酬パラメータ`r`をランダムサンプルし、その`r`に従って計算した報酬で学習する単一のcriticである（従来のA-1専用・A-2専用の2つのcriticを統合）。SM（Superposition Module）のアーキテクチャ自体は一切変更していない。

### 1.3 値域の改善

同じcriticに異なる`r`を入れるだけで済むため、値域が構造的に揃う。A-1条件とA-2条件のQ値std比は、v4/v5の**70倍から約2.5倍まで改善**した（`docs/v6_experiment_log.md` §9・§28・§31.6）。

## 2. どこまで成功したか

### 2.1 S1：条件付きcriticの学習（成功）

カリキュラム学習（学習初期はA-1/A-2近傍のみ、徐々に全域へ拡大するr分布）により、A-1条件・A-2条件それぞれでQ値空間マップが正しい色（Red高・Green高）を示す健全なcriticを得た。

**未知の連続値rへの汎化を座標勾配の疑いなく確認**（2026-10-02、S5着手前）：checkerboard型r=(0.5,-0.5,0.5,-0.5)（対角のRed・Blueを好み、もう一方の対角Green・Cyanを嫌う）でテストしたところ、

| | Red | Green | Blue | Cyan |
|---|---|---|---|---|
| Q値 | 0.907 | -0.457 | 0.563 | -0.261 |

点対称な corner ペア（Red・Blueの平均=0.735、Green・Cyanの平均=-0.359）の差は1.094——**線形な座標勾配ならこの差はゼロになるはずであり、座標勾配では数学的に説明できない、色ベースの評価であることが確認された**（`data/result/v6_baseline/unseen_r_generalization_seed2_film_norelabel_curriculum.png`）。

### 2.2 S2・S3：base段（v5を上回る）

| | v5 | v6 |
|---|---|---|
| S2視覚損失（self_vision, MSE, in-dist） | 12.05 | **8.78** |
| S2 h¹→self（in-dist） | 0.796 | **0.8215** |
| S3視覚損失（self_vision, L1, in-dist） | 12.04±0.02 | **11.21±0.01** |

Encoderをスクラッチ学習する方針（元論文Encoderの凍結流用では価値入力レジームで収束しないことがv5で判明済み）を踏襲し、v5と同一条件下で、視覚損失・h¹→self（自己表現の質）ともにv5を上回った（`data/result/v6_baseline/v6_s2_base_mse_training_curve.png`、`v6_s3_base_l1_training_curve.png`、予測画像`v6_s2_base_mse_pred_images_ep400.png`・`v6_s3_base_l1_pred_images_ep200.png`）。

**ただしcanonical protocol（r2_a1random_a2rl、学習に使っていないデータ分布）ではh¹→selfが0.49まで低下する**（v5は0.72）——このh¹→selfの汎化の弱さは§4で後述する。

### 2.3 S4：オラクル実験（正解を与えると機能する、ただし距離に依存）

VEを介さず、A-2の真の報酬パラメータを直接条件付きcriticに与えてQ̂²を計算したところ：

- **全体では`true_r < zero`は不成立**（v4/v5と同種の「正解を入れると損をする」結果、+0.0008）
- **しかし事前登録した距離別アブレーションでは、Greenから離れるほど単調に効果が強まった**：

| 距離ビン | n（割合） | true_r − zero |
|---|---|---|
| <5 | 90.4% | +0.0014 |
| 5-10 | 4.6% | -0.0016 |
| 10-15 | 3.1% | -0.0043 |
| ≥15 | 1.9% | **-0.0139** |

late-5チェックポイント間のsdは最遠ビンで0.0001——効果量の1/139であり、ノイズではない。**対照実験として`constant`（方向情報を除いた非零信号）で同じ距離別分析を行ったところ、同じ単調な改善トレンドを示さなかった**（-0.0039→+0.0038→+0.0014→-0.0026、符号反転を繰り返すのみ）——これにより、距離別の効果が「何らかの非零信号があること」ではなく「正しい報酬の情報」によるものだと確認された（`data/result/v6_baseline/v6_s3_base_l1_oracle_distance_binned.png`）。

**解釈**：全体での不成立は、評価データの90.4%がGreenから距離5未満に集中している（A-2自身がGreen選好で行動するため）という、データ分布に起因するものであり、criticやメカニズム自体の欠陥ではない。「遠い領域では機能するが、実際のA-2の行動特性により実効性が薄まる」という構造である。

## 3. どこで失敗したか

### 3.1 S5：VE'の出力はほぼ定数に収束した

VE'（LSTMCell、自己視覚由来の`ov_enc`から4次元の`r̂²`をtanh出力、教師信号は視覚予測損失のみ）を400epoch学習した。

**r̂²の実際の値**（全300,000フレーム平均）：

| 成分 | A-1真値 | A-2真値 | r̂²平均±sd |
|---|---|---|---|
| red | +1 | -1 | +0.154±0.495 |
| green | -1 | +1 | +0.572±0.224 |
| blue | 0 | 0 | **+0.742±0.428**（最大） |
| cyan | 0 | 0 | +0.525±0.267 |

**4成分すべてが正であり、最大の成分は両真値ともゼロのはずのblueである。** 赤成分の符号も真値（-1）と逆。見かけ上「A-2の真値とのコサイン類似度+0.27」が得られていたが、これは無関係な次元（blue・cyan）に乗った大きな正のバイアスの上に、greenがredよりわずかに大きいという弱い傾きが乗っていたことで生じていたに過ぎない——**他者の報酬を正しく推定した結果ではなく、ほぼ定数に近い出力**である（`data/result/v6_baseline/v6_s5_ve_r_hat_components_ep400.png`、`v6_s5_ve_r_hat_scatter_ep400.png`）。この傾向はep50（学習のごく初期）から一貫しており、学習を通じた改善は見られなかった。

### 3.2 真値に置き換えても回復しない＝設計の上限

学習済みのr̂²を**A-2の真値に置き換えて**、同一の凍結SM・critic（S5では`value_estimator_module`以外すべて凍結、S3から重みは一切変化していない）で再計算したところ：

| 条件 | h²→self | h²→other |
|---|---|---|
| VE'学習済みr̂²（実測） | 0.480 | 0.471 |
| **真値r2を代入** | 0.513 | **0.481** |
| （参考）S4オラクル（実際のother_vision使用） | 0.016 | 0.880 |

**真値に置き換えてもh²→otherはほとんど変わらない（0.471→0.481）。** S4のオラクル値0.880には遠く及ばない。これは、S4のオラクルが「実際のother_vision」をcriticの視覚入力として使っていたのに対し、S5の設計（本研究の主張に忠実な「自己視覚のみ」）は**self_visionのみ**をcriticの視覚入力として使うためである——self_visionには他者の実際の位置に関する情報がほとんど含まれないため、どれだけ正しい`r`を与えても、そこから計算されるQ̂²が他者位置を強く符号化することは原理的に難しい。**この結果は、VE'の学習精度の問題ではなく、「自己視覚のみから推定し、自己視覚のみへ突き返す」という設計そのものの表現力の上限であることを示す。**

## 4. 何が分かったか（知見）

### 4.1 「価値の通約可能性を得る代わりに、価値の状態特異性を失う」トレードオフ

条件付きcriticは値域の通約可能性を構造的に得る代わりに、probe-Qベクトルの自己位置特異性を失う。単一時刻のprobe-Q→自己位置の直接回帰R²は、v4の素のcritic（赤好き専用）で0.60だったのに対し、v6の条件付きcritic（任意の好みに対応）では0.41まで低下した（`docs/v6_experiment_log.md` §31.5-31.6）。

この低下はv4で問題視されていた構成概念妥当性の懸念（「Q値が単なる位置センサーとして機能しているだけでは」）にとっては望ましい変化だが、位置情報の供給源としては弱くなっており、S2でのcanonical protocolにおけるh¹→selfの汎化の弱さ（0.82→0.49）と無関係とは言い切れない。

### 4.2 self_visionのみからの推定には構造的な表現力の上限がある

§3.2で確認した通り、VE'の推定精度を向上させても、h²→otherは0.48付近が天井になる可能性が高い。これは「自己の視覚・価値だけから他者を理解する」という本研究のテーゼに忠実であろうとすること自体が、他者位置の表現力に上限を課すという、設計上のトレードオフを明らかにしている。

### 4.3 S4の効果はデータの行動分布に強く依存する

正しい報酬情報は原理的には視覚予測を改善するが、その効果量は「対象が目標のすぐそばにいる」という評価データの大半（90.4%）では薄まる。これはcriticの欠陥ではなく、A-2自身がGreen選好に従って行動した結果、Green近傍に軌跡が集中するという、データ収集方法に起因する構造的な制約である。

## 5. v4/v5の結論への含意

v4/v5で確立された「**予測学習だけで自己表現は価値入力レジームへtransferするが、他者の価値の生成的推定（VE）はtransferしない**」という結論は、**報酬レベルまで対象を単純化しても同じ形で成立する**ことが確認された。v6はこの結論に対する境界をさらに一段階強いものにする。

元論文（Noguchi et al., 2022）のLimitation「他者の内面状態の推論は獲得されなかった」に対し、v6はS4とS5という2段階の実験によって、より具体的な理由を示す形になった：

- **S4**：メカニズム自体（条件付きcritic経由で報酬情報を視覚予測に利用する仕組み）は、少なくとも対象が目標から十分離れている場合には機能する。「正解を与えれば使える」ことは示された。
- **S5**：しかし、その正解（報酬パラメータ）を**自己の観察だけから推定する**段階で、推定がほぼ定数的な出力に縮退し、機能しなかった。さらに、推定精度を仮に完全にしても（真値代入実験）、自己視覚のみを使うという設計自体が他者位置の表現力に上限を課すことが分かった。

つまり、失敗の所在は「メカニズムが他者の価値情報を使えない」ことではなく、「**自己の観察だけから他者の報酬を抽出する**」という、より具体的なボトルネックにあることが、v6によって特定された。

## 6. Future Work

### 6.1 設計変更の候補

- **VE'の入力を`ov_enc`ではなく`h²`（process-2のSM出力、既に時間統合・構造化された表現）にする**：現在のVE'は生の`ov_enc`から直接`r̂²`を推定しているが、`h²`は既にSM内部で時間方向に統合された表現であり、より豊かな手がかりを含んでいる可能性がある。
- **観察の蓄積を明示的に扱う機構**：現在のLSTMCellは暗黙的に時間統合を行うが、「他者がどれだけ一貫してある方向に向かっているか」のような、より明示的な蓄積統計量（移動平均・分散など）を設計に組み込む余地がある。
- **self_vision限定という制約の緩和を伴う段階的な実験**：本研究の核心的主張（自己視覚のみからの他者理解）を保持したまま、どこまでの情報（例えば、他者の過去の自己申告的な軌跡情報を間接的な形で与えるなど）が許容されうるかの境界を探る。

### 6.2 理論的検討

- **なぜself_vision限定の設計に構造的な上限があるのか**：self_visionに含まれる他者情報は、A-2がA-1の視野に偶然入った場合の間接的な手がかりに限られる。この情報量の理論的な上限（相互情報量の観点など）を定式化できれば、S5の限界がどの程度本質的なものかを定量的に論じられる可能性がある。
- **「価値の通約可能性」と「価値の状態特異性」のトレードオフの一般化**：§4.1で見つかったトレードオフが、条件付き価値関数一般に成り立つ構造的な性質なのか、本研究の特定の設計に固有のものなのかの検討。
