## 1. 研究の目的（不変）

### 1.1 何を問うているか

他者の価値（欲求・選好）の理解が、**いかなる前提から最小限に創発しうるか**を構成論的に示す。

自己の一人称視覚を予測するという単一の学習目的のみを与えられたネットワークが、副産物として他者の行動価値に対応する内部表現を形成しうるかを検証する。

**目指さないもの**：他者の報酬を高精度に推定するアルゴリズム（それは逆強化学習が既に解いている）。問うのは、**IRL が前提として要求するもの——他者を価値主体とみなす枠組みそれ自体——がどう獲得されうるか**である。

### 1.2 元論文との関係

Noguchi, Iizuka, Yamamoto & Taguchi (2022) *Scientific Reports* 12:2859

元論文は、A-1 の視覚と**運動指令** `m_t` から次の視覚を予測する学習だけで、A-2 の位置・視点・運動を表現する内部状態が創発することを示した。鍵は process-1 と process-2 が**同一の Shared Module（LSTM）を共有**する点。

**本研究はこの入力を行動価値 `Q(s,·)` に置き換える。**

| | 元論文 | v4 |
|---|---|---|
| process-2 の入力が必要な理由 | A-2 の**運動**が観測できない | A-2 の**価値**が観測できない |
| それを埋めるモジュール | Motion Generator (MG) | **Value Estimator (VE)** |
| process-1 の入力 | 実際の `m_t` | 実際の `Q¹(s,·)` |
| process-2 の入力 | 生成した `m̂²` | 生成した `Q̂²` |

**VE は MG の一対一の置き換え。** 構造は元論文と同一のまま、扱う量が運動から価値に変わる。

### 1.3 なぜ Q値なのか

- **運動指令** = 「何をしたか」。外から観察可能
- **Q値** = 「何にどれだけ価値を感じているか」。**観察不可能**で、しかも**選ばれなかった行動の価値**（反実仮想）を含む

他者の Q値を表現するとは、「その他者が**実行しなかったが実行しえた選択肢**をどれだけ望んでいたか」を表現すること。ミラーニューロン理論への既知の批判（Hickok 2009：観察された運動の共鳴では目標・意図の帰属を説明できない）に対する、構成論的な回答になる。

元論文自身が Limitation として「他者の信念や意図といった内面の推論は獲得されなかった」と明記しており、本研究はそこに直接取り組む。

## 4. 確定した設計判断と、その理由

### 4.1 MG は R3 以降のアーキテクチャから削除する

**根拠**：元論文の `SuperpositionNetworkMotionGeneration.forward()`（root `model/model.py:120-141`）は

```python
om = self.motion_generator_module(ov_enc)
ss, os = self.superposition_module(sv_enc, sm, ov_enc, om)  # om が process-2 の入力
```

MG は **process-2 のモーション入力を供給するためのモジュール**であり、評価用デコーダではない。したがって VE はその一対一の置き換えであり、**両方を持つ理由がない**。

**v3 の誤り**：`ov_enc → MG → VE → SM` という直列構成にしていた。MG は SM に接続されず直接の損失も持たないため、**運動を予測するよう訓練されたことが一度もなかった**（R² = -576000 の真因）。この直列は v3 独自の変更で、元論文由来ではない。

**各ゲートでの構成**

| 段 | process-2 の入力 | MG | VE |
|---|---|---|---|
| R2 | MG 出力 `m̂²` | あり（元論文構成） | なし |
| R3 | 正規化後の零ベクトル | **なし** | なし |
| R4 | **`Q̂²`（VE 出力）** | **なし** | あり |

運動の診断は、**凍結した h² から A-2 の真の運動を予測する事後プローブ**として外部化する。

### 4.2 プローブQベクトル

**仕様**：
- K=8、単位円上に等間隔 `(cos(2πk/8), sin(2πk/8))`
- 静止 (0,0) プローブは追加しない
- 正規化：**tanh((Q-μ)/σ)**、μ・σ は **A-1 の実データのみ**から算出
- process-1 / process-2 で**同一の正規化統計**を使用

**なぜスカラーではなくベクトルか**：スカラー Q には方向成分がなく、LSTM が経路積分できない。元論文の内部表現は経路積分の産物なので、その根拠が失われる。K方向の値があれば argmax/重心で方向が復元できる。

**プローブが同時に解決する問題**：

| 問題 | 解決理由 |
|---|---|
| サンプリングノイズ（変動係数23%） | プローブは固定なので Q値が状態の決定論的関数になる |
| 分布シフト（ランダム行動 vs 方策行動） | どの方策で動いても `Q(s, a_probe)` は同じ |

**「A-1 の経験のみから導出する共通統計」という定式化が重要**。A-1 が知り得る情報だけで正規化するので、superposition の主張（自己の機構で他者を解釈する）が守られる。

**tanh を選んだ理由**（実測にもとづく）：

| | A-1 std | A-2 std |
|---|---|---|
| tanh | **0.629** | 0.0090 |
| 線形クリップ `(Q-μ)/(3σ)` | 0.333 | 0.0581 |

線形クリップは A-2 の分散を6倍改善するが、**A-1 の分散を半分に落とす**。R3 で使うのは process-1 のみ（process-2 は零ベクトル）なので、A-1 の分散を最大化すべき。また元論文の `m_t` が (-1,1) をフルに使っていたことと値域が一致する。

**A-2 の潰れは正規化では解決しない問題**（A-2 の Q値レンジ幅1.76 が A-1 の5.54 の1/3しかない）。R4 で正面から扱う。

### 4.3 静止の意味論

正規化後の**零ベクトル**（全方向の Q値が等しい＝方向的選好なし）を静止の表現とする。

元論文の「速度ゼロ＝動いていない」と意味が一貫し、base 学習から R4 への移行で意味論が断裂しない。**v3 はここで「価値ゼロ」という別の意味を入れてしまっていた。**

### 4.4 報酬を連続値にした理由

**カバレッジのためではない**（密報酬はむしろ点アトラクタを作る）。理由は**Q値の空間的情報量**。

しきい値報酬（緑>50px で +1.0）だと、A-2 が実際にいる場所で **Q値が平坦**になる。実測：

```
x=-9固定、yを振る：
y=-9: green= 96   y=-1: green= 52  ← green>50 の平坦な満足領域
y=-7: green=121   y= 1: green= 35  ← ここで red>50 に転換
```

`x=-9, y∈[-9,-1]` が「green>50 かつ red<50」を満たす平坦領域で、この中のどこにいても報酬が同一。角へ向かう勾配がない。

**R4 の評価は「Q̂² と A-2 の真 Q値の相関」なので、推定対象が定数では実験が成立しない。**

### 4.5 確率的行動を採用する理由

決定論化（`tanh(mean)`）を一度指示したが**撤回した**。

当初の理由は「Q¹ のサンプリングノイズを消すため」だったが、**プローブQベクトルの採用でこの理由は消滅**（`Q(s,a_probe)` は方策の確率性と無関係）。再現性もシード固定で担保済み。

そして実測が決定論化の害を示した：

| | A-2 std |
|---|---|
| v3（確率的、0.15x） | 4.95 / 5.08 |
| 決定論的、1.0x | **2.33 / 1.65** |

**確率性はカバレッジに貢献していた。** 教授のメモにも「確率εで探索、1-εで行動価値が高い方に行く」とあり、これが当初の想定だった。現行 ε=0.1。

### 4.6 データセットに Q値を焼き込まない

保存するのは `self_vision`, `other_vision`, 位置、運動、シード。**Q値は critic チェックポイント + 視覚系列から都度計算する。**

v3 は `a1_q_values` を HDF5 に焼き込んでいたため、正規化もプローブ化も試せず作り直しになった。critic の forward pass は環境シミュレーション + レンダリングに比べて桁違いに安い。

### 4.7 視覚データは uint8 で保存

元画像は 0〜255 の整数で、モデル入力直前に `scale_vision(v) = v*2-1` で正規化される。**保存時点で uint8 なら情報は一切失われない。**

float32 → uint8 で **8.21GB → 2.06GB**（1/4）。v3 から引き継がれていた無駄で、「v3 と同一だから異常なし」という判断では見つからなかった。

### 4.8 SM の部分転移

`sm` の次元が 2（運動）→ 8（プローブQ）に変わるため `weight_ih` の形が合わないが、**全部を捨てる必要はない**：

- `weight_ih_l0` の**最初の64列（視覚入力の重み）は次元不変でコピー可能**
- 新しい8列（Q値入力）のみランダム初期化
- **`weight_hh`（再帰重み）と `bias` は次元不変で全部コピー可能**

LSTM のパラメータの大半は `weight_hh` と視覚側 `weight_ih` なので、部分転移でほぼ全ての学習内容を引き継げる。

**注意**：この実装時に「66列コピー（旧行動用2列を Q値用に誤流用）」というバグが混入した。1エポックも完了しないうちに発見・修正済みで、完了済みの結果には影響していない。

### 5.1 4軸 R²（位置回帰、Ridge）

| **exp1_l1**（元論文再現） | 0.9772 | 0.0373 | 0.0774 | 0.9725 |
| **exp3**（MG付き、Cycler） | 0.9635 | 0.0129 | 0.0716 | 0.7122 |

### 5.2 R2 の評価：条件付き通過

**当初のゲート基準 `h²→self < 0.15` は未達（0.3421）。しかし基準自体を見直した。**

理由：R2 の失敗原因が **MG の学習失敗**と特定され、**MG は R3 以降存在しない**ため。exp3 の 0.0716 を再現することに意味がない（exp3 の土俵には MG があり、v4 の最終形にはない）。

R2 の当初の目的（v3 の逆転が Q値化のせいか A-2 方策のせいかの切り分け）は達成された。

### 5.3 R3-A の評価：通過

`h¹→self = 0.9086 > 0.90` で通過。**教授のステップ1「Q値で予測画像が出るようにする」に相当。**

`h²→self = 0.0910` が exp1_l1 水準（0.0774）まで改善したのも重要で、**R2 の漏れが MG 由来だった**ことの裏づけ。

**部分転移の効果はなかった**：0.9086 vs 0.9095（転移なし版）、0.5849 vs 0.5820。差は誤差範囲。
→ **SM は exp1_l1 の学習内容をほとんど使っていない**。入力が `m_t` から Q値に変わった時点で、事実上ゼロから学習し直しているに近い。

**残る懸念**：`h¹→other = 0.5849`。元論文水準（0.01〜0.04）の15倍以上。process-1 に他者情報が漏れている。
→ R5（自己投影バイアス）を測る際、process-1 に他者情報が混入していると投影を測る土台が弱くなる。**R4/R5 の解釈時に留意すること。**

### 5.4 R3-A-cycler 統制実験：RL方策仮説を棄却

**仮説**：`h¹→other` の上昇は A-2 が RL 方策で動いている（A-1 の視覚に反応する）ためではないか。Cycler なら A-1 と独立なので改善するはず。

**結果は真逆**：`h¹→other` が 0.5849 → **0.9062** に上昇。

さらに Cycler 条件では**自他分離そのものが崩れている**：

```
h¹→self  0.8219  <  h¹→other  0.9062   ← h¹ が自分より他者を良く表現
```

**解釈**：Cycler は決定論的スクリプトで軌道が完全に予測可能なため、視覚予測タスクとして A-2 の位置は極めて有用な情報になる。両プロセスがこぞってそれを符号化する。

exp3 でこれが起きなかったのは、process-1 の入力が実際の運動 `m_t` だったため。`m_t` は A-1 自身の変位そのものなので LSTM は経路積分に使うしかなく、h¹ は A-1 の位置を保持する以外に選択肢がなかった。

**Cycler は統制実験として役目を終えた。以後使用しない。**

### 5.5 R3'（Probe-Q アブレーション）：通過

**問い**：h¹ は Q値を「価値の方向構造」として使っているのか、単なる「状態の識別子」として使っているだけか。

推論時のみの操作（追加学習なし）：

| 条件 | h¹→self | 低下幅 |
|---|---|---|
| baseline | 0.9092 | — |
| rotate90（2つ循環シフト） | 0.6721 | -26.1% |
| shuffle（固定ランダム置換、大きさ保存） | 0.6382 | -29.8% |
| **critic_swap（A-2 の critic に差替え）** | **0.5927** | **-34.8%** |
| constant（各時刻の平均値に置換） | 0.5877 | -35.4% |

h²系列（0.0902 / 0.8994）は全条件で完全に不変 → 操作が process-1 側に正しく限定されていることの確認。

**critic_swap が決定的**：同じ8方向・同じ軌跡・同じ正規化定数のまま、**価値関数の中身だけ**を変えて -34.8%。入力の並びも次元も変えていないので、置換感度では説明できない。

→ **h¹ は Q を「Q値っぽい形をした何か」ではなく、A-1 自身の価値構造に依存して使っている。** 位置コード疑惑は晴れた。

### 5.6 経路積分については未確定

**実装上の発見**：`p_mask_vision_self` は `sv_enc`（エンコード後の視覚特徴）のみをマスクし、`q1_vec` はマスク前の生の `sv` から毎回計算される（`model.py` L356-364）。exp1_l1 の `m_t` も常時マスクなしで供給される設計と対称であり、バグではない。

**結果として「視覚を完全に遮断して Q のみにする」実験は R3-A に対しては原理的に実現できない**（Q が毎ステップ生の現在フレームを見ているため）。

参考値（`p_mask_vision_self=1.0`）：

| | h¹→self |
|---|---|
| r3_a_direct（Q駆動） | 0.8342 |
| exp1_l1（`m_t` 駆動） | 0.5463 |

これは「maskable な sv_enc パスへの依存度」の比較として読める。

**直接検証**（LSTM 再帰を使わず、各時刻の Q ベクトル単体から位置を Ridge 回帰）：

| | R² |
|---|---|
| Q単体（単一時刻、再帰なし） → 位置 | **0.5989** |
| h¹（LSTM 再帰後） → 位置 | 0.9086 |

**単一時刻の Q だけで 0.60 読める。** 報酬源が赤と緑の2つあるため、2つの距離から位置がかなり絞れる（「Q値が距離センサとして機能する」問題は実在した）。

一方 +0.31 の上乗せがあり、**再帰処理が実質的な役割を果たしている**。ただしそれが真の変位積分か時間的平滑化かは未確定。

**この点は無理に決着させない。** Q値入力では単一時刻でも位置情報が 0.60 得られ、再帰統合で 0.91 に達する——事実として記述すれば足りる。元論文とは経路積分の必要性が構造的に異なるため、同じ土俵での比較自体が適切でない可能性がある。

## 7. 未解決の懸念

### 7.1 `h¹→other` の漏れ（未解決のまま R4 へ）

R3-A で 0.5849。元論文水準（0.01〜0.04）の15倍以上。

**原因は特定できていない。** 棄却された候補：
- A-2 が RL 方策だから → Cycler でむしろ悪化（§5.4）
- MG が悪さをしている → MG 除去後も残存
- 部分転移が効いていない → 転移してもしなくても同じ（§5.3）

**残る有力な解釈**：Q値入力には、h¹ に自己位置の保持を強制する力が `m_t` ほど強くない。`m_t` は変位そのものなので経路積分に使うしかないが、Q値は状態の関数なので h¹ が自己位置を保持しなくても予測が成立する。結果として h¹ の容量に余裕が生まれ、予測に有用な他者情報も取り込む。

**R5 への影響**：「Q̂² が A-1 自身の選好に引かれるか」を測る際、process-1 に他者情報が混入していると投影バイアスの解釈が弱くなる。R5 の結果を見る際に留意すること。

### 7.2 MG と価値駆動方策の原理的緊張

RL エージェントは報酬を最大化するので、目標へ向かい続けるのが正しい振る舞い。実測：

```
A-1 (RandomAgent):  std_x 0.677  std_y 0.678
A-2 (RL, R2):       std_x 0.254  std_y 0.0154  ← 参照値の1/44
exp3 A-2 (Cycler):  std_x 0.690  std_y 0.690
```

**MG が学習するには運動が全方向に散る必要があるが、価値に従う方策は運動が単調になる。** 元論文が Cycler という人工的な決定論方策を使っていたのは偶然ではなく、MG が学習可能であるために必要だった。

**これは論文に書ける知見**：価値ベースに置き換えると MG の前提が崩れる ＝ v4 が VE を採用する積極的な理由。

### 7.3 A-1 と A-2 の Q値域の乖離

```
A-1 seed0: [0.075, 4.032]  分散 0.842
A-2 seed0: [3.118, 4.380]  分散 0.082
```

幅が3倍、中心も重ならない。tanh 正規化下で A-2 の分散は 5.5% まで縮小する。**R3 では process-2 が零ベクトルなので影響しないが、R4 で VE が学習可能かは要検証。**

不可の場合の対処案：
- A-2 の critic 再学習（報酬スケールを上げれば Q レンジは広がる）
- A-2 の報酬設計の見直し
- **VE の入力を `ov_enc` ではなく `h²` にする**（h² には A-2 位置情報が R²=0.90 で存在する。元論文の MG が `ov_enc` 入力だったのは MG の設計上の都合で、VE も同じにする必然性はない）

### 7.4 A-1 の緑嫌悪が R5 を妨げる可能性

A-1 は緑に −1.0 のペナルティを持つため、共有モジュールが「緑＝悪い」を強く学習する。**R5 で「VE が緑を正の価値として出す」ことが構造的に困難な可能性がある。**

R5 で分化が観測されなかった場合、これが交絡要因になりうる。

### 7.5 到達度の非対称（未解明）

環境は完全対称であるにもかかわらず：

```
A-1: Red 内1.5 に 65.5%
A-2: Green 内1.5 に 1.8%
```

実測では緑ピクセルのピークが y=-7（121px）で角の y=-9（96px）より高く、**視覚的ピークと実座標がずれている**。A-2 が帯状に留まるのはこれで説明できるが、赤側でも同じずれがあるはずなのに A-1 は角に到達しており、噛み合わない。

### 7.6 critic 崩壊のリスク

SAC の既知の失敗モード。実測で A-1 は 2/3、A-2 は 1/3 が健全だった。

**critic を再学習するたびに健全性チェックを必須とする**：ノイズ画像・4隅・行動変化に対する Q の応答を見て、`action_std > 0.05` かつ `corner_std > 0.05` を満たすこと。

一度、崩壊した critic（全入力に対し Q≈1.65 の定数出力）に気づかず進みかけた。プローブQベクトルが全部同じ値なら SM への入力が定数になり、**何を学習しても意味のない実験**になっていた。

### 7.7 データ収集クラッシュ（原因未特定）

空き42GB に対し理論値8.21GB の収集がディスク不足でクラッシュした。RAM は無罪（RSS フラット）、コードにも異常なし。消去法で「他プロセスによる圧迫」としたが直接証拠はない。**uint8 化で必要量が2.06GB に下がったため実害は消えたが、原因は未特定。**

### 7.8 A-2 の Q値分散不足（診断の因果誤り、実験再開済み）

**発覚**：2026-08-20、R4 着手前の§8.2項目2の確認作業（v4_experiment_log.md §8.2 参照）。
**訂正**：2026-08-21、停止判断を撤回し実験再開。A-2 の真 Q 値はネットワークへの入力に一切使われず（学習信号は視覚予測誤差のみ、A-2 の真 Q 値は評価時の事後相関チェックにのみ登場）、「真 Q 値の分散が小さいから VE が学習しない」という因果は成立していなかった。VE の学習可否を決めるのは Q̂² が視覚予測に寄与するかどうかであり、A-2 の真 Q 値の統計的性質ではない（元論文の MG が A-1 の真の運動を直接の教師信号にしていなかったのと同型）。**以下の分析（3手段の失敗理由、報酬増幅率48倍 vs 4倍の発見）自体は有効な知見として残す**——誤っていたのは「ゆえに実験を止める」という結論のみ。詳細は `docs/r4_a2_q_variance_blocker_report.md` 冒頭の追記を参照。

A-2 の Q値（A-1 の共有統計で tanh 正規化後）の std は 0.0092、A-1 の 0.6301 に対し**分散比 0.02%**。VE が定数を出力しても視覚予測損失がほぼ変わらないため、教師なし学習が成立しない。

**試した3手段、すべて失敗**：
1. 報酬スケール変更 → tanh 飽和の逆効果で最適 k≈0.52 でも上限 std=0.088（目標未達）
2. 探索拡大（TARGET_ENTROPY 緩和 → 全条件で critic 崩壊／ε-greedy → 崩壊は解消したが Q std は不変(0.172→0.173-0.175)、正規化後 std はむしろ悪化(0.0092→0.0017-0.0030)）
3. 正規化方式変更（A-2 自身の統計を使えば std=0.5354 で目標達成するが、循環参照になり§4.2の設計原則に反する。分布形状も非類似（歪度 -0.39 vs -2.09）で形の一致による弁明も不可）

**根本原因の再診断（重要）**：当初「A-2 の報酬変動幅が小さい（緑ピクセル96〜121px/1024）ことが原因」と想定していたが、実測で**否定された**。A-1/A-2 それぞれの実際の訪問状態での報酬 std を測定した結果：

| | 報酬 std | Q std | Q/報酬増幅率 |
|---|---|---|---|
| A-1 | 0.0196 | 0.9482 | 48.3倍 |
| A-2 | **0.0430**（A-1の219%） | 0.1721 | **4.0倍** |

A-2 の瞬間報酬の変動幅は A-1 より大きい。にもかかわらず Q 値の変動幅は A-1 の 1/5.5 しかない。**「報酬が平坦だから Q が平坦」という説明は誤りで、真因は割引累積報酬（Q）の段階にある**——価値最大化方策（A-2）はどの状態から出発しても速やかに高価値領域へ収束するため、長い割引地平線（GAMMA=0.99）の大部分が「収束後の似た将来」で占められ、出発時点の報酬差が薄まって平坦化される。ランダム方策（A-1）にはこの自己修正収束がなく、出発点の違いがそのまま将来に反映されるため増幅率が大きい。**§7.2「価値最大化方策は運動多様性を減らす」と同根の現象が、Q値の空間分散にも及んでいる可能性がある（未検証の仮説）。**

**詳細レポート**：`docs/r4_a2_q_variance_blocker_report.md`（選択肢4つの整理は記録として残すが、採否は保留——実験自体は再開したため緊急の判断は不要になった）。

**状態**：実験再開。R4（VE追加、`config/exp/r4_ve.yml`、`SuperpositionNetworkProbeQValueEstimation`）を実装・学習中。評価では真 Q 値との相関だけでなく、Q̂² を定数固定した場合との視覚予測損失比較（VE の寄与の直接判定）と、8方向の値パターン（絶対値でなく方向構造）を必ず記録する。

**Revisit at**：R4 の評価結果が出た時点。分散が小さい真 Q 値との相関は感度が低いことを承知の上で参考指標として記録する。

6. **A-2 の運動プローブ**：凍結 h² から真の運動を予測する事後プローブの R²
7. **R4 以降**：Q̂² の統計とヒートマップ、A-2 真Q値との相関

すべて `data/result/` 配下に JSON 保存し、**実験ID・git commit hash・シードをセットで記録**すること。
