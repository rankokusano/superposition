## 1. 研究の背景（ここまでの流れ）

### 1.1 元論文
Noguchi, Iizuka, Yamamoto & Taguchi (2022), *Scientific Reports* 12:2859, "Superposition mechanism as a neural basis for understanding others"。公式実装は https://github.com/wtrnoguchi/superposition （このリポジトリの root がその clone）。

- エージェント A-1 は、自分の一人称視覚と自分の運動だけを入力に、次の視覚を予測するよう学習します。
- 1つの LSTM（Superposition Module）の中に、process-1（自己）と process-2（他者）を重ねて持たせます。
- その結果、他者 A-2 の位置・視点（Fig.5）・運動（Motion Generator、相関 r≈0.87）が、予測学習だけで獲得されました。
- Limitation：他者の**内面**（意図・価値）には届いていない。

### 1.2 本研究のこれまで（v4〜v6）
入力を「運動」から「行動価値（Q値）」に置き換え、「自分の価値だけを学習して、他者の価値が分かるか」を問いました。

| 版 | 内容 | 結果 |
|---|---|---|
| v4 | Q値入力（8方向 probe-Q）。Encoder は元論文のものを凍結。MG を Value Estimator（VE）に置き換え | 自己位置は保たれる（R²=0.91）。VE は他者の価値を再現できない（相関 r≈0。自分の位置を流してしまう） |
| v5 | Encoder も価値入力で学習し直し | 学習は安定したが、他者側の表現は弱くなる。VE の失敗は解消せず |
| v6 | 推定対象を報酬パラメータ r（4次元）に変更。報酬条件付き critic Q(s,a,r) を1つ作り、自他の尺度の違いを解消 | critic は成功（段階1）。正解の r を入れると遠方では予測が改善（段階4）。しかし VE′ の推定はほぼ定数に落ちた（段階5）。**ライン終了** |

### 1.3 失敗の見立て
- **予測誤差だけでは、他者の価値を正しく作る動機がない。** A-2 は毎回まっすぐ緑に向かうので、価値を考えなくても予測できてしまう。好みが固定なので、価値は位置でほぼ決まる。
- 逆強化学習（IRL）は、まさに「行動から報酬を逆算する」推論を担う方法です。ただし前提として、他者の軌跡（状態と行動）と、価値を計算する仕組みが必要です。v4〜v6 にはこの推論の原理がありませんでした。v6 で部品（条件付き critic）は揃いましたが、推論は予測誤差のままでした。

### 1.4 指導教員のメモ（7月）

> ステップ2　逆強化学習について調べる。＝＞　ここ研究かも：ステップ1の情報を反映できないか検討する。

本研究ではこれを「**学習した予測モデルや自分の価値の仕組みを、逆強化学習の部品として使う**」と解釈します。v7 はこれを初めて実際に試す版です。

## 2. v7 でやること

### 2.1 中心のアイデア
他者の価値の推論に必要な部品を、**すべて A-1 自身の仕組みを流用して作る**。これは superposition の考え方（自分の仕組みで他者を処理する）を、価値の推論まで広げることに相当します。

| 逆強化学習に必要なもの | v7 での供給元 | 由来 |
|---|---|---|
| 他者の状態 | A-1 の視覚 → Encoder-2 → Decoder で取り出した A-2 の視点 v̂²ₜ | 元論文 Fig.5（予測学習で得た Encoder） |
| 他者の行動 | Motion Generator が推定した A-2 の運動 â²ₜ | 元論文 exp3（段階3で使用） |
| 価値の計算方法 | **A-1 自身の条件付き critic** Q(s, a, r) | v6 段階1 |
| 推論 | ベイズ逆プランニング：観察した行動を最もよく説明する r を探す | 新規 |

ベイズ逆プランニングの式：
- 行動は価値の高い方向に選ばれやすいと仮定します。π(a | s, r) ∝ exp(β · Q(s, a, r))
- 事後確率は P(r | s₁:ₜ, a₁:ₜ) ∝ P(r) · Πₖ π(aₖ | sₖ, r) で求めます。

### 2.2 段階（各段の判定基準を満たすまで次に進まない）
部品を1つずつ「本物」から「A-1 が推定したもの」に置き換えていきます。どこで崩れたかで原因が分かるようにするためです。

| 段 | 状態 s | 行動 a | 目的 |
|---|---|---|---|
| 段階0 | — | — | データ作成（A-2 の目標をエピソードごとに変える） |
| 段階1 | A-2 の本当の視界 | A-2 の本当の行動 | 上限。自分の critic で他者の行動を説明できるかの確認 |
| 段階2 | **取り出した視点** v̂² | 本当の行動 | 予測モデル由来の「他者の状態」で足りるか |
| 段階3 | 取り出した視点 | **MG が推定した行動** | 本命。A-1 の視覚だけから推論 |

**この指示書の対象は段階0〜2です。** 段階3は、段階2の結果を見て私が判断してから、別途指示します。

## 4. 研究の意図を崩さないための原則（最重要）

v7 の主張は「**他者の位置・行動・報酬を一切与えずに、A-1 の一人称視覚と A-1 自身の仕組みだけで、他者の報酬に届く**」です。以下はこの主張を守るための原則で、**どれか1つでも破ると主張が成り立ちません。** 迷ったら手を止めて私に聞いてください。

1. **推論の経路に、A-2 の真の情報を入れない。** A-2 の本当の視界・位置・行動・報酬は、**評価と、段階1（上限）・段階2（行動のみ）で明示的に許可した場所だけ**で使う。どの段でどの真値を使ったかを、結果に必ず明記すること。
2. **A-1 の critic は凍結して使う。** A-2 のデータで critic を学習・微調整しない。critic は「A-1 が自分の経験から作った価値の仕組み」でなければならない。
3. **r² を教師信号にしない。** 逆強化学習は推論であって、r² を当てる回帰器の学習ではない。r² を使ってよいのは評価だけ。
4. **β などのハイパーパラメータを、r² を見て調整しない。** β はあらかじめ決めた格子の上で周辺化する（§6.2）。
5. **位置の正解で学習した回帰器を、推論の経路に入れない**（評価用のベースラインとしてのみ可）。
6. **A-1 はランダム歩行のまま**（指導教員の指示。変更禁止）。
7. **判定基準は結果を見る前に固定する。** §6 の基準を、実行前に `docs/v7_experiment_log.md` に事前登録として書き写すこと。結果を見てから基準を書き換えない。
8. **うまくいかなかった結果も、そのまま記録する。** 数値を合わせにいく操作（条件の後付けの絞り込み、都合の良いチェックポイントの選択など）をしない。

### 4.1 v4〜v6 から変える設定（承知の上での変更）
- **A-2 の目標をエピソードごとに変える。** これまでは「A-2 は緑が好き」で固定でした（指導教員の指示）。固定のままだと、推論結果がいつも「緑」でも当たってしまい、観察から推論した証拠になりません。
- これは**新しいデータを追加するだけ**です。v4〜v6 の設定・データ・結果は一切変えません。
- 指導教員の了承はまだ得ていません（相談中）。ログに「指導教員未承認の設定変更」と明記してください。

### 4.2 書くときに必ず意識する交絡
目標に向かう A-2 では、**位置を見れば目標が分かります**（step3 Phase 3 の選好分類を撤回した理由と同じ。`docs/thesis_skeleton.md` §4）。そのため A-2 の位置を使うベースラインは強いはずです。v7 の主張は「位置より当たる」ではなく、上の主張（位置も行動も与えずに届く）です。位置ベースラインは必ず並べて報告し、主張を誇張しないこと。

## 6. 各段の内容と判定基準（事前登録すること）

### 段階0：データ作成
**内容**
- A-2 の目標を4種類にします。
  - 赤：(+1, −1, 0, 0)
  - 緑：(−1, +1, 0, 0)
  - 青：(0, 0, +1, −1)
  - シアン：(0, 0, −1, +1)
- いずれも Σ|w|=2 です。エピソードごとに、4種類から一様に1つ選びます。
- **A-2 を動かす actor は seed1 版を使います。** 推論側の critic は seed2 版です。こうすると、A-2 の動かし方と A-1 の評価の仕組みが同一モデルではなくなり、循環を少し弱められます。行動のサンプリング設定（確率的か、ε など）は `r2_a1random_a2rl` の収集と揃えてください。
- A-1：RandomAgent（従来と同じ）。初期位置はどちらもランダム。1エピソード 100 ステップ。
- エピソード数：`r2_a1random_a2rl` の train/test 構成と揃える（収集前に確認して報告）。
- 保存するもの：self_vision、other_vision、self/other position、self/other motion（**A-2 の行動は必須**）、エピソードごとの r²（目標ラベル）、シード。
- 収集の決まり：視覚は uint8、シードはデータセット名の MD5 から生成して HDF5 属性に記録、Q値は保存しない（都度計算する）。少量で bit-identical な再現を確かめてから本収集すること。
- データセット名の例：`data/data/v7_a1random_a2goal4/`（新規）

**関門（事前登録）**
- 4つの目標それぞれで、seed1 actor のロールアウト終端距離が ≤ 5 であること。v6 §25.2 と同じ基準・同じ方法（`actor_rollout_v6.py`、50ep×100step）で測ります。
- v6 の actor は赤・緑の周辺から学習しているので、**青・シアンは未確認**です。
- 青・シアンが基準を満たさない場合は、**目標を赤・緑の2種類に減らして進めます**（チャンスレベル 50%）。actor を再学習してまで4種類にこだわらないこと。どちらにしたかを報告してください。
- データの統計も報告すること：目標ごとのエピソード数、A-2 の初期位置から目標までの距離の分布、A-2 が目標から 5 以内にいるフレームの割合。

### 段階1：上限（本物の状態と行動）
**内容**
- 各エピソードの各時刻で、A-2 の本当の視界を s、A-2 の本当の行動を a として、A-1 の critic で Q(s, a, r) を計算します。
- critic は、v4〜v6 の probe-Q と同じく **hidden=None（1フレームずつ）**で呼びます。
- π(a|s,r) の正規化は、単位円上の K=64 方向の行動で近似します。大きさは観察した行動と同じにします。K は事前に固定してください。
- **β は格子 {0.5, 1, 2, 4, 8, 16} 上で一様事前分布として周辺化します。** r² を使って β を選ばないこと。
- 事前分布 P(r) は4目標で一様にします。
- 出力：各エピソード・各時刻 t の事後確率 P(r | 1:t)。

**比較するもの**

| 条件 | 内容 |
|---|---|
| 逆強化学習（本物の状態と行動） | 本段の主結果 |
| 色の割合の累積 | critic を使わず、Σₜ r · fraction(sₜ) が最大の r を答える |
| 自己投影 | 常に A-1 の r¹ を答える／事前分布を r¹ に寄せた場合 |
| 位置ベースライン | A-2 の真の位置の時系列から目標を当てる分類器。train split で学習し test で評価する。参考として必ず並べる |
| チャンス | 0.25（2目標なら 0.5） |

**指標**
- test split で、t = 1, 5, 10, 20, 50, 100 における正答率（事後確率最大の r が正解か）と、正解 r の事後確率の平均。
- 初期距離のビン別（<5、5〜10、10〜15、≥15）でも出すこと。v6 で、目標の近くでは方向情報が弱いことが分かっているためです。

**関門（事前登録）**
- 逆強化学習（本物）が **t=50 で正答率 0.8 以上**、かつ色の割合の累積を上回ること。
- 満たさなければ、「A-1 の critic では A-2 の行動を説明できない」として、段階2に進まずに報告すること。

**注意**：A-2 は v6 の条件付き actor（critic と一緒に学習したもの）で動いているので、ここは当たって当然に近いサニティチェックです。結果の読み方にそう明記してください。

### 段階2：状態を「取り出した視点」に置き換える
**内容**
- A-1 の視覚を Encoder-2 → Decoder に通して、A-2 の視点 v̂²ₜ を取り出します。Fig.5 と同じ経路です。
- 行動は本物のままです。それ以外は段階1と同じ設定にします。
- Encoder は2通り試します。
  - **(a) 主条件**：元論文の Encoder ＋ `fig5_v4_exp1l1000` の Decoder
  - **(b) 比較条件**：v6 の Encoder ＋ `fig5_v6_base` の Decoder
- Decoder はどちらも **ep100 のチェックポイントに固定**します（事前登録）。v6 は Decoder の学習量でマージンが変わる（ep10 で 0.013、ep100 で 0.023）ため、結果を見てから良い方を選ばないこと。
- (a) を主条件にする理由は、Fig.5 の結果です。
  - 元論文・v4 の Encoder は、復元した他者視点が A-2 の視界に近い（other_other 0.058 < self_other 0.136）。
  - v5・v6 の Encoder は、判定式（other_other < other_self）は通りますが、**復元画像が A-1 自身の視界のほうに近い**（self_other < other_other。v6 は t = +21.4 / +23.5）。
  - (b) で取り出した視点を critic に入れると、A-1 自身の視界に近い画像を評価することになり、推定が A-1 の好み（赤）に引っ張られるおそれがあります。

**最初に測ること（逆強化学習の前に）**
- 本当の視界 vs 取り出した視点で、critic の Q値がどれだけ一致するか。4目標それぞれについて、フレーム間の相関と、各フレームで最良となる方向の一致率を出す。
- 色の割合の一致度。
- 取り出した視点の画像例（目視確認すること）。

**関門（事前登録）**
- 逆強化学習（取り出した視点）が、t=50 で正答率がチャンスと自己投影を明確に上回ること。
- 段階1との差を報告すること（どれだけ落ちたか）。
- (a) と (b) のどちらが良いかも報告すること。
- **(b) で推定が A-1 の報酬 r¹ 側に偏っていないか**を必ず確認すること。目標ごとの混同行列と、r¹ に対する事後確率の平均を出すこと。偏りが見られた場合、それは失敗ではなく「他者の視点が取れていないと、他者の価値が自分の価値に引き寄せられる」という結果として記録すること。
