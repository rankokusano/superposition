# v15 方針：好みを一貫させ、選べるものを変える

Oct 24, 2026

## 目的と位置づけ

v15 は、他者の好みを「方角ではなく好みでしか予測できない場面」で推せるかを問うための、環境の作り直しである。10月末の論文は v12〜v14 の結果で書き、v15 はそれと並行して進める。論文が条件付き採択にならない場合や、教授の納得が得られない場合に、研究を続ける道になる。

v14 までで、他者の好みの推定は方角で止まった。理由は二つと考えられる。

- 快・不快 P が「方角ごとの（赤 − 緑）」で、色と方角の組み合わせを人が先に計算して渡している。ネットワークが学ぶのは「快い方角へ動く」で、好みは方角に縮退する。
- 学習データに、方角の外挿では予測できない場面がない。A-2 は好きな色へまっすぐ進むので、進む方角を延ばせば次の視界は当たる。v14-A でも、経験ありのモデルの選び方は、好みより「A-2 が直近に進んだ方角」によく合っていた。

v15 では、好みは一貫させたまま、選べるもの（どの色があるか）を場面で変える。好きな物に着くと「食べて」灰色になり、次に好きな物へ向かう。食べた後どこへ向かうかは、方角では決まらず、好みの順位でしか決まらない。

## 欲しい結果

自分の次の視界の予測は、欲しい結果ではなく学習の手段（学習目標）である。欲しいのは、その学習の結果として中に何が生まれるかである。

| 段 | 欲しい結果 | 位置づけ |
| --- | --- | --- |
| 土台 | 自分の次の視界が予測できる | 前提（学習の手段） |
| 土台 | 自他の分化：h¹ から自分の位置、h² から相手の位置が読め、自他が同じ形で表される（自他の揃い、Fig.5） | 前提（元論文の再現） |
| 自分側 | 自分の経験から「ある中で一番好きなものへ向かい、食べたら次に好きなものへ向かう」見込みが生まれる | 正の結果その1 |
| 他者側 | 相手の好みを与えれば、その見込みで相手の動き（食べた後の向かう先を含む）を予測できる | 正の結果その2（今の G5 にあたる） |
| 本命 | 相手の動きを見て、相手の好みを推せる。方角の外挿と好みの予測が食い違う「食べた直後」の場面で、好みの方に従う | 研究の問いへの答え |
| 本命 | それが自分の経験の有無と、自他の共有の有無で変わる | 重ね合わせを使う理由 |

## 今の設計との違い

変えるのは環境と好みの与え方で、ネットワークは v12 の作りのままにする（Encoder の扱いだけ段階1で決める）。

| 項目 | 今（v12〜v14） | v15 | 変える理由 |
| --- | --- | --- | --- |
| ランドマークの位置 | 四隅に4個 | 同じ | 自己位置の手がかりを変えない |
| ランドマークの色 | 赤・緑・青・シアン。赤と緑はエピソードごとに入れ替え | 同じ入れ替えに加え、エピソードごとに1色を灰色にする（その色がない回）。好きな物に着くと「食べて」灰色になる | 選べるものが場面で変わり、方角だけでは行動を予測できなくなる |
| 自分の好み | 赤が好き、緑が嫌い（1ビット） | 一貫した順位で、全エピソードで同じ。赤が一番好き、緑が一番嫌い（青・シアンの位置と価値は段階0で決める） | 好みは一貫したまま、行動が場面で変わる |
| 相手の好み | 緑好き、または赤好き | ① いつも同じ順位、② エピソードごとに少数の候補から選ぶ（主）、③ 一番目が同じで二番目だけ違う候補（対照）。② の候補は、一番目の色がすべて違い、二番目も違う隅にあるものにする | 推し量る必要が生まれる（いつも同じなら推す必要がない）。一番目に何を食べたかで候補が決まり、観察から順位を推す材料ができる。自分と違う好みの候補を含めれば Repacholi & Gopnik の課題に対応する |
| 動き方 | 半分は好きな色へ、半分はランダム | 半分は「ある中で一番好きなもの」へ、着いたら食べて次へ（割合は段階0で決める） | 食べた後の向かう先が好みでしか決まらない |
| 快・不快 P | 方角ごとの（赤の画素 − 緑の画素） | 方角ごとの（色の画素 × その色の価値）の和。灰色は 0 | 今の作りとの比較を保つ。青も価値を持つので範囲 2〜5 も使われ、抜け道も減る |
| ネットワーク | v12 の作り | 同じ（Encoder の扱いだけ段階1で決める） | 変える点を環境に絞る |
| 1段目の A-2 | 静止 | 同じ（食べるのは A-1 だけ） | 自分の経験だけを積む |
| 2段目の A-1 | ランダム | 同じ（食べるのは A-2 だけ） | 相手の行動だけを観察する |
| 本命の検査 | 入れ替えの瞬間（T2）、好みだけが違う相手（T5）、逆推論（v14-A） | 相手が食べた直後に、次にどこへ向かうと予測するか | 方角の外挿と好みの予測が、はっきり食い違う場面 |

1段目と2段目で、食べるのを片方のエージェントだけにする。2人が同じランドマークを食べ合うと、話が複雑になるため。ランドマークが変わるのはエピソードの間と、エージェントが食べたときだけで、それ以外はエピソードの中で動かない。元論文の分化の圧力（自分の運動で説明できない変化は相手だけ）を保つためである。

## 進め方

いちばん大きなリスクを、いちばん先に、いちばん安く確かめる順に、3段階で進める。各段階の合格を次に進む条件にする。

### 段階0：データだけの確認（学習なし、CPU、半日）

目的：この環境が、本当に「好みでしか予測できない場面」を作れているかを、学習の前に確かめる。

| 確かめること | 合格の目安 |
| --- | --- |
| 1エピソードで「食べる」が何回起きるか（1段目の A-1、2段目の A-2） | 大半のエピソードで1回以上 |
| 食べた後、向かう方角が変わる割合 | 半分以上 |
| 食べた後の相手の動きを、3通りの手がかりでどれだけ当てられるか：(a) 直前の進行方向を外挿、(b) 位置と配置だけ（行動の履歴は使わない）、(c) 本当の好みの順位（上限）、(d) それまでの相手の行動から順位を推す理想の観察者 | (d) が (a)・(b) をはっきり上回る（ネットワークは本当の順位を知らないので、(c) ではなく (d) で比べる） |
| A-1 が好みに従う割合（50% か 80% か） | 食べる回数が十分になる方を選ぶ |
| 配置の種類の数と、各配置の出現回数 | 各配置が学習に十分な回数ある |

他に、後の評価に使う「食い違いの組」を数える。主の組は、食べた隅も直前の方角も同じで、食べた物の色（それまでの行動）が違うために次の向かう先が分かれる組。対照の組（③）は、食べる瞬間まで軌跡が完全に同じで、推す材料がなく、どの観察者にも 50% になる組。

ダメだった場合：(d) が (a) を上回らなければ、観察から順位を推す材料が環境にない。学習せずに設計を直す。ここでの失敗はコストがほぼゼロである。

### 段階1：Encoder だけの試し（GPU 1〜2枚、1〜2日）

目的：いちばん大きなリスク（自他の揃いと色の区別の両立）を、本体の学習の前に確かめる。

| 項目 | 内容 |
| --- | --- |
| 学習するもの | 元論文と同じ作り（運動だけ）を、新しい環境のデータ（A-1 は好みに従って動く）で一から |
| 条件 | (i) 普通の損失、(ii) 色の誤差を重く見る損失。この2本 |
| 測るもの | 自他の揃い（コサイン）、Fig.5 のマージン、Encoder-2 から各隅の色（灰色を含む）を読めるか、Fig.5 の画像で色が描き分けられるか |
| 合格の目安 | 揃い 0.7 以上、かつ色の読み取りが高い（たとえば 0.9 以上）、かつ画像で色が描き分けられる |

A-1 が好みに従って動くデータにするのは、E1 で色の情報が育たなかった理由が「ランダムに歩くので色を区別する理由がなかった」と考えられるため。二乗誤差では、色が不確かなとき平均の色（黄色）を描くのが得になるので、(ii) も試す。

ダメだった場合：揃いと色が両立しないことが、新しい環境でも確かめられる。考察の材料として残し、本体は v4 の Encoder で凍結して進めるか、ここで止めるかを判断する。

### 段階2：本体の試し学習（GPU 2〜4枚、2〜3日）

目的：新しい環境で、自分側の見込みと、他者の好みの推定が出るかの見込みをつける。

| 項目 | 内容 |
| --- | --- |
| ネットワーク | v12 の作り（運動＋快・不快＋隠れの印、運動を隠して快・不快を止める）。Encoder は段階1で合格したもの、ダメなら v4 で凍結 |
| 規模 | 試しの規模（1000エピソード、150エポック）、経験あり・なし |
| 1段目で見るもの | 自己位置・相手の位置（分化が保たれるか）。食べた後の見込みが、次に好きな色へ移るか（今の M1(d) を、食べる瞬間の前後で見る） |
| 2段目で見るもの | 相手の本当の快・不快を与えたとき、食べた後に予測の中の相手が次に好きな色へ向かうか（G5 の新版）。逆推論の候補を好みの順位にして、食べた後の向かう先で選べるか |
| 本命の判定 | 方角の外挿と好みの予測が食い違う「食べた直後」の場面で、好みの方に従うか |

## リスクと、どこで止まっても分かること

成功の見込みは高くない。ただし段階ごとに確かめるので、どこで止まっても次の判断材料が残る。

| リスク | 大きさ（この設計で） | 根拠 | 確かめる段階 |
| --- | --- | --- | --- |
| 見え方の構造が変わる | 小 | ランドマークの位置と数は変えず、ない色は灰色の立方体にする | 2 |
| 配置の種類が増える | 中 | 今は 2 通りで問題なく読めた（v11 で t=1 からほぼ 1.0）。この設計では 8 通り程度 | 0、1 |
| Encoder が色を持てるか | 大、未解決 | v4 の Encoder は赤緑すら Decoder が描き分けられない程度に弱い。揃いと色を両立する Encoder は未得（E1・E2） | 1 |
| 学習が難しくなる | 中 | 食べる前後で行動が変わるので、今の見込み（G2・G3）も出なくなるおそれ | 2 |
| それでも近道が残る | 中 | 食べた直後も、数歩見れば方角の外挿で当たる。差が出るのは食べてから数歩の間だけ | 0、2 |

| どこでつまずくか | 分かること | 貢献の大きさ |
| --- | --- | --- |
| 段階0：(c) が (a) を上回らない | 環境の作りが足りない。学習前に設計を直せる | なし（コストもほぼなし） |
| 段階1：揃いと色が両立しない | 「自他を同じ形で表すこと」と「価値に関わる特徴を表すこと」が予測学習の中でぶつかる。E1・E2 の結果を補強する | 中 |
| 段階2：自他の分化が崩れる | 重ね合わせの分化には、エピソードをまたいだ環境の安定が要る。元論文が明示していない条件 | 小〜中 |
| 段階2：土台は保たれるが、好みは推せない | 好みが予測に必要な環境でも推せない。限界は環境ではなく学習目標（1歩先の予測）にある | 中 |
| 成功：好みを推せる | 研究の問いへの正の答え | 大 |

成功以外の行は、それだけでジャーナルの主の結果になる強さではない。修論や、今の論文の考察・今後の課題を具体的にする材料になる。

## 未決事項

- [ ] 好みの順位の具体的な値。A-1 は赤が一番、緑が最下（決定済み）で、青・シアンの位置と価値。② の A-2 の候補（A-1 と同じ一番目の候補を入れるか）。② の条件のためにシアンに価値を持たせるか
- [ ] 灰色にする色の選び方（毎回1色か、全色ある回も混ぜるか）
- [ ] 「食べる」の条件（どれだけ近づいたら食べたことにするか）
- [ ] A-1 が好みに従う割合（50% か 80% か。段階0 で決める）
- [ ] 本命の判定の具体的な指標と、事前登録の内容（段階2 の前に決める）
- [ ] 共有しないモデル（process-1・2 で重みを分ける）を対照に入れる時期（段階2 か、本番からか）
- [ ] 快・不快を方角ごとの形のままにするか。この形は好みを方角に縮退させた原因の一つ。v15 では比較のために保つが、食べた後に相手の快・不快が変わるので、他者側の部品は好みの順位を知らないと正しく書けない。それでも近道が残れば、色で書かれた欲求の信号への変更を検討する
