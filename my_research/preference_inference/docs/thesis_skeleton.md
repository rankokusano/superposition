## 1. 貢献1 —— 自己表現は価値入力レジームへ transfer する（陽性・確定、ただし n=2）

**主張**：予測学習だけで、A-1 の自己位置表現は運動入力レジームから価値入力（probe-Q）レジームへ transfer する。

**支える実験・数値**：
- **R3-A_400（frozen Encoder ＋ probe-Q、`r2_a1random_a2rl`、in-dist）：h¹→self = 0.9065**（収束2シード、between-seed sd ≈ 0.0006、**n=2 参考値**）。運動入力（元論文 exp1_l1_1000 = 0.967）よりやや低いが高水準。
- 収束率 **2/3**（seed0 trans@290、seed1 trans@236 が収束。seed2 は境界例：①level OK・②drift のみ基準外、trans@327、h¹→self 0.8971）。200ep では **0/3** → 400ep 延長が必須だった（定量的証拠）。
- h² は自己位置を拾わない（h²→self ≈ 0.06–0.09、全 base 系列共通）＝ superposition の役割分離が base 段で保たれる。
- **critic_swap アブレーション（R3′、`v4_experiment_log §5.5`）——「h¹ は Q を位置の代理として読んでいるだけでは?」への直接の反論**：推論時のみの操作（追加学習なし）で h¹→self が baseline 0.909 から
  - critic_swap（**A-2 の critic に差替え**、8方向・軌跡・正規化定数は同一、価値関数の中身だけ変更）→ **0.593、−34.8%**
  - rotate90 → 0.672（−26.1%）／ shuffle（大きさ保存の固定置換）→ 0.638（−29.8%）／ constant（各時刻の平均に置換）→ 0.588（−35.4%）
  - h² 系列（0.090 / 0.899）は全条件で完全に不変＝操作は process-1 に正しく限定。
  → **h¹ は A-1 自身の価値構造に依存して Q を使っている**（「Q値っぽい形の何か」ではない）。置換感度・次元・並びでは説明できない。
  補足（§5.6）：単一時刻の probe-Q だけでも位置が R²≈0.60 読める（報酬源が2つ＝距離センサとして機能）。再帰統合で 0.91 に到達。→ 「0.91 は Q を位置の代理として読んでいるだけ」という指摘への回答が critic_swap。

**限界（反証可能な形で）**：
- **n=2**（収束シードのみ）。seed を増やして収束率が下がる、または h¹→self の分散が 0.0006 より大きくなれば、「再現性が高い」は後退する。
- **3シードは SM 部分のみ**（Visual Encoder frontend は seed-0 共通で凍結）。frontend の乱数を変えると h¹→self が動く可能性は未検証。
- **base データ依存**：A-2 静止 base ＋ probe-Q の R3-stay_400 系列では h¹→self が 0.768 に下がり **3/3 未収束**。「価値入力なら常に transfer する」ではない。
- **R3-A seed0 は「当たり」シード**（3シード中唯一 200ep で相転移）。P0-2 の pretrain 元がこれである点は §3 の留保に波及。
- 運動入力（0.967）との 0.06 の差は「probe-Q 入力そのもののコスト」（`results_log` §5quater (6)）＝ config バグではなく知見。
- **h¹→other 漏れ（未解決）**：R3-A の **h¹→other = 0.585**（元論文水準 0.01–0.04 の 15倍以上、P0-2/R3-A_400 でも ~0.58 で再現）。**「自己表現が transfer した」と言うとき、その h¹ が他者情報も相当量持っている**——process-1（自己）の状態が純粋な自己表現ではない、という注記が要る。原因は未特定：**A-2 が RL 方策だから説は Cycler 統制で棄却**（0.585 → 0.906 と逆に悪化、`v4_experiment_log §5.4/§7.1`）、**部分転移説も棄却**（転移あり 0.9086 vs なし 0.9095、差は誤差範囲）。残る候補は「Q は状態の関数なので `m_t` ほど h¹ に自己位置保持を強制しない」のみで、未検証。R5（自己投影バイアス）の解釈にも交絡しうる（Future Work）。

## 2. 貢献2 —— 機構の自己組織化：Encoder は運動レジームに依存していた（陽性・確定、単一シード）

**主張**：「運動入力で作った Visual Encoder を凍結流用して『価値に置き換えた』」とは言えない。**価値入力には専用の視覚表現が必要**。Encoder を価値入力の下でスクラッチ学習し直すと、凍結流用で起きていた学習の非収束が解消し、予測性能も改善する。**ただし Encoder 再学習は非対称に効き、他者表現の組織化は3経路一致で悪化する。**

**支える実験・数値**：

*自己側（4経路すべて改善）*：
- 収束：v5_base_mse trans@27・滑らか単調（元論文型）／ R3-stay_400 は **3/3 未収束**（「ep1 で下がって以降じわじわ上昇」の共通病理）
- 視覚損失（train 最終）：fp_other **20.1 vs 30–60**、fp_self **10.6 vs 13–14.5**、self_vision **12.05 vs 16.5–17.9**
- 予測画像（通常予測経路、viz20）：mean\|pred−truth\| **0.051 vs 0.077**（元論文運動入力 0.031）
- h¹ の 2D 場所マップ組織化：PC 全ペア最良 **0.61/0.63 vs 凍結 R3-stay_400 の 0.34/0.46**
- Encoder 分化：sv_enc/ov_enc cos_sim **0.26 vs 0.48–0.66**（元論文よりむしろ分化）

*他者側（3経路すべて悪化、独立測定が一致）*：

| 経路 | v5 | v4（凍結 Enc） | 比 |
|---|---|---|---|
| h² の 2D 場所マップ（Fig.4c 相当・PCA 状態マップ） | 片軸 PC 0.87/**0.07** | 2D PC 0.81/**0.96** | y 軸が消える |
| h²→other 位置デコード（128次元 Ridge、common） | **0.64** | **0.86** | 0.74× |
| Fig.5 他者視点再現マージン（`other_self − other_other`、ep10=ep100） | **0.025** | **0.091** | 0.27× |

- **原因は scratch Encoder に確定**（統制：R3-stay_400 = 同一データ `r3_stay`・同一入力 probe-Q・**Encoder のみ凍結**で 2D マップ 0.81/0.96 とマージン 0.091 を保つ）。
- 対立仮説はすべて反例で棄却：**報酬配置説**（Red/Green とも x=−9 → x 優位のはず）→ 実測は probe-Q→y R² 0.55 > →x 0.36、\|dV/dy\| > \|dV/dx\|（y 優位、逆）。**価値入力説** → R3-A_400 は価値入力でも h² 2D マップ 0.83/0.94。**静止データ説** → R3-stay_400 は静止データでも h² 2D マップ。
- 自他分離の**向き**は v5 でも保たれる（状態レベル h²→A-1位置 cross ≈ 0、Fig.5 `other_other < other_self` 成立）。壊れているのは分離の**質**（他者位置の解像度・場所マップ構造）。

**この研究の前提への回答**：**「言えなかった」。** 元論文の Encoder は exp1 の運動入力学習で「自他が分離するよう」組織化されていた。価値入力ではその組織化を Encoder に再度求める必要があり、再学習すると自己側は改善するが他者側は損なわれる。→ 「価値に置き換える」には視覚表現の再設計まで含めた検討が要る。

**限界（反証可能な形で）**：
- **v5 は単一シード（seed 0）**。別シードで収束挙動・h² 悪化幅が大きく変われば「Encoder が原因」の確度が下がる。
- **v5 は「動く他者」で訓練されていない**（base 段は `r3_stay` = A-2 静止、元論文 exp1 に対応させたため）。他者トラッキングの弱さ（h²→other 0.64）は「静止他者で訓練＋scratch Encoder」の2要因重畳。本来の解は P2-a `v5_r4_move`／Future Work の v5 フルチェーン。
- **h¹ の 128次元 Ridge プローブは 0.80**（情報は全空間にある）が、支配的 PC への 2D 場所マップ組織化は PC1–3 に散らばる（PC0–1 では 0.10/0.51）。「h¹ 組織化が改善」は「凍結 R3-stay_400 比」であって「元論文 0.97/0.96 比」ではない。
- **元論文 exp2 との Fig.5 数値比較には条件差**（評価シナリオ `self_stay_other_random` vs `self_random_other_stay_1000`、Autoencoder recipe）。v4 の other_other 0.058 < exp2 の 0.1125 を「v4 Encoder が原著より良い」とは主張しない。**確実なのは v4 vs v5 の完全同条件比較のみ。**

## 3. 貢献3 —— 他者の価値の生成的予測（VE）は元論文に忠実な条件で失敗する（陰性・確定）

**主張**：元論文の Motion Generator を Value Estimator（VE）に一対一置換し、元論文に忠実な系列（P0-4：A-2 静止 base → A-2 移動で VE 追加、exp3-parity runner）で回すと、**VE は A-2 の価値を表現できない**。失敗は3性質を持つ。原因の一部（能動的な害・学習非収束）は **Q 値の自己との通約不可能性**。ただし値域を揃えても VE は成功しない（残余の失敗）。

**支える実験・数値**：

*失敗の3性質（P0-4、late-5 平均 ± inter-ckpt sd）*：
1. **方向が積極的に間違っている**：VE のピーク方向は A-2 の目標と逆（P0-4 緑ターゲット cos_sim **−0.80**、45°以内が chance 25% 未満）。「効果なし」より強い。
2. **真 Q を VE 出力に差し替えると視覚予測が悪化**：`true_q2 − zero = +0.00441 ± 0.00048`（SURVIVES）。
3. **学習が収束しない**：`fp_other` が P0-5 基準を外す（min 8.55@ep191、ep400 で 9.14）。base の `r3_stay_400` も 3/3 未収束。

*原因の切り分け（P1.75 対称サニティ：A-2 の報酬を A-1 と一致させ Q 値域を構造的に揃えた。真 Q std 0.009 → 0.593）*：
- `true_q2 − zero` が +0.00441 → **+0.00014 ± 0.00039（FRAGILE、ゼロと区別不能）** ＝ **害が消える**。
- P0-4 で収束しなかった学習が **P1.75 ではクリーンに収束**（trans@3、同一構造・データのみ差）。
- → **害（性質2）と非収束（性質3）は Q 非通約性が原因**。

*ただし残余の失敗*：
- P1.75 でも `true_q2` は zero を上回らない（益ではない）。方向は依然逆（cos_sim −0.46）。process-2 表現は P0-4 より弱い。**値域一致は VE 成功の十分条件ではない。**
- 残余の候補：**位置優先**（VE 入力 `ov_enc` は A-1 視覚由来 → 他者の価値より位置を流すほうが視覚予測損失を下げる。h²→self は base 0.056 → VE 0.47 と上昇）。**P0-2（非忠実）に加え、収束した忠実系列 P2-a でも安定して観測された（下記）→ 候補から「支持のある仮説」に格上げ。**

*P2-a（v5_r4_move、Encoder 要因の独立検証）—— 確定（2026-09-10）*
事前登録した基準（`research_plan §P2-a`）での判定：

| 指標 | P0-4（参照） | **v5_r4_move（late-5）** | 判定基準 | 結果 |
|---|---|---|---|---|
| `true_q2 − zero` | +0.00441 ± 0.00048 | **+0.00333 ± 0.00006**（SURVIVES） | ≈0 または負 | **❌** わずかに縮小するが依然正・頑健（真 Q は依然として害） |
| `Q̂²→A-2位置` / `→A-1位置` | 0.633 / 0.193（他者を符号化） | **0.097 / 0.387**（**自己を符号化・逆転**） | 差が拡大 | **❌** 逆転して悪化 |
| 方向 cos_sim（緑ターゲット） | −0.80 | **−0.378 ± 0.009** | 正に転じる | **❌** 緩和するが依然明確に負 |
| 収束（`fp_other`、P0-5 基準） | ❌ | **✅ CONVERGED（trans@3、drift 0.066）** | ✅ | **✅** 改善 |

参考：`real − zero = +0.00745 ± 0.00019`（SURVIVES）＝ VE 出力そのものが視覚予測を能動的に悪化（P0-4 は −0.0018 で微弱に有用だった）。h²→self は base（v5_base_l1 common）0.081 → VE 段 **0.634** に急上昇、h²→other は 0.645 → 0.660 とほぼ不変。

**判定：4基準中3つ不合格、収束のみ合格。事前登録の「改善しない」に該当するが、非対称。**
- **学習の非収束（性質3）には Encoder が寄与していた** —— v5_r4_move は収束（P0-4 は未収束）。`§4ter.1`「安定性は Q 値域一致に依存」に加え「運動レジーム Encoder も非収束の一因」。
- **表現の失敗（性質1・2：方向が逆・真 Q が害）は Encoder 再学習で解消しない** —— cos_sim 依然 −0.38、`true_q2 − zero` 依然 +0.0033（頑健）、Q̂² は A-2 でなく **A-1 の位置を符号化（逆転）**。
- → **VE の中核的失敗（他者の価値を表現できない）の主因は Encoder ではない。** P1.75（値域一致でも失敗）と合わせて、**主因は Q 非通約性 ＋ 位置優先。Encoder は学習の安定性にのみ寄与していた。**
- **位置優先の格上げ**：v5_r4_move は**収束した忠実系列**で、Q̂²→A-1位置 0.387 ≫ →A-2位置 0.097、h²→self 0.081→0.634。P0-4 のチェックポイント依存問題がなく安定。**F3 VE 段の PCA でも h² の支配的分散が A-1 位置**（cross PC0-1 = 0.44、P0-4・P1.75 は cross ≈ 0）＝視覚的にも確認。→ §3 冒頭の「残余の候補：位置優先」は P0-2 限定でなくなり、**支持のある仮説**になった。

**standing caveat（適用）**：v5 base の h²→other は弱い（common 0.645 vs 凍結 0.86）。v5_r4_move の VE 段でも 0.660 と改善せず。**「Encoder が表現失敗の原因でない」と「base の他者表現が弱すぎて VE が学べない」は完全には区別できない。** ただし後者だとしても「Encoder を直せば VE が動く」は否定される（v5_r4_move で実際に動いていない）。h¹ 組織化は v5 のほうが良いので、留保は h² 側に限定。

**限界（反証可能な形で）**：
- **P0-4 は未収束**。P0-4 由来の単一チェックポイント値（h²→self、Q̂²→自己位置）はチェックポイント依存で、**頑健に押せるのは `true_q2` と弱く `Q̂²→他者位置` のみ**。late-5 平均＋inter-ckpt sd を必ず併記。
- **P0-2（収束）は非忠実系列**（base 段から A-2 が動くデータ、元論文の静止base→移動生成と構造が違う）。h²→self（0.10→0.82）はここでしか安定測定できないが、主結果には使わない。
- **値域一致下でも他者位置符号化が P0-2 未満の理由は部分的に未解明**（base フロントエンドの弱さ＋A-2 位置分布の集中で部分説明、完全には解けていない）。
- P1.75 は**原因特定のための対照実験**であって研究の方向ではない（A-1＝A-2＝赤好きでは「異なる価値観の他者を理解」という問いが成立しない）。

## 4. 方法論的警告 —— 目的地指向他者での「選好分類」は位置交絡（旧・貢献2 の撤回）

**当初の本命主張**（旧・貢献2）：Phase 3 で「A-2 の選好（どのランドマークを目指すか）が h² に創発し、線形分類で読み取れる」。mg7 PCA スコアと分類精度を根拠にしていた。

**なぜ崩れたか**：
- **目的地指向エージェントでは preference ≡ position**。A-2 が「Red を目指す」＝ A-2 の軌道が Red 方向に偏る、であって、選好とその瞬間位置は不可分。
- したがって h² から選好を分類できても、それが「選好を表現している」のか「A-2 の位置を表現しているだけ」なのかを区別できない。
- **適切なベースライン（A-2 位置のみを入力とする分類器）を組むと、それが h² ベースの分類器を全区間で上回る**。h² は位置以上の選好情報を持っていない。
- （mg7 PCA スコアも同じ交絡。位置で説明がつく。）

**論文での扱い**：この主張は**撤回**。ただし撤回そのものを方法論的教訓として1節で報告する：
> 「潜在状態から他者の潜在変数（選好）を線形デコードできる」という結果は、**その潜在変数が観測可能な状態（位置）と混同されていないベースラインで初めて意味を持つ**。目的地指向タスクでは選好と位置が縮退するため、選好デコードの主張には行動パターン型の選好（時計回り／反時計回り／停止など、位置と独立に定義できるもの）が必要。

→ Future Work「多選好の選好分類（行動パターン型）」がこの正しい設計。本論文では実施しない。

## 5. 付随する定量的知見（副次的貢献）

- **入力様式が学習ダイナミクスを質的に変える**：運動入力は相転移 ep ≤ 6 で滑らかに収束（元論文 2/2）。価値入力（probe-Q）は収束に数百エポック要し、seed 依存で未収束もある（R3-A_400 2/3、R3-stay_400 0/3）。→ F9。
- **学習の安定性は Q 値域の一致に依存**：P0-4（非対称）と P1.75（対称）は構造同一・データのみ差で、前者は未収束・後者は収束（`results_log` §4ter.1、独立した結果）。
- **報酬源の空間配置と価値表現**：Red(−9,+9)/Green(−9,−9) が y 方向に分離 → A-1 の probe-Q は x より y に敏感（→y R² 0.55 > →x 0.36）。運動ベクトル `m_t` は x-y 対称なので、この非対称は価値入力固有。

## 8. 「何が言えて、何が言えないか」まとめ

**言える**：
- (a) 自己表現は価値入力へ transfer する（h¹→self 0.91、n=2）。**h¹ は Q を A-1 自身の価値構造として使っている**（critic_swap で −34.8%）。**ただし h¹→other も 0.585 あり、process-1 の状態は純粋な自己表現ではない**（原因未特定）。
- 価値入力には専用の視覚表現が要る（凍結 Encoder では非収束、再学習で解消）。
- Encoder 再学習は自己側を改善し他者側を損なう（3経路一致の非対称）。
- 他者の価値の生成的予測（VE）は元論文に忠実な条件で失敗する（方向逆・真 Q が害・非収束）。
- その失敗のうち **害と非収束は Q 非通約性 ＋ 運動レジーム Encoder が原因**（対称サニティ P1.75 で害が消える／Encoder 再学習 P2-a で収束する）。
- **VE の中核的失敗（他者の価値を表現できない）は Encoder を直しても解消しない**（P2-a：v5_r4_move は収束したが `true_q2 − zero` 依然 +0.0033・方向 −0.38・Q̂² は A-1 位置を符号化）。→ 主因は Q 非通約性 ＋ **位置優先**。
- **位置優先は「支持のある仮説」**：収束した忠実系列 P2-a で Q̂²→A-1位置 0.39 ≫ →A-2位置 0.10、h²→self 0.08→0.63（`ov_enc` は A-1 視覚由来なので他者の価値より自己位置を流すほうが視覚予測損失を下げる）。

**言えない／未確定**：
- (b) の h²→other が process-2／superposition の働きか副産物か（P1.5 未実施）。
- **位置優先が「残余の失敗」の唯一の原因かどうか**（支持はあるが排他的証明はない。P1.5 が部分的に切り分ける）。
- 貢献1 の確定値（n=2 参考値、frontend シード未変更）。
- 貢献2 の Encoder-原因説の確度（v5 単一シード）。
- **「Encoder が VE 中核失敗の原因でない」と「v5 base の h²→other が弱すぎて VE が学べない」の完全な切り分け**（standing caveat。ただしどちらでも「Encoder を直せば VE が動く」は否定される）。

**主張しない**：
- 価値機構がゼロから創発する（RL critic は所与）。
- 単一環境・手設計報酬を超える一般性。
- v4/v5 の Encoder が元論文より優れている（Fig.5 の条件差）。
- 「他者の選好の分類」（position 交絡で Phase 3 撤回済み）。
